# 玩家五枪生命、敌人转体与枪声、手雷模型修复

实现基线：`1e26594`；交付分支：main。追溯 P3 task019、场景 task014、玩法 task015，BDD23/27，接口03/15/19。保留原有本地字体、OpenXR及项目设置修改。

## 改动

- 玩家默认生命5、有效敌弹伤害1，前四次命中存活，第五次失败。敌人仍为两次玩家子弹命中才死亡。HUD消费Health/MaxHealth显示五格及5/5至0/5；修复分格浮点边界使已失去的格仍亮的问题。
- 核心判定敌人进入Attacking后，场景按实际步长以180度/秒平滑水平转体朝向玩家，并回传实际朝向。保留位置、视角、遮挡、射程及攻击间隔，死亡、暂停、追踪丢失和开场锁定时停止。
- 确保敌人枪声音源启用、非静音、3D定位，使用8m至65m线性衰减和优先级32，使30m有效射程内枪声不再被原有对数衰减大幅压低；反馈去重及致命射击表现保留。
- 生产投掷测试确认未绑定GrenadePrefab时，CLR空合并运算跳过了Unity序列化空引用的资源回退，记录“Grenade model resource is missing”并不生成投射物。改用Unity对象空引用判断，正确加载已有原始M67模型。
- 手雷启用网格后从网格几何求包围盒，归一化为22cm并居中，不依赖首帧Renderer.bounds；世界根保持单位缩放。爆炸粒子先停止并清空再设置duration，修复实际爆炸时的Unity断言。
