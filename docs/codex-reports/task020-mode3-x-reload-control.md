# task020 模式三 X 键换弹与左手控制交接修复

## 行为与根因

原模式三输入使用左摇杆按压，与用户要求的左手柄 X 键不同；换弹表现覆盖人物手姿态，但前握把仍可被左手选择、输入控制器仍保留双手握枪状态。

本次将模式三 VR 换弹接到左手柄 `primaryButton`（X）的按下沿，兼容 Input System 与 Unity XR 输入回退。持续按住只触发一次，松开重按才产生新命令；模式三 X 不再同时提交 Confirm。模式四保留左摇杆按压换弹及 X 交互，桌面 R 保留。

有效换弹开始后，输入适配清除左手握持；场景取消当前左手 XRI 选择并锁定前握把，右手继续持枪。人物左手暂时脱离手柄父节点跟随换弹锚点，手柄移动不能拖动动画中的手。服务仍控制两秒计时和装填，动画不修改弹药。

结束、暂停、追踪失效、终局、退出或组件禁用均恢复左手父节点、手柄控制与握枪入口。恢复后左手松开再按 Grip 重建双手持枪；满弹、无备用及其他无效请求不进入动画或锁定。HUD 根据模式显示正确的换弹提示。

## VR 实机验收

1. 进入模式三并完成无人机开场，双手握枪，先发射至少一发再按左手柄 X。应开始拔匣、移出视野、装入动作；按左摇杆不换弹。
2. 换弹中移动/旋转左手柄、保持或反复按 Grip：左人物手继续执行动画，不能握住前握把，不能开火；右手握枪、HMD 和 UI 射线仍正常。
3. 两秒动作结束后 HUD 枪内30发、备用减少一个弹匣；左人物手恢复跟踪，松开再按 Grip 可重新支撑枪械并射击。
4. 在动作中暂停或丢失跟踪：取消装填、弹药不变，左手恢复控制且不遗留握枪锁定。重试后库存恢复30/60。
5. 满弹/无备用/准备阶段按 X 不启动动画；模式四仍按左摇杆换弹，X 开门/检查正常。

无设备替身和编译检查不能替代以上双眼可见性、手握姿态及舒适度实机验收。
