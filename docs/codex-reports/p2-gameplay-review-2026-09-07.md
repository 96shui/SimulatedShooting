## 评审结论

移动靶不是尚未实现：设置、拾枪门禁、倒计时、路线移动、左端禁射、两发起射/连射、结算和重试已有实现。本次发现的问题主要在场景武器生命周期与逐发反馈，不是缺少移动靶状态机。

## 本次修复

- 控制器停用后只清除了输入订阅，却保留初始化标记；重新启用后输入分发器为空。现已重新建立订阅，停用时取消连射并复位后坐力。
- 重试沿用旧局握枪状态和射击序号，可能跳过重新拾枪、漏播新局第一发反馈。现按 Session 清空缓存、解除旧 XR 抓取、枪回架；保留无 VR 基准视点，避免重新初始化时累加 ADS/后坐力偏移。
- 最后一发可能先触发服务结算再到达场景订阅者。逐发反馈改为核对已绑定 Session，避免因当前 Session 已结束而漏播。
- 碰撞反馈传入了默认 RaycastHit，命中特效坐标错误。现使用真实物理碰撞点和法线；环境有碰撞反馈，但仍不计靶标命中。
- 新局清空旧靶面标记和命中去重缓存。
- P2 输入事件使用 MovingTargetHud 来源；不再误标成 P1。武器组件不会在结算后擅自新建 P1 Session。
- 枪回架时不再对静态刚体写速度，避免物理警告；控制器复用并释放临时曳光材质。
