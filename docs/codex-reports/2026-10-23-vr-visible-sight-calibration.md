# 2026-10-23 VR可见瞄具与实际枪线标定

用户明确问题发生在VR。此前桌面ADS输入整改偏离问题，相关控制逻辑和测试已撤回；其记录保留为历史，不能作为本轮验收。当前以BDD33、接口25、P1功能B task013与场景task012为准。

## 复现的实际原因

原AimLinePoint位置为`(0.006, 0.047, -0.118)`，旋转为单位四元数，即沿枪体+Z。它没有经过模型上真正的觇孔中心，方向也没有经过准星柱顶部。此前测试直接按这个虚拟锚点摆正枪体，无法发现玩家在HMD中按可见瞄具瞄准后的偏差。

本轮从现有QBZ191源OBJ提取几何，并在Unity导入后的真实MeshCollider上验证：

- 源OBJ的X轴经Unity导入镜像。后觇孔内圈包络中心约`(-0.0057315, 0.0573025, -0.118108)`，前准星柱近侧顶边约`(-0.005689, 0.050240, 0.228503)`，单位米，坐标在RecoilRoot空间。
- 穿过后觇孔中心的射线可通光；上移3mm碰到金属环。前准星处自上向下射线命中实际柱顶，排除了把护圈或装饰螺丝当成瞄准点的做法。
- 旧锚点射线与可见瞄具射线在100m处相差**2.02969m**。真实XRI双手持枪、只移动跟踪姿态对齐可见瞄具后，旧生产快照仍偏离靶心**201.927856cm**。两条独立回归均先失败，证据已保存。

## 修改

只校准现有步枪Prefab中AimLinePoint的位置和朝向，使其位于觇孔中心，朝向实际准星柱顶。`TrainingRifleSightCalibration`记录标定；Prefab构建器同时应用该标定，防止重建恢复旧错误。编辑器菜单支持只更新瞄准锚点，不重建模型、材质、手部、握把或碰撞体。

生产射击继续使用真实枪口指向可见瞄具在目标平面的交点；实际遮挡、三发一轮、首轮固定偏移、补偿、弹孔、曳光、评分仍走原服务链路。未添加吸附、扩大十环、移动靶子、修改HMD视角或修改VR FOV。

步枪Prefab为多个模式共享，故进行全项目回归。两份旧物理测试的摆枪辅助函数同步改为考虑瞄准线在枪体上的真实标定旋转；这些辅助函数仍不是VR输入验收依据。

## VR验收路径

新增`VrZeroingMechanicalSightTests`使用真实场景、真实步枪Prefab、XRDirectInteractor、XRInteractionManager和生产控制器/服务。只替换无设备环境中的头部与双手跟踪、扳机输入：

1. 经InteractionManager选择右后握把，再选左前握把，得到TwoHandHeld。
2. 根据独立的模型觇孔和准星几何，只转动两个跟踪替身，等待XRI更新枪体；测试不直接摆正枪体Transform。
3. 通过扳机输入击发三次，应用首轮建议，再执行下一轮三次。
4. 验证目标平面采样距可见瞄具瞄点小于1cm，六发均有实际弹孔，第二轮三发均为十环，平均偏差小于1cm。
5. 验证开枪不改写头部位置、旋转、FOV；独立移动头部不改变枪线；松开支撑手后扳机不能产生有效射击。

首次校准后这两条VR PlayMode测试已通过。全量EditMode **336/336通过**；最终PlayMode结果和原始输出见[evidence/vr-mechanical-sight-20261023](evidence/vr-mechanical-sight-20261023)。

最终模式一/二相关PlayMode **86/86通过**，包括新的VR双手/扳机/头部隔离、旧物理射击、补偿、VR场景交接、后坐回正、P2两发及路线、P1训练流程与分析UI。VR测试六发目标平面采样均显示`(0.00,0.00)cm`，第二轮平均弹着也为`(0.00,0.00)cm`（日志显示精度）；断言验证每发误差小于1cm及六个实际弹孔，未以日志四舍五入替代断言。

全量PlayMode执行261项后有两项失败：其一是旧“背向/平行”测试直接旋转枪体+Z，标定后该轴已不等于光学方向，已修正测试以实际光学方向构造背向/平行射线，保留原未命中断言。其二为模式三`Bdd14_NewTrenchAllowsContinuousMovementAndFiring`的`Combat request rejected: NotFound`。对该项分别使用标定后的Prefab和未标定的HEAD原Prefab独立重跑，均报同错；该测试用相机FrameOverride射线，未使用本次标定锚点。保留原失败记录，不修改模式三业务逻辑，也不宣称本次全量PlayMode零失败。比较结束后已恢复标定后的Prefab。

证据图片为Unity原生渲染：`vr-substitute-mechanical-sight.png`是跟踪替身眼位的单目机瞄图，`vr-round2-target-inspection.png`为近靶检查镜头。它们不是实机双目截图；真实头显验收尚需确认自然对齐觇孔/准星后能正常射校、双手稳定性和舒适度。本轮不会把键鼠测试或跟踪替身描述为实机通过。

原P1/P2场景文件保持`54073a0`的100m后排靶布局。验证后恢复测试前OpenXR设置，不提交或推送。

最终`git diff --check`通过；未发现C#编译错误。Console仍含无眼动设备环境提示，不宣称实机设备或Console零日志验收。Unity已退出Play Mode。
