# 模式三/四：队友火力、脚底贴地与落枪

日期：2026-10-25。关联：BDD23、接口15、P3玩法task004、场景task014。

## 改动

- 核心服务接收可替换的队友感知事实，30米内对准且无遮挡的敌人持续可见1.5秒后开火，随后每1.5秒一次，每发1伤害；两名队友各自计时。不消耗玩家弹药，击杀进入已有清敌/结算。暂停、失踪、开场、终局、投雷、目标死亡或遮挡时停止新射击。
- 场景采集队友枪口射线，排除自身、保留墙/门/其他人物遮挡，并检查枪口是否在墙中。关闭房门的敌人不能作为目标。瞄准期间关闭导航自动转体，但保留跟进路径；失去目标恢复导航转体。服务攻击反馈驱动动作、枪声、枪口效果和弹道。
- 实测两套Prefab真实鞋底分别约为根节点上方0.249986m、0.249990m，而导入包围盒最低点约为-0.001615m、0.019843m。这是旧算法无法消除浮空的来源。
- 两模式均使用真实烘焙鞋底最低点修正视觉与命中体；在导航根附近探测当前地形/楼板，支持MeshCollider、BoxCollider等非Trigger表面，保留导航根和死亡动作。
- 战斗模式取消落枪后的距离/高度自动回架；XRI最终松手显式恢复动态刚体、重力和连续碰撞。VR输入帧同步实际XRI选择状态，按住Grip进入抓取范围也能让服务认可重新拾取，弹药不重置。P1/P2原有回架条件保持。

手工验收：

1. 模式三开场结束后接近敌人，观察队友转向、枪声/弹道与击杀计数；墙体遮挡和投雷时不能继续新射击。
2. 模式四开门后观察队友跟进与开火，清空建筑敌人后沿既有规则结算。
3. 检查敌我站立、行走和三层楼板上的鞋底，无原来的约25cm浮空；死亡倒地不被重新拉到站立高度。
4. 拿枪离开初始位置超过3.5m，松开后握把，确认双手释放且枪落地保留；走近后按住Grip拾起，握护木继续射击，弹数维持。
5. 暂停、失踪、重试及退出后，检查没有持续枪声/延迟伤害，重新开局枪械与队伍恢复。
