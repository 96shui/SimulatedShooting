# 准心柱原始调节恢复

后续用户已明确选择 [恢复c57823f](p1-sept25-restore.md)。本记录保留为历史验证，当前射击和调整记账以该次恢复报告为准。

- 准心柱短按每次1°，按0.064cm换算；长按恢复原来的匀速单度重复，不再加速。
- 移除垂直方向±50cm硬限制，支持按顺/逆时针多圈累计；不改变水平规则、默认补偿、方向、原始成绩和同轮应用幂等。
- 界面恢复“按住连续调节”。应用前可以继续调，应用后本轮按钮锁定，保持原流程。
- 保留上一轮已经验证的靶面坐标、实际弹孔与评分一致性修复。

先补测试再修改：修复前新增4个EditMode用例均失败，分别复现正负64cm建议补偿被拉回50cm，以及正反1600°累计被截断到±50cm。修复后运行规则/服务与真实场景/UI回归；结果见 [本次验证数据](evidence/p1-two-axis-zeroing/front-sight-restore-validation.json)。
