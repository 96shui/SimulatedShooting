# 2026-10-23 模式一仍难命中：桌面精瞄输入整改

2026-10-23 已被用户澄清取代：问题发生于VR，本文件的桌面控制修改已撤回，不构成VR验收；以BDD33及接口25为准。

对应用户“模式一打不准还是”，BDD32、接口24、P1功能B task005/013。未改动原100m靶排、靶子大小、十环、服务偏移和评级。

## 确认的问题

之前的物理命中测试会按目标计算并直接摆正枪体，能证明枪线和弹着一致，无法证明玩家实际输入能细调。本轮改为通过输入适配层、握持命令和控制器姿态更新验证。

- 无VR ADS进入后忽略全部TurnAxis，鼠标或方向轴不改变实际枪线。修复前小幅鼠标测试位移为0。
- WASD前手位移0.28m/s，握距约0.326m；100m靶场下，60fps一帧的实测落点变化141.985cm，30fps为283.970cm，远大于胸靶和十环。
- 控制器先移动姿态、后处理本帧ADS状态；刚进入机瞄的一帧仍使用粗调速度，回归中实测跳动75.830cm。

## 修改

- 无VR ADS继续响应鼠标/方向轴，角速度上限1.2度/秒；WASD前手微调速度乘0.005。30/60fps单帧小于2cm，释放输入后保持稳定。
- 同帧先处理握持和ADS状态，再更新枪体与观察姿态、取样击发，防止切入ADS时跳动。
- 非ADS保留原粗调速度；VR分支仍提前返回，不改变HMD姿态、FOV、真实握持或自然枪线。不引入靶心吸附。
- 两模式共享同一桌面控制器，P2仅继承相同精瞄输入；未改其命中规则、两发机制和场景。

## 验证

- 修复前后结果保存在[evidence/p1-precision-input-20261023](evidence/p1-precision-input-20261023)。三个精瞄回归及切入ADS时序回归均先复现失败。
- 实际桌面输入两轮：通过Grip输入取得双手状态、方向轴瞄准、Trigger击发、物理采样、三发结算、应用建议、继续下一轮，再瞄准击发三次。第二轮三发全部进入十环；全过程不直接摆正枪体Transform或注入命中坐标。
- 首轮扩展物理/射校/输入测试20项通过；最终相关PlayMode **90/90通过**，包含精瞄输入、切入ADS时序、实际输入两轮射校、原物理弹着/补偿、握持/VR跟踪隔离、模式二路线/两发、P1流程和分析UI。没有重跑与本次修改无关的整个项目测试。
- 这是已确认的桌面输入问题修复。用户尚未确认使用桌面还是VR；未把桌面输入测试宣称为VR实机问题已解决。VR握持、跟踪/HMD隔离通过替身回归检查，实际头显下的机瞄手感仍待用户复测。

桌面复测：拿枪并支撑，按住右键/Shift进入机瞄，使用鼠标调整方向、WASD微调，再击发；保留原射校偏移，首轮仍需按弹着分析应用补偿后进入下一轮。
