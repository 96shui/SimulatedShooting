# 37 各模式操作介绍

阶段：P1/P2/P3 共用 UI。2026-11-16，关联 BDD02、接口01、P1/UI task008、P2/UI task002、P3/UI task002。覆盖历史主菜单总览入口，保持各模式原有训练流程。

```gherkin
# language: zh-CN
功能: 进入训练前阅读对应模式的操作说明

  场景大纲: 四个入口打开各自介绍且不提前启动训练
    假如当前路由为 MainMenu 且没有训练会话
    当点击 <入口>
    那么只显示 <模式> 的操作介绍，标题为 <标题>
    而且有“按键操作”“界面与按钮”两栏以及“返回”“进入训练”两个按钮
    而且路由、训练会话及战斗模式快照保持原值
    当点击“返回”
    那么关闭介绍回到主菜单，不发送服务命令，不改变路由历史或会话
    而且多次重复打开及返回均可正常使用
    当再次点击该入口并点击“进入训练”
    那么仅调用一次该入口原有处理并到达 <原页面>
    而且保留后续设置、简报、侦察、战斗与结算流程

    例子:
      | 入口 | 模式 | 标题 | 原页面 |
      | 01 | 模式一 | 模式一 · 100m 精度射校 | ZeroingBriefing |
      | 02 | 模式二 | 模式二 · 移动目标射击 | MovingTargetSettings |
      | 03 | 模式三 | 模式三 · 堑壕射击 | TrenchMapSelection |
      | 04 | 模式四 | 模式四 · 城镇攻防 | UrbanMapSelection |

  场景: 每页独立说明完整操作
    那么四页均完整说明右手侧握键抓枪、左手侧握键辅助抓握与右扳机射击
    而且模式一说明固定射击位、单发、每轮4发共3轮、自动分析、水平方向5°、垂直方向1cm、应用调整立即判定、下一轮作废本轮、最终评级、蓝点当前补偿和分散禁用调整
    而且模式二说明固定射击位、快速扣动两发与保持逐发连射、速度档位、跟随射击、等待射击、弹药命中用时和结算重训返回
    而且模式三、四各自完整说明X换弹、Y姿态、B换肩、左肩左手主手与左扳机、A请求队友手雷、左摇杆移动、右摇杆转向
    而且模式三说明任务阶段剩余目标、30发及备用4匣、拐角射击、交互提示、地图简报侦察和结算评级
    而且模式四说明右摇杆按压开门交互、楼层房间与进度、开门检查房间、街道楼层入口、队友推进投雷与避免挡枪线、结算评级
    而且全中文，不使用“同模式一”等跨页省略；仅保留键位字母与数值单位

  场景: 正文自适应并可滚动且不阻断按钮
    那么面板沿用旧“操作介绍”页的AddPanel参数：深色底(11,19,16,245)、边线(45,66,56)，保留panel_holo_large原色九宫格贴图的蓝色发光外框与内部深色科技网格，不清空贴图、不额外染色、不添加Outline
    而且保持38号居中标题、26号正文、lineSpacing为10、两栏间距60与底部双按钮；“进入训练”使用button_primary_orange黄色高亮，“返回”保留button_secondary_cyan
    而且面板位于(130,120)至(1790,960)，正文使用竖直ScrollRect，关闭横向滚动
    而且面板尺寸为1660×840，标题位于(80,750)至(1580,820)，滚动区位于(75,150)至(1585,720)，返回位于(460,35)至(760,105)，进入训练位于(900,35)至(1200,105)
    而且内容按两栏文本首选高度自适应，常规字号下1920×1080、1280×720与2560×1440均一屏完整显示
    当字号增大使正文超出时
    那么可竖直滚动到最后一行，无文字截断、重叠或压住按钮
    而且两个按钮均位于滚动区外，可通过普通与XR指针点击
```
