# 25 P3 城镇阶段与检查

task010，补充BDD18/19/20/21；契约见接口17。

```gherkin
# language: zh-CN
功能: 城镇服务闭环
  场景: 种子与归属
    当使用相同种子及合法三层房间配置开始
    那么街道1到2人、建筑3到6人的位置与归属可复现
    而且未知地图、非法房间数与无效候选不能创建会话

  场景: 带风险进入并返回
    当玩家在入口范围内且街道仍有敌人
    那么允许进入建筑并显示风险，不重建Session
    当经同入口返回街道
    那么弹药、击杀与房间状态保留
    而且范围外不能进入或退出

  场景: 房门与检查的独立门禁
    当玩家在门口开门
    那么房间进入搜索中但不等于已搜索
    当玩家在检查区且房间无活敌
    那么确认检查才记为已搜索，空房也必须开门
    而且重复开门和检查不增加计数，Later观察不执行

  场景: 全部条件和死亡优先
    假如只完成检查、只清敌或街道仍有残敌
    那么不能胜利
    当全部敌人清除且全部房间检查且玩家存活
    那么只发布一次胜利与三层结果地图
    当同批次玩家也受到致命伤害
    那么失败优先并保留部分/该批统计

  场景: 重试和一致快照
    当结束后取消并重新开始
    那么使用新会话，重置房门房间和战斗数据，旧结果保持不变
    而且HUD、楼层、门视觉、任务及结果由同一服务快照提供
```
