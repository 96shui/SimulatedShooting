# 30 P1/P2视觉距离与射校命中修复

2026-10-22 用户最新修订，优先于回退记录及冲突的旧条款；P3保持现状。接口22；沿用P1玩法task006/013、UI task010、场景task012，P2玩法task007与场景task006。

```gherkin
# language: zh-CN
功能: 更近的现有靶标和一致的命中反馈
  场景: 缩短视觉距离不增加场景物体
    当更新模式一和模式二场景
    那么仅移动现有靶标和路线到玩家前方25米和50米
    而且不新增靶标、辅助环、遮挡物或改变HMD跟踪
    而且保留50厘米胸靶、10厘米直径十环、原始偏移、三发一轮和评级规则
    而且模式二路线仍长40米，速度、两发起射和禁射规则不变

  场景: 模式一实际应用补偿
    假如第一轮三发同一枪线且未通过
    当应用建议并进入下一轮
    那么同一枪线的新弹着扣除上一轮平均偏差且可归零
    而且重复应用不叠加，历史弹着不变
    而且弹孔、曳光、HUD、分析和评级使用同发补偿后弹着

  场景: 帮助显示应调多少
    假如本轮三发平均偏左8厘米偏上12厘米
    当打开帮助并手动改变待应用补偿
    那么帮助仍建议觇孔向前4格和准心柱顺时针188度
    而且调节控件和蓝色预览单独显示当前待应用量
    而且切换下一轮后帮助由新一轮弹着重新生成

  场景: 两模式瞄准线与枪口命中一致
    当用真实步枪瞄准线对准现有靶心或移动靶路线任意位置
    那么枪口射线经过该瞄准线在当前靶面上的交点
    而且射线忽略自身武器和交互Trigger但保留真实环境遮挡
    而且模式二逐发使用最新枪线与移动靶Collider记录命中

  场景: 脱靶不误判
    当枪线经过靶边或靶外
    那么均使用同一靶心原点和厘米单位
    当背向靶面、平行靶面或被前方环境遮挡
    那么消耗弹药并记录未命中，不生成靶心弹孔且不得判十环
```
