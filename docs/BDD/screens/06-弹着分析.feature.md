## Unity 验收点

- 偏差算法应独立成可单元测试服务：垂直 23cm 一周，0.064cm 约等于 1°；水平一格 2cm 并向上取整。
- `应用调整` 需要幂等，避免玩家多次点击造成调整量重复累加。
- P1 EditMode Test 必须覆盖偏差计算、调整方向、调整量取整和重复应用幂等。
- 手动调节按靶面坐标计量：X 正向为右、Y 正向为上；单次按钮操作 1cm，补偿每轴限制在 ±50cm。调整后预览只使用 DTO，不修改本轮历史弹着。
- PlayMode Test 必须覆盖分析 UI 自动出现、下一轮自动隐藏以及固定射击点不变化。
