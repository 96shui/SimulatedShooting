# 06 弹着分析

阶段：P1。来源：draw.io 页面 `p06`；本契约于 2026-11-11 更新，仅影响模式一。
## 2026-11-10 帮助与答案互斥（优先于下文独立展开的旧条款）

场景: 初始收起
  假如进入弹着分析页
  那么帮助和答案按钮同时可见，帮助正文、准心柱/觇孔提示行和答案面板隐藏，坐标文本可见。
场景: 展开和收起帮助
  当点击帮助
  那么帮助正文和准心柱/觇孔提示行显示，坐标文本隐藏，帮助按钮显示“收起帮助”，答案按钮及答案面板隐藏。
  当再次点击“收起帮助”
  那么回到初始收起态，帮助和答案按钮同时可见。
场景: 展开和收起答案
  当点击答案
  那么答案面板显示，帮助按钮和帮助正文隐藏，坐标文本仍可见。
  当再次点击答案
  那么回到初始收起态，帮助和答案按钮同时可见。
场景: 轮次和页面切换后重置
  当切换轮次、重新进入分析页或离开分析页
  那么帮助和答案均恢复收起，两个按钮的自身可见状态恢复，坐标文本恢复；页面再次显示时不遗留上一轮展开状态。
  而且两个按钮以及答案面板的位置和尺寸保持不变，隐藏时不重新排布其余控件。

## 2026-11-09 瞄具基准与答案（优先于冲突旧条款）

场景: 新建模式一会话时瞄具基准为觇孔向前1格、准心柱顺时针5度；两轴读数是有符号的机械位置，同向相加、反向相减，可跨零。基准仅影响读数，固定弹着偏移、实际弹着和调整后偏移≤5cm通过判定不因此改变。

场景: 点击帮助右侧的答案按钮；答案默认收起，与帮助按上述三态互斥；原有帮助、调整及继续按钮位置和门禁不变。答案展示本局当前固定偏移、按待应用补偿反推的觇孔与准心柱方向和量（2cm/格，0.064cm/度，采用服务现有5度量化），以及应用后固定偏移模长与≤5cm是否立即通过，并说明第1/2/3轮通过为优秀/良好/及格。待应用量经手动调整或应用后立即刷新；已应用时不得再次加上同一补偿，离开或进入下一轮自动收起，重新打开读取当前轮数据。服务仍按既有条件和流程评定最终结果。

## 2026-11-09 四象限随机与调整后通过（优先于历史冲突）
场景: 本局初始偏移
  当每次从菜单或场景默认入口开始模式一
  那么种子来自非固定来源；测试仍可注入固定种子并复现
  而且 X、Y 独立取随机符号与绝对值 5–20cm（含端点），四象限等概率
  而且现有 ±25cm 靶面夹取不变，中心瞄准时 ±20cm 产生靶内弹着与标记。
场景: 应用调整立即通过
  假如本轮完成三发且未因全部十环直接结算
  当应用量化调整后固定偏移 FixedImpactOffsetCm 的模长 ≤5cm
  那么本轮 PassedTenRing 和 FinalResultAvailable 立即为真，主按钮显示“查看评级”，无需再射击
  而且本轮原始弹着记录不变，判定不取决于平均点或玩家实际弹着。
  而且分析页在应用前说明偏移门槛，应用后显示通过或未通过状态。
场景: 调整后未通过
  当已应用调整后的固定偏移模长大于5cm
  那么仍按既有三轮流程继续；三发全部进入十环仍独立通过，5cm 边界包含等号。
2026-10-31 用户最新修订：模式一初始固定弹道偏差的水平、垂直分量各自取 -20～-5cm 或 5～20cm，包含端点并排除 (-5, 5)；固定种子可复现，后续手动校正不受此初始范围约束。

2026-10-31 用户修订：P1/P2命中射线从枪械瞄准线起点沿瞄准方向检测，枪口仍作为枪口火光和曳光起点；环境遮挡与P2逐发目标判定保持生效，P1弹着和UI沿用同一记录。

2026-10-31 用户修订：模式一觇孔建议、待应用调整和方向按钮均以整数格显示，每格仍为2cm；初始固定弹道偏移每轴位于 -20cm 至 20cm，保留既有随机分布和手动调节规则。

## 2026-10-30 命中坐标和靶面弹着修订

模式一依据枪械瞄准线与靶平面的真实交点，加当前射校固定偏移及已应用的机械补偿来计算落点，不压缩瞄准误差或限制到靶内。枪线被实体遮挡、无正向交点时记未命中，不显示靶面弹着；有效投影在靶面外也不会被判为十环或生成靶面标记。靶面内的最终坐标与弹孔、弹道、分析和评级一致，弹孔朝向靶面并放在靶面前方，避免被胸靶贴图或深度精度遮住。

## 2026-10-30 调整量显示修订

调整控件的觇孔方向按钮分别标明每次2cm，准心柱方向按钮分别标明每次5°；两组按钮之间显示服务DTO的当前待应用调整量和方向，觇孔以cm、准心柱以整数°显示，包括零值。建议区显示本轮建议的方向及大小，觇孔使用cm，准心柱使用°。手动调整只改变待应用量，建议仍来自本轮平均弹着数据；应用后禁用调整按钮。数值转换与已有2cm/格、0.064cm/度契约一致。

## 功能

作为玩家，我希望每轮射击后看到垂直和水平偏差，并根据提示应用准星柱和觇孔调整。

```gherkin
# language: zh-CN
功能: 100m 射校弹着分析
  背景:
    假如本轮记录了 4 发射击
    那么打开分析页，物理训练靶的弹孔立即清除，分析图继续使用服务记录

  场景: 构造计算集
    假如有效弹着未 MissedTargetPlane 且 |x|、|y| 均不大于 25cm
    当 4 发都有效
    那么先求四发均值，舍弃距离该均值最远的一发；并列时舍弃最早一发
    而且剩余三发构成计算集，重新求均值作为黄点
    当恰有 3 发有效
    那么这三发直接构成计算集，没有舍弃弹
    当有效弹着不足 3 发
    那么本轮分散，不产生有效计算集

  场景: 严格的集中门槛
    假如存在三发计算集
    当每发距黄点均小于 10cm 且每对弹着间距均小于 15cm
    那么本轮集中，否则分散；10cm 和 15cm 边界均不通过

  场景: 分散处置
    假如本轮分散
    那么显示“弹着点过于分散，本次射击无参考价值，不可用于调整，请进行下一轮。”
    而且四个调整按钮和应用调整按钮禁用并置灰，建议与答案按钮隐藏
    而且服务拒绝手动调整和应用调整并返回 InvalidState
    而且无需补射，前两轮只可进入下一轮，第 3 轮可查看评级

  场景: 显示四发及补偿
    那么靶图显示四发全部记录；无法投影或位于靶面外的发次在靶图旁的脱靶区逐发标记，不伪造靶内坐标
    而且脱靶发次在坐标记录中明确列出
    而且四发均正常显示，不对被舍弃的一发做额外标注或视觉区分
    而且黄点为计算集三发的平均，蓝点为待应用补偿本身，初始在靶心
    而且蓝点不参与任何通过判定；PreviewAverageOffsetCm 可保留为黄点加待应用补偿

  场景: 手动量化调整
    假如本轮集中、未通过且未应用调整
    当点击觇孔向前或向后
    那么待应用 X 分别加或减 2cm，限幅 ±50cm
    当点击准心柱顺时针或逆时针
    那么待应用 Y 分别加或减 0.32cm，限幅 ±49.92cm
    而且偏左建议向前，偏右建议向后；偏上建议逆时针，偏下建议顺时针
    而且有符号机械位置正数仍代表向前或顺时针
    而且按钮名称、位置和 ID 保持不变，长按连续步进，松开、移出、禁用或关页停止

  场景: 四发完成即判的通过路径
    假如集中规则成立
    当计算集每发距靶心≤10cm、黄点距靶心≤5cm、至少一发距靶心≤5cm
    那么本轮立即通过，按钮显示“查看评级”

  场景: 应用调整后当场通过
    假如集中规则成立且本轮未通过
    当应用本轮实际补偿后 |黄点 + 本轮实际应用补偿| < 5cm
    那么本轮立即通过，可查看评级；等于 5cm 不通过
    而且重复应用幂等，固定偏移只累加一次，未通过时可进入下一轮

  场景: 帮助与答案互斥
    假如本轮集中
    那么帮助与答案初始收起且两按钮可见；打开帮助时隐藏答案按钮，打开答案时隐藏帮助按钮，再点击已打开按钮收起
    而且帮助正文和答案面板互斥，收起时坐标文本可见；离开页面或进入下一轮重置
    而且建议使用计算集均值，待应用补偿初始为零，答案显示当前量和服务提供的数值判定，不以固定偏移模长判通过；最终缩略图蓝点也表示当前补偿量
```

胸靶图与场景使用相同半身胸靶、靶心和厘米坐标；弹着、黄点与蓝点独立于纹理绘制，不因透明区域或缩放发生镜像和位移。实时射击、曳光和场景弹孔使用同一服务记录的落点。

验收：EditMode 覆盖筛选、并列顺序、严格边界、两种通过路径、补偿量化、拒绝与幂等；PlayMode 覆盖四点无额外标注、脱靶标签、分散 UI、方向及物理靶清除。无 VR 输入替身可运行，VR 实机检查布局可读性、按钮交互和长按。
