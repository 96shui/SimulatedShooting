# 06 弹着分析

阶段：P1。来源：draw.io 页面 `p06`；本契约于 2026-11-11 更新，仅影响模式一。

```gherkin
# language: zh-CN
功能: 100m 射校弹着分析
  背景:
    假如本轮记录了 4 发射击
    那么打开分析页，物理训练靶的弹孔立即清除，分析图继续使用服务记录

  场景: 构造计算集
    假如有效弹着未 MissedTargetPlane 且 |x|、|y| 均不大于 25cm
    当 4 发都有效
    那么先求四发均值，舍弃距离该均值最远的一发；并列时舍弃最早一发
    而且剩余三发构成计算集，重新求均值作为黄点
    当恰有 3 发有效
    那么这三发直接构成计算集，没有舍弃弹
    当有效弹着不足 3 发
    那么本轮分散，不产生有效计算集

  场景: 严格的集中门槛
    假如存在三发计算集
    当每发距黄点均小于 10cm 且每对弹着间距均小于 15cm
    那么本轮集中，否则分散；10cm 和 15cm 边界均不通过

  场景: 分散处置
    假如本轮分散
    那么显示“弹着点过于分散，本次射击无参考价值，不可用于调整，请进行下一轮。”
    而且四个调整按钮和应用调整按钮禁用并置灰，建议与答案按钮隐藏
    而且服务拒绝手动调整和应用调整并返回 InvalidState
    而且无需补射，前两轮只可进入下一轮，第 3 轮可查看评级

  场景: 显示四发及补偿
    那么靶图显示四发全部记录；无法投影或位于靶面外的发次在靶图旁的脱靶区逐发标记，不伪造靶内坐标
    而且脱靶发次在坐标记录中明确列出
    而且四发均正常显示，不对被舍弃的一发做额外标注或视觉区分
    而且黄点为计算集三发的平均，蓝点为待应用补偿本身，初始在靶心
    而且蓝点不参与任何通过判定；PreviewAverageOffsetCm 可保留为黄点加待应用补偿

  场景: 手动量化调整
    假如本轮集中、未通过且未应用调整
    当点击觇孔向前或向后
    那么待应用 X 分别加或减 2cm，限幅 ±50cm
    当点击准心柱顺时针或逆时针
    那么待应用 Y 分别加或减 0.32cm，限幅 ±49.92cm
    而且偏左建议向前，偏右建议向后；偏上建议逆时针，偏下建议顺时针
    而且有符号机械位置正数仍代表向前或顺时针
    而且按钮名称、位置和 ID 保持不变，长按连续步进，松开、移出、禁用或关页停止

  场景: 四发完成即判的通过路径
    假如集中规则成立
    当计算集每发距靶心≤10cm、黄点距靶心≤5cm、至少一发距靶心≤5cm
    那么本轮立即通过，按钮显示“查看评级”

  场景: 应用调整后当场通过
    假如集中规则成立且本轮未通过
    当应用本轮实际补偿后 |黄点 + 本轮实际应用补偿| < 5cm
    那么本轮立即通过，可查看评级；等于 5cm 不通过
    而且重复应用幂等，固定偏移只累加一次，未通过时可进入下一轮

  场景: 帮助与答案互斥
    假如本轮集中
    那么帮助与答案初始收起且两按钮可见；打开帮助时隐藏答案按钮，打开答案时隐藏帮助按钮，再点击已打开按钮收起
    而且帮助正文和答案面板互斥，收起时坐标文本可见；离开页面或进入下一轮重置
    而且建议使用计算集均值，待应用补偿初始为零，答案显示当前量和服务提供的数值判定，不以固定偏移模长判通过；最终缩略图蓝点也表示当前补偿量
```

胸靶图与场景使用相同半身胸靶、靶心和厘米坐标；弹着、黄点与蓝点独立于纹理绘制，不因透明区域或缩放发生镜像和位移。实时射击、曳光和场景弹孔使用同一服务记录的落点。

验收：EditMode 覆盖筛选、并列顺序、严格边界、两种通过路径、补偿量化、拒绝与幂等；PlayMode 覆盖四点无额外标注、脱靶标签、分散 UI、方向及物理靶清除。无 VR 输入替身可运行，VR 实机检查布局可读性、按钮交互和长按。
