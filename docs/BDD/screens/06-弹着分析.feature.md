# 06 弹着分析

来源：draw.io 页面 `p06 06 弹着分析`

阶段：P1；P2 按 `00-P1P2卧姿固定射击交互.feature.md` 改造轮间 UI 显隐。

## 功能

作为玩家，我希望每轮射击后看到垂直和水平偏差，并根据提示应用准星柱和觇孔调整。

```gherkin
# language: zh-CN
功能: 本轮弹着分析

  背景:
    假如玩家完成 100m 射校的一轮 3 发射击
    那么系统应打开本轮弹着分析弹窗
    而且弹窗应显示在卧姿玩家正前方
    而且有效射击应被禁用

  场景: 显示本轮弹着点和偏差数据
    当弹着分析界面加载完成
    那么左侧应显示与场景实际射击靶一致的半身胸靶示意及 50cm×50cm 命中坐标区域
    而且胸靶上应显示本轮 3 个弹着点
    而且右侧应显示垂直偏差和水平偏差
    而且右侧应显示准星柱调整方向和角度
    而且右侧应显示觇孔调整方向和格数
    而且面板应显示 3 发水平、垂直坐标分别求平均后的弹着中心
    而且应显示待应用补偿后的弹着中心预览

  场景: 半身胸靶与场景一致
    当本轮弹着分析界面加载完成
    那么靶图应使用场景胸靶相同的半身轮廓、靶心位置和配色
    而且不得以纯同心圆环形靶替代半身胸靶
    而且10环和3个弹着点应按服务厘米坐标对齐
    而且平均点及补偿预览不得因换图发生镜像、翻转或比例变化

    当玩家点击水平向左或向右、垂直向下或向上按钮

    假如玩家已在面板上设置水平和垂直补偿
    当玩家点击“应用调整”并进入下一轮

    而且下一轮同样的瞄准输入应按所应用的补偿改变弹着点
    而且调整应用后四个调节按钮应不可操作
    而且未手动调节时默认补偿应将本轮平均弹着中心移至靶心

  场景大纲: 根据垂直偏差给出准星柱调整方向
    假如本轮弹着中心相对靶心“<偏差方向>”
    当系统计算准星柱建议
    那么界面应提示“<调整建议>”

    例子:
      | 偏差方向 | 调整建议 |
      | 偏上 | 准星柱逆时针调整 X° |
      | 偏下 | 准星柱顺时针调整 X° |

  场景大纲: 根据水平偏差给出觇孔调整方向
    假如本轮弹着中心相对靶心“<偏差方向>”
    当系统计算觇孔建议
    那么界面应提示“<调整建议>”

    例子:
      | 偏差方向 | 调整建议 |
      | 偏左 | 觇孔向前调整 X 格 |
      | 偏右 | 觇孔向后调整 X 格 |

  场景: 应用调整后更新归零状态
    当玩家点击“应用调整”
    那么系统应把本轮建议应用到武器归零状态
    而且界面应标记调整已应用
    而且重复点击不应重复叠加同一次调整

  场景: 进入下一轮
    假如本轮调整已应用
    而且当前轮次不是第 3 轮
    而且本轮未满足 3 发全部进入 10 环
    当玩家点击“进入下一轮”
    那么系统应回到“100m射击HUD”
    而且轮次应增加 1
    而且本轮弹数应重置为 3/3
    而且弹着分析 UI 应自动隐藏
    而且玩家应留在同一卧姿固定射击点

  场景: 从弹着分析返回主菜单
    当玩家点击“返回主菜单”
    那么系统应返回“游戏主界面”
    而且不应继续进入下一轮

  场景: 应用调整后进入下一步

    而且最终评级应由射校服务计算
    假如本轮未通过且仍有剩余轮次
    当玩家继续
    那么系统应回到“100m射击HUD”并进入下一轮

  场景: 第三轮后不再显示进入下一轮

    而且本轮调整已应用

    当玩家点击“查看评级”

    而且独立的“返回主菜单”按钮仍可直接返回“游戏主界面”
```

## Unity 验收点

- 偏差算法应独立成可单元测试服务：垂直 23cm 一周，0.064cm 约等于 1°；水平一格 2cm 并向上取整。
- `应用调整` 需要幂等，避免玩家多次点击造成调整量重复累加。
- P1 EditMode Test 必须覆盖偏差计算、调整方向、调整量取整和重复应用幂等。
- 手动调节按靶面坐标计量：X 正向为右、Y 正向为上；单次按钮操作 1cm，补偿每轴限制在 ±50cm。调整后预览只使用 DTO，不修改本轮历史弹着。
- PlayMode Test 必须覆盖分析 UI 自动出现、下一轮自动隐藏以及固定射击点不变化。


## 2026-10-04 参考图与出生修订

模式一场景、弹着分析和最终结算共用用户提供的绿色胸靶原图（ChestTargetReference.jpg），保留环线及 6–10 数字。白色10环圆心为厘米坐标零点，按原图白圈直径202像素校准为10cm；命中范围继续为以靶心为中心的50cm正方形，评级规则不变。禁止独立手绘UI轮廓。场景原几何轮廓隐藏，共享平面贴图替代。

模式三出生先按实际 Terrain/可站立场景表面求脚底高度，若胶囊与堑壕几何重叠则选邻近无遮挡位置；VR保留真实头部跟踪。开场面板缩小并按当前地面高度放置。无人机模型支持绑定外部Prefab，不变更侦察规则。

本次按用户要求不运行测试，需VR实机核对出生视野、面板完整性以及胸靶与弹着位置。

## 2026-10-05 终局直接评级（覆盖终局必须应用调整的旧要求）
本轮完成3发后，若全部进入10环，或第3轮仍未通过，直接显示最终评级，不再进入弹着调整界面。只有未通过且轮次少于3的情况才显示弹着分析并要求应用补偿后继续。终局不能通过补偿改变本轮原始成绩。

2026-10-05 补偿一致性修复：原始瞄准位置统一按射线与所绑定靶面平面的交点换算为厘米（含脱靶），服务只叠加一次同局固定偏移与已应用补偿。场景弹孔和弹道终点使用ZeroingShotRecordedEvent.ImpactPointCm；场景与UI不得各画未补偿与已补偿两套弹着。相同瞄准经默认补偿后，下一轮弹着中心应与预览一致。

## 2026-10-05 修订：机械调节与点击帮助（覆盖旧厘米按钮、偏差文本要求）

- 分析页不显示垂直/水平厘米偏差和自动说明；显示觇孔前后格数、准心柱顺逆时针角度，调节按钮分别为一格（2cm）和一度（0.064cm）。服务内部厘米坐标、弹着记录和应用补偿流程保留。
- 觇孔向前使弹着向右，向后使弹着向左；准心柱顺时针使弹着向下，逆时针使弹着向上。准心柱建议方向同步按此规则显示。
- “帮助”默认收起，点击显示：弹着点偏左时觇孔向前调整，弹着点偏右时觇孔向后调整，100m射击距离时觇孔调整一格为两厘米。弹着点偏上时顺时针调整准心柱，弹着点偏下时逆时针调整准心柱，100m射击距离时准心柱调整一圈约为23厘米，调整1度约0.064厘米。
- 最终评级三个靶图按 RoundIndex 分别显示各轮 Shots 原始弹着点，提前通过后未射击的轮次不显示点。标记不得因靶图透明区域采样而不可见，坐标只换算一次。
- 本次按用户要求不运行自动测试；更新回归断言并在编辑器检查编译、靶图渲染和帮助开关。VR实机需确认手柄点击帮助和调节按钮。
