# 11 移动靶结算

来源：draw.io 页面 `p11 11 移动靶结算`

阶段：P2。

## 功能

作为玩家，我希望移动目标训练结束后看到命中数量、弹药消耗、射击序列、逐发路线命中时间点和评级。

```gherkin
# language: zh-CN
功能: 移动目标射击训练结算

  背景:
    假如移动目标射击训练已经结束
    那么系统应显示“移动目标射击 训练结算”
    而且结算 UI 应自动显示在卧姿玩家正前方
    而且有效射击应被禁用

  场景大纲: 根据命中发数显示评级
    假如本局命中发数为 <命中数>
    当系统计算移动靶评级
    那么界面应显示评级“<评级>”

    例子:
      | 命中数 | 评级 |
      | 0 | 不及格 |
      | 2 | 不及格 |
      | 3 | 及格 |
      | 4 | 良好 |
      | 5 | 优秀 |
      | 8 | 优秀 |

  场景: 显示训练摘要
    当结算界面加载完成
    那么界面应显示命中数
    而且应显示实际消耗弹药发数
    而且应显示目标速度
    而且应显示评级规则

  场景: 显示射击序列和逐发记录
    当结算界面加载完成
    那么界面应按实际扣动次数显示射击序列记录
    而且每个序列应标明快速两发或长按连射、实际射击发数和命中发数
    而且每发记录应标明命中或未命中
    而且路线命中时间点应与逐发记录一致

  场景: 重新训练
    当玩家点击“重新训练”
    那么系统应清空本次移动靶 Session
    而且返回移动靶设置界面并保留上次速度选择

  场景: 返回模式选择
    当玩家点击“返回模式选择”
    那么系统应返回训练模式选择界面
```

## Unity 验收点

- 结算页所有数值来自 `MovingTargetSession`，不能使用静态示例文本。
- 路线命中时间点建议保存为可序列化记录，便于回放和测试。

## 2026-10-16：结算帮助（P2 UI task005）

```gherkin
  场景: 点击帮助查看移动射击方法
    假如玩家进入模式二结算界面
    那么“帮助”默认收起，射击记录正常显示
    当玩家点击“帮助”
    那么记录区域显示以下完整文字，按钮变为“收起帮助”
      """
      移动射击的方法通常有两种。
      一是跟随射击，移动武器追随目标进行射击。
      二是等待射击，预判目标的移动轨迹在它的运动方向上等待经过进行射击。
      由于物体的运动我们需要瞄准目标的前侧才能保证命中，在一百米视距上，大约在20-30cm半个靶子的身位。
      """
    而且训练摘要、返回和重新训练按钮仍可见
    当再次点击“收起帮助”
    那么恢复射击记录和滚动提示
    而且重复刷新结算 DTO 不改变帮助展开状态
    当离开结算界面后重新进入结算
    那么帮助恢复收起状态
```
