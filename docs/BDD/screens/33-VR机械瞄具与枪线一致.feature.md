# 33 VR机械瞄具与枪线一致

2026-10-23 用户明确反馈的是VR游戏。BDD32桌面输入不构成此问题的整改或验收；撤回该轮桌面控制逻辑修改。本次沿用BDD05/30/31、接口06/22/23与P1功能B task013、场景task012。

```gherkin
# language: zh-CN
功能: 在头显中通过可见机械瞄具射校
  场景: 可见觇孔和准星决定真实枪线
    假如训练步枪使用现有QBZ191模型
    当玩家通过可见觇孔中心与准星柱顶瞄准100米靶心
    那么有效瞄准线应与模型上的两点连线一致
    而且不能用一个位置和朝向均未校准的旧锚点代替
    而且HMD位置、双目跟踪和FOV不因瞄准而改变

  场景: 实际双手选择与扳机能完成两轮射校
    当跟踪替身通过XRInteractionManager选择真实步枪的前后握把
    而且仅移动双手跟踪姿态使可见瞄具指向靶心并扣动扳机
    那么靶面采样与可见瞄具的交点误差应小于1厘米
    而且应用首轮建议后第二轮三发可进入十环
    而且不能逐发直接摆正枪体Transform或注入命中坐标

  场景: 头部移动不能代替枪体瞄准
    假如双手稳定持枪且后坐已回正
    当头部独立移动或转动
    那么只改变观察位置而不改变冻结的枪线和弹着
    而且放开支撑手仍禁止有效射击
```
