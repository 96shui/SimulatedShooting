# 29 训练辅助与镜像左肩持枪

```gherkin
# language: zh-CN
功能: 更易瞄准的训练和镜像左肩
  场景大纲: 实际距离与显示一致
    当玩家进入<模式>开始训练
    那么实际射击距离应为<距离>米
    而且VR和无VR出生点及正前方枪架/UI同步，仍禁止人工移动
    例子:
      | 模式 | 距离 |
      | 模式一 | 25 |
      | 模式二 | 50 |

  场景: 模式一更小初始偏移和更大十环
    当使用固定种子启动模式一
    那么初始偏移半径应在3至8厘米且同种子复现
    而且距中心10厘米计入十环，超过10厘米不计入
    而且场景和UI均显示20厘米直径的同一判定范围

  场景: 调整每次一格且真实影响下一轮
    假如模式一未通过的一轮三发结束
    当点击一次水平前调
    那么待应用水平补偿增加1格即2厘米，垂直不变
    而且展开帮助的方向、角度与格数应和当前待应用补偿一致，不保留过时的原始均值建议
    当应用调整并用相同枪线进入下一轮
    那么服务、实际弹孔及曳光终点按预览改变同样的厘米量
    而且重复应用不叠加，本轮历史点不改变

  场景: 靶外坐标不跳变和吸附
    当枪线连续穿过靶心、靶边和靶外
    那么始终使用同一靶平面厘米坐标及同发服务补偿结果
    而且不能因物理Collider变化切换单位或把靶外点改成十环

  场景: 模式三恰好多承受五枪
    当模式三玩家连续承受每次1点的十次敌人命中
    那么初始生命/最大生命10，第五枪后5，第九枪后1且存活，第十枪死亡
    而且重试恢复10，模式四仍5，显式配置保持调用者参数

  场景大纲: B键切换扳机手且不自动击发
    假如玩家在<模式>右肩双手持枪
    当右B按下一次并保持
    那么仅切到左肩一次，左手后握把扣扳机，右手支撑
    而且右扳机不能击发，左扳机释放后重新按下可击发
    当B释放后再次按下
    那么恢复右肩角色，切换不额外发射或扣弹
    例子:
      | 模式 |
      | 模式一 |
      | 模式二 |
      | 模式三 |
      | 模式四 |

  场景: 手臂手指严格镜像并可还原
    假如保存了完整右肩枪械握把和双手手臂指骨姿态
    当切到左肩
    那么左右角色交换后的各位置和旋转应为纵向中面的严格镜像
    而且再切回右肩恢复原姿态，HMD/控制器跟踪不被改写

  场景: 左肩换弹和双手门禁
    假如左肩持枪
    当换弹或支撑手释放/丢失跟踪
    那么右支撑手执行换弹或退出支撑，禁止有效射击
    而且完成/取消后恢复对应控制器和握持入口
```
