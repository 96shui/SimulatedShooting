```gherkin
  场景大纲: 持枪与凝视不显示蓝线标签
    假如进入“<模式>”并有效持枪
    当悬停步枪并凝视场景指引超过原延时
    那么枪上的世界空间取枪提示始终隐藏

    而且HUD面板据枪、调整、禁射等提示仍正常显示
    而且准心、弹道、命中反馈和战斗血条保持原行为
    例子:
      | 模式 |
      | 模式一 |
      | 模式二 |
      | 模式三 |
      | 模式四 |
```

## 2026-11-12 换肩修复与双模式十点生命（优先于历史镜像条款）

```gherkin
  场景大纲: 双模式十次有效命中与重试
    假如<模式>采用默认配置
    那么生命与最大生命都是10且HUD从DTO显示十格
    当每次1点的有效敌弹命中九次
    那么剩1且存活，第十次归零并失败，重试恢复10
    而且显式注入生命配置不被覆盖
    例子:
      | 模式 |
      | Trench |
      | Urban |
  场景: 换肩只交换握枪角色而不镜像枪体
    当在任意支持换肩的模式切换肩侧
    那么右肩右手后握把左手护木，左肩左手后握把右手护木
    而且枪身、瞄具、枪口和握把不负缩放、不上下翻转，枪线与弹道一致
    而且真实控制器与HMD姿态不被改写，只有手模型可镜像
    而且双手松开重抓、当前后手扳机、后坐力与当前支撑手换弹正确
    而且P1/P2保留原有换肩入口，不额外启用B键
```


2026-10-22 回退修订：PR #28 的模式一、二行为已撤回至 54073a0；本文件仅对模式三、四的生命与镜像左肩行为生效。P1/P2 按该基线原有 BDD、接口及任务验收。

```gherkin
# language: zh-CN
功能: 模式三、四镜像左肩与模式三生命

    而且右扳机不能击发，左扳机释放后重新按下可击发

    那么左右角色交换后的各位置和旋转应为纵向中面的严格镜像
    而且再切回右肩恢复原姿态，HMD/控制器跟踪不被改写

  场景: 模式三四左肩换弹和双手门禁
    假如左肩持枪
    当换弹或支撑手释放/丢失跟踪
    那么右支撑手执行换弹或退出支撑，禁止有效射击
    而且完成/取消后恢复对应控制器和握持入口
```
