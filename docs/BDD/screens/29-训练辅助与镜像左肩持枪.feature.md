# 29 训练辅助与镜像左肩持枪

2026-10-22 回退修订：PR #28 的模式一、二行为已撤回至 54073a0；本文件仅对模式三、四的生命与镜像左肩行为生效。P1/P2 按该基线原有 BDD、接口及任务验收。

```gherkin
# language: zh-CN
功能: 模式三、四镜像左肩与模式三生命
  场景: 模式三恰好多承受五枪
    当模式三玩家连续承受每次1点的十次敌人命中
    那么初始生命/最大生命10，第五枪后5，第九枪后1且存活，第十枪死亡
    而且重试恢复10，模式四仍5，显式配置保持调用者参数

  场景大纲: B键切换扳机手且不自动击发
    假如玩家在<模式>右肩双手持枪
    当右B按下一次并保持
    那么仅切到左肩一次，左手后握把扣扳机，右手支撑
    而且右扳机不能击发，左扳机释放后重新按下可击发
    当B释放后再次按下
    那么恢复右肩角色，切换不额外发射或扣弹
    例子:
      | 模式 |
      | 模式三 |
      | 模式四 |

  场景: 模式三四手臂手指严格镜像并可还原
    假如保存了完整右肩枪械握把和双手手臂指骨姿态
    当切到左肩
    那么左右角色交换后的各位置和旋转应为纵向中面的严格镜像
    而且再切回右肩恢复原姿态，HMD/控制器跟踪不被改写

  场景: 模式三四左肩换弹和双手门禁
    假如左肩持枪
    当换弹或支撑手释放/丢失跟踪
    那么右支撑手执行换弹或退出支撑，禁止有效射击
    而且完成/取消后恢复对应控制器和握持入口
```
