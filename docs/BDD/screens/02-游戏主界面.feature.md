## 功能

作为玩家，我希望从主界面进入训练模式，并能看到自己的档案状态。

```gherkin
# language: zh-CN
功能: 游戏主界面

  背景:
    假如玩家启动游戏并完成基础加载
    那么系统应显示“VR射击训练系统 DEMO”主界面

  场景: 主界面显示玩家档案和底部状态栏
    当主界面加载完成
    那么左下角应显示玩家档案、训练等级和最近评级
    而且底部状态栏应显示网络、音量、用户、版本和提示
    而且这些信息不应阻挡右侧主菜单按钮

  场景: 进入 100m 精度射校靶
    当玩家选择“100m精度射校靶”
    那么系统应进入“100m任务说明”界面
    而且当前训练模式应记录为 100m 精度射校靶

  场景: 无 VR 设备时进入 100m 精度射校靶
    假如当前使用输入替身或 XR Device Simulator
    当测试输入确认“100m精度射校靶”
    那么系统应进入“100m任务说明”界面
    而且路由状态应与真实 XR 输入一致

  场景: SteamVR 手柄后扳机点击主菜单
    假如 SteamVR OpenXR 已运行且手柄射线指向可用菜单按钮
    当任一手柄的后扳机超过点击阈值并松开
    那么对应菜单按钮收到一次点击并执行既有路由
    而且只提供模拟扳机值的手柄也可点击
    而且选中场景物体不得禁用菜单的 UI 点击输入

  场景: VR 主界面使用真实地面高度并保持菜单清晰可读
    假如 OpenXR 已启动并使用 HMD 或 XR Device Simulator
    当主界面切换为 VR World Space Canvas
    那么 XR Origin 应使用 Floor Tracking Origin 且不得再叠加固定站立眼高
    而且 XR Rig 根节点位于地面；运行时回退到 Device Tracking Origin 时通过 Camera Offset 提供1.65m眼高，Floor模式偏移仍为0
    而且玩家视点与地面的高度差应由 HMD 或输入替身的真实跟踪姿态决定
    而且主菜单应在跟踪姿态稳定后重新摆放到水平视线略下方
    而且主菜单应位于玩家前方 1.2m 至 1.5m 并提供足够大的可读视角
    而且主菜单画布下沿不得低于地面 0.10m
    而且修正 UI 位置不得直接写入 HMD Camera 或 XR Origin 的跟踪姿态

  场景: 主菜单双摇杆各司其职
    假如玩家在 VR 主界面使用双手柄
    当玩家只推动左摇杆
    那么玩家只应平移而不应由该摇杆转向
    当玩家只推动右摇杆
    那么玩家只应转向而不应由该摇杆平移
    而且一次右摇杆操作不得被平滑和离散转向同时执行

  场景: 主菜单射线可见且真实扳机可以点击
    假如主菜单已进入VR模式且头手跟踪有效
    那么未命中按钮时左右UI射线仍可见，不缩成手边0.25m的短线
    当任一手柄射线指向100m入口并按下、松开后扳机
    那么XRUIInputModule收到真实输入并导航到任务说明，不能用按钮回调替代验收
    当返回主菜单时共享Input Actions被其他场景禁用
    那么主菜单恢复当前XR Rig的动作和UI Press，不遗留失效射线

  场景: 进入移动目标射击设置
    当玩家选择“移动目标射击”
    那么系统应进入“移动靶设置”界面
    而且当前训练模式应记录为移动目标射击

  场景: 进入堑壕射击地图选择
    当玩家选择“堑壕射击”
    那么系统应进入“堑壕地图选择”界面
    而且当前训练模式应记录为堑壕射击

  场景: 进入城镇攻防地图选择
    当玩家选择“城镇攻防”
    那么系统应进入“城镇地图选择”界面
    而且当前训练模式应记录为城镇攻防

  场景: 查看关于制作人并返回
    当玩家点击主菜单的“关于制作人”
    那么主菜单内应显示制作人信息面板
    而且以大字体显示“制作人：李延鹏、李龙乾”
    而且信息面板应遮挡底层训练入口的点击
    当玩家点击“返回”
    那么信息面板关闭且可继续选择训练科目
    而且查看信息不创建训练 Session 或改变页面路由

  场景: 快速重复点击菜单按钮
    假如玩家已经点击一个主菜单按钮
    当场景正在切换或页面正在打开
    那么系统应临时禁用主菜单按钮
    而且不应重复创建训练 Session 或重复加载场景
```

## Unity 验收点

- 主菜单按钮应绑定到 UI 路由，不直接创建训练逻辑。
- 若线框图仍含“武器库”“设置”入口，实现时隐藏或移除，不绑定路由。
