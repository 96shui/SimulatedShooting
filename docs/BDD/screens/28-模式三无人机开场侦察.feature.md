# 28 模式三无人机开场侦察

阶段：P3；2026-10-03 新增。仅模式三堑壕；模式四城镇保持既有入口。

依据：用户新增需求、接口20、P3 task016/017/018、draw.io p14/p28。以下为待实现验收规格，不能把既有简化起飞表现视为已完成本需求。

```gherkin
# language: zh-CN
功能: 先侦察再正式开始堑壕训练

  背景:
    假如玩家已在模式三地图的小队出生处查看开场简报
    而且无人机停在该出生处地面
    而且正式训练尚未开始
    那么所有角色的战斗和人工移动行为应被禁用

  场景: 点击开始后从玩家视角观察约三秒起飞
    当玩家点击“开始进入”或等效“开始游戏”按钮
    那么系统应只创建一次 Preparing 状态的本局 Session
    而且按固定种子准备 3 到 5 名敌人及两名队友并保持待命
    而且玩家应从自己的第一人称视角看到无人机从地面升空
    而且起飞默认持续 3 秒，允许正负 0.3 秒的表现误差
    而且起飞未完成时不得提前显示无人机监控视角或开始战斗

  场景: 切换到实时无人机监控画面
    假如起飞完成且摄像头输出已就绪
    当系统进入无人机侦察阶段
    那么主观察内容应切换为本局场景中无人机摄像头的实时画面
    而且应显示观察框、监控状态、阶段和侦察用时
    而且应应用可配置的低饱和灰绿或黑白监控滤镜
    而且堑壕地形与敌人轮廓仍应清晰可辨
    而且不能用静态图片、预录外部视频或虚构的遥测替代本局画面

  场景: 沿堑壕查询本局敌情并返航
    当无人机沿已配置的堑壕航线巡航
    那么摄像头应观察堑壕通道、拐角和本局已生成的敌人
    而且无人机不得穿墙、穿地或离开地图有效区域
    而且侦察不应改变搜索进度、击杀数、弹药、生命或任务结果
    当全部侦察航点完成
    那么无人机应飞回小队原出生处并降落
    而且返航和降落期间仍不得开始战斗

  场景: 连续固定镜头及二十秒开场上限
    当无人机执行侦察开场
    那么摄像头应保持固定世界朝向和相对机体的位置偏移，只随机体平移
    而且不逐航点转向、切镜或停顿
    而且巡航速度应提高并按本局航线长度调整，使完整开场预计在20秒以内完成
    当有效开场时间达到20秒
    那么应自动关闭巡逻画面并恢复玩家主视角，无人机回到停放位置
    而且完成主视角恢复后只开启一次正常战斗及人物行动
    而且暂停或跟踪失效的等待时间不计入20秒

  场景: 单程巡逻不重复展示同一区域
    当无人机开始巡逻
    那么速度应为上一版同局路线计算速度的三分之一
    而且应沿起点到终点的一条连续完整路径巡逻一次
    而且不得依次往返搜索点和敌人点造成反复巡逻
    当单程巡逻完成
    那么监控画面应退出并恢复玩家观察方式
    而且返航及停放不作为第二轮巡逻展示，20秒有效上限与开战门禁保持有效

  场景大纲: 正式开始前禁用场上所有人物相关行为
    假如开场处于“<阶段>”
    当玩家或角色适配器提交拾枪、持枪战斗动作、开火、换弹、人工移动、AI攻击或手雷请求
    那么玩家、队友和敌人的对应行为均不得执行
    而且不得消耗弹药、造成伤害、登记击杀、推进搜索或训练计时
    而且头手跟踪、无人机开场和返回取消UI仍可工作

    例子:
      | 阶段 |
      | 简报准备 |
      | 起飞 |
      | 侦察 |
      | 返航 |
      | 降落 |
      | 恢复玩家视角 |

  场景: 降落并恢复主视角后才正式开战
    假如本局侦察及返航已完成
    当无人机确认落地且玩家主视角确认恢复
    那么 Session 应只进入一次 Running
    而且监控UI应关闭并显示堑壕战斗HUD
    而且此时才允许玩家拾枪和射击、队友行动及敌人感知攻击
    而且训练用时应从此时开始累计
    而且本局敌人数量和位置不得被重新随机生成

  场景: 开场输入不会在开战时补执行
    假如玩家在开场期间一直按住握把、扳机、摇杆或手雷按键
    当系统正式开战
    那么不得自动拿枪、开火、移动或投掷
    而且玩家必须释放并重新提交有效输入

  场景: 无人机观察不改写真实头部跟踪
    当玩家使用真实VR观看起飞及无人机监控画面
    那么头手跟踪应继续有效
    而且无人机飞行不应直接改写HMD跟踪姿态
    而且稳定观察屏应展示与桌面相同的无人机画面
    当主视角恢复
    那么玩家应仍在原出生位置且可自然转头观察

  场景: 暂停或跟踪失效不越过开场阶段
    假如开场正在播放
    当暂停或跟踪失效
    那么开场逻辑时钟与阶段推进应停止且角色继续锁定
    当恢复
    那么应从原阶段继续，不能因等待时间自动跳到开战

  场景: 资源缺失或航线异常不会提前开战
    假如无人机、航线、摄像头或视频输出缺失或失败
    当开场无法继续
    那么系统应显示 ResourceUnavailable 并恢复玩家观察方式
    而且角色行为锁应继续有效
    而且玩家应能返回或重新开始，不能直接进入战斗

  场景: 取消和重新开始隔离旧开场
    假如开场处于任一阶段
    当玩家返回地图或主菜单
    那么本局应取消并清理角色、飞行、视频资源、音效和订阅
    而且恢复玩家观察方式但不能解除旧局战斗门禁
    当玩家再次开始模式三
    那么新Session应从地面起飞重新完整播放
    而且旧会话或旧阶段的完成回调不得触发新局开战

  场景: 其他模式入口不触发无人机
    当玩家进入模式一、模式二或模式四
    那么其开始、输入、相机和结算流程应遵循各自原有规格
    而且不触发模式三无人机开场
```
