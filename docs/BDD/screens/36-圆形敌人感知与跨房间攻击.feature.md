# 圆形敌人感知与跨房间攻击（P3，2026-11-15）

覆盖 BDD23/25/35 中发现玩家所用的视角锥、单点视线和房门登记状态限制。沿用玩法 task004/010、场景 task012；接口见28。模式三、四共用；武器、伤害、开战和生命周期门禁保持。

```gherkin
# language: zh-CN
功能: 受几何遮挡影响的大圆形感知
  场景: 从一层一号房进入一层二号房后敌人转向开火
    假如生产城镇场景按固定种子开始且 room-12 有存活敌人
    而且敌人在玩家进入前已经实例化
    当玩家先到 room-11，再打开 room-12 房门并进入 room-12
    那么在水平半径内、垂直容差内且任一头胸脚视线无遮挡时立即发现玩家
    而且玩家位于背后也立即平滑转向，并进入 Attacking
    而且水平朝向误差几秒内收敛到12度以内，再按 EnemyAttackInterval 开火造成伤害
  场景: 关闭的门与楼板阻挡感知
    当三条视线全部被关闭的门、墙体或楼板挡住
    那么敌人不发现、不转向、不攻击玩家
    而且开门立即禁用门扇阻挡碰撞体，关门或复位恢复它，门框保持实体
  场景: 任一采样通畅即可发现
    假如胸部视线被矮掩体挡住但头部视线通畅
    那么敌人发现并转向玩家
    而且自身和玩家自身碰撞体不算遮挡，其他物理遮挡仍有效
  场景: 实际几何决定可见性
    假如玩家已在房间内部且与敌人视线通畅
    那么即使房门登记状态关闭也不拒绝真实感知事实
    而且同 RoomId 的所有门视图按开门快照同步
  场景: 模式三共用感知回归
    假如 Trench 正式开战且敌人在圆内无遮挡
    那么侧面背后均能发现、转向并开火
    而且暂停、跟踪失效、死亡、开场锁定仍阻止攻击
  场景: 诊断可关闭与参数可注入
    那么半径、垂直容差、采样高度和转向速度来自同一 CombatConfigDto
    而且默认关闭的诊断可逐帧记录距离、遮挡物、圆内、Visible、提交结果、状态、夹角与 actor 存在性
```

无设备验收加载生产场景、服务、输入替身和真实 Physics，移动玩家位置复现 room-11→room-12 并保存日志。头显内转向观感和遮挡边缘体验单列实机待验。
