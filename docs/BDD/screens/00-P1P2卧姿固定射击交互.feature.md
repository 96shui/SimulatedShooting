# 00 P1/P2 卧姿固定射击交互

来源：2026-08-12 产品补充需求。

阶段：P2 实施；同时回归改造 P1 的 100m 射校体验。

## 功能

作为玩家，我希望进入 100m 射校或移动靶模式时直接处于卧姿射击点，正前方即可看到训练 UI 和步枪，拿枪后专注射击，轮次或训练结束后再查看结果。

```gherkin
# language: zh-CN
功能: P1/P2 共用卧姿固定射击交互

  场景大纲: 进入靶场时固定在卧姿射击点
    当玩家进入“<训练模式>”靶场
    那么玩家根节点应位于该场景的卧姿射击点
    而且玩家初始朝向应对准主射界
    而且连续移动、传送和人工平移输入应不可用
    而且移动输入不得改变 XR Origin 或无 VR 玩家根节点的位置
    而且玩家仍可通过真实 HMD 和双手跟踪自然移动头部与手柄

    例子:
      | 训练模式 |
      | 100m 精度射校靶 |
      | 移动目标射击 |

  场景大纲: 入场 UI 和步枪位于正前方
    假如玩家刚进入“<训练模式>”靶场
    当头显或无 VR 视角姿态稳定
    那么该模式的准备 UI 应显示在玩家正前方
    而且训练步枪应放置在玩家正前方的自然伸手范围
    而且 UI 锚点、武器锚点和卧姿射击点应为互相独立的场景绑定
    而且 UI 或武器对齐不得反向修改 HMD Camera 的跟踪姿态

    例子:
      | 训练模式 |
      | 100m 精度射校靶 |
      | 移动目标射击 |

  场景大纲: 拾枪后隐藏大型交互 UI
    假如玩家已在“<训练模式>”准备 UI 中确认开始
    而且训练步枪位于枪架或武器托架
    当玩家用右手近距拾取训练步枪后握把
    那么系统应进入对应射击流程
    而且 100m 模式应进入实弹阶段，移动靶模式应先进入 3 秒倒计时
    而且准备 UI 或上一轮结果 UI 应自动隐藏
    而且隐藏只改变 UI 表现，不应销毁 Session 或场景锚点
    而且可保留不遮挡瞄准线的最小只读射击 HUD

    例子:
      | 训练模式 |
      | 100m 精度射校靶 |
      | 移动目标射击 |

  场景: 未确认开始时拾枪不应丢失准备 UI
    假如玩家尚未在准备 UI 中确认开始
    当玩家尝试拾取训练步枪
    那么系统不应进入实弹阶段
    而且准备 UI 应继续可见
    而且系统应提示玩家先确认当前训练设置

  场景: 100m 每轮结束后显示弹着分析
    假如玩家正在 100m 射校实弹阶段
    当本轮第 3 发有效射击完成
    那么射击应被禁用
    而且本轮弹着分析 UI 应自动显示在玩家正前方
    当玩家完成调整并点击“进入下一轮”
    那么弹着分析 UI 应自动隐藏
    而且下一轮射击应在同一卧姿射击点继续
    而且即使训练枪已释放，大型 UI 也应继续隐藏，仅以最小 HUD 提示重新取枪

  场景: 训练最终结束后显示结算 UI
    假如玩家正在 100m 射校或移动目标射击
    当服务层把当前训练标记为完成
    那么有效射击应被禁用
    而且该模式的最终结算 UI 应自动显示在玩家正前方
    而且结算 UI 的出现不得依赖目标 Transform 或 UI 自行判断弹药数

  场景: 无 VR 输入替身遵守相同交互顺序
    假如当前没有 VR 设备
    当测试替身进入靶场、确认开始、拾枪、完成射击并进入下一轮或结算
    那么卧姿固定点、移动禁用、UI 显隐和武器状态应与真实 XR 路径一致

  场景: P2 连射能力不得改变 P1 单发模式
    假如玩家正在 100m 射校可射击阶段
    当玩家扣住右手 Trigger 并保持不释放
    那么系统只应在按下边沿记录 1 发有效射击
    而且保持 Trigger 不应继续生成射击
    当玩家释放并再次扣动 Trigger
    那么系统才应记录下一发单发射击
```

## Unity 验收点

- “卧姿”是 P1/P2 的固定模式配置，不依赖玩家在 UI 中切换姿态。
- 禁止人工移动不等于冻结 HMD：真实房间尺度内的头部/手部跟踪仍是输入权威。
- 大型交互 UI 与最小只读 HUD 分离；实弹阶段隐藏前者，后者只显示必要状态且不得遮挡瞄准线。
- UI、场景、玩法通过 DTO、事件和绑定接口协作；任一方都必须可以用测试替身独立验收。
