# 14 堑壕开场简报

来源：draw.io 页面 `p14 14 堑壕开场简报`

阶段：P3；2026-10-03 更新为完整无人机开场侦察，详细验收见 `28-模式三无人机开场侦察.feature.md`；队伍仍为 3 人纵队。

## 功能

作为玩家，我希望先查看堑壕平面图、小队配置和任务目标，点击开始后观看无人机起飞、监控侦察及返航降落，再进入正式战斗。

```gherkin
# language: zh-CN
功能: 堑壕射击开场任务

  背景:
    假如玩家已选择堑壕地图和武器
    当堑壕任务准备完成
    那么系统应显示“堑壕射击 开场任务”

  场景: 简报展示地图并等待开始
    当开场简报开始
    那么无人机应停在小队出生处地面，等待玩家点击开始
    而且投影区域应显示堑壕入口、队友位置和红色敌情区域
    而且所有角色在简报期间不应提前进入堑壕战斗状态

  场景: 显示小队配置
    当简报界面加载完成
    那么左侧应显示玩家在最前
    而且显示二号队友后方掩护
    而且显示三号队友朝后警戒

  场景: 显示任务目标
    当玩家查看任务目标面板
    那么界面应显示进入堑壕
    而且显示搜索路线
    而且显示消灭敌人
    而且显示保持小队队形

  场景: 开始进入堑壕
    当玩家选择“开始进入”
    那么系统应创建 Preparing 状态的堑壕任务 Session
    而且生成 3 到 5 名敌人
    而且生成两名队友并排列为三人纵队
    而且所有角色应保持待命并禁用拿枪、射击和相关战斗行为
    而且应按BDD28播放玩家视角起飞、无人机监控侦察、返航和降落
    当无人机降落完成且玩家主视角恢复
    那么才进入Running和“堑壕第一人称HUD”并开放战斗行为

  场景: 新战壕入口与敌人候选点
    假如模式 03 的新战壕场景已加载
    当玩家选择“开始进入”
    那么玩家与两名队友应出生在可行走的入口位置
    而且 3 到 5 名敌人的候选出生点应位于新战壕的有效导航区域
    而且入口到搜索节点和敌人候选点应存在可通行路径
    而且所有角色脚部应贴合原始演示场景的可见地面

  场景: 新战壕进入实战后保持完整操作
    假如玩家从模式 03 简报开始任务且已完成无人机侦察并正式开战
    当玩家沿战壕移动并向前方开枪
    那么玩家应能沿可见通道连续移动
    而且角色脚部应位于通道地面之上
    而且开枪应正常消耗弹药并产生射击反馈
    而且敌人、队友和搜索节点仍按原有模式 03 规则运行

  场景: 新战壕出生点可见并可拾取武器
    假如玩家进入模式 03 开场简报
    那么玩家身旁的武器锚点应显示训练步枪
    当玩家选择“开始进入”
    那么训练步枪应在玩家可见且伸手可及的位置生成但暂不允许抓取
    而且场景预览枪应隐藏，不得与可抓取枪重叠
    当无人机降落完成且玩家主视角恢复并正式开战
    那么才允许右手抓取训练步枪

  场景: 所有敌人候选点脚部贴合可见地面
    当敌人在任一合法候选点生成
    那么脚底应贴合该点的实际可见地面
    而且命中碰撞体应与人物外观保持对齐

  场景: 查看地图
    当玩家选择“查看地图”
    那么系统应放大或聚焦堑壕平面图
    而且玩家应能返回开场简报

  场景: 返回地图选择
    当玩家选择“返回”
    那么系统应返回堑壕地图选择界面
    而且不应创建新的堑壕任务 Session
```

## 应用装配异常（task013）

```gherkin
  场景: 加载失败恢复地图选择
    当选定地图的场景加载失败
    那么系统应保留可重试的地图选择页并显示 ResourceUnavailable
    而且不创建战斗 Session 或角色

  场景: 加载中取消或切换模式
    假如场景仍在加载
    当玩家返回主菜单或切换训练模式
    那么旧加载完成后只清理自己拥有的场景
    而且不得覆盖当前页面或创建旧模式的 Session
```

## Unity 验收点

- 直接启动 `CombatScene` 场景巡检、加载和简报预览时无人机保持静止。起飞仅由模式三“开始进入”命令触发，完整流程见BDD28。

- 开始进入时才创建 Preparing 会话、敌人和队友；准备期间角色冻结。降落及玩家视角恢复后才进入正式战斗，训练计时从此开始。
- 队友队形可通过 NavMeshAgent、路径点或自定义跟随逻辑实现，但状态需可测试。


## 2026-10-04 全堑壕侦察与安全开局（当前生效）

按最新用户要求，撤销单程最长主路和20秒强制结束：无人机按当前速度巡察当前训练地图的所有堑壕分段、支路、掩体及搜索区域，逐点完成后才返航。增加观察点不能提高巡航速度，速度仍按原搜索/敌人点基准计算。支路覆盖允许必要回折，不循环重播路线。返航与降落保持无人机实时画面；返航、降落和玩家视角恢复确认全部完成后，应用才发布正式开战并解除玩家/队友/敌人行为锁。

MaximumOpeningSeconds=0表示不设总时长；默认0。侦察/返航不因StepTimeoutSeconds中断，起飞、降落和恢复阶段仍保留异常超时保护。两处近出生敌人点移至掩体后的可导航位置，同步估计区，保持点ID、种子和敌人数量契约；开局玩家与敌人之间必须有真实几何遮挡。
