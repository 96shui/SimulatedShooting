# 14 堑壕开场简报

来源：draw.io 页面 `p14 14 堑壕开场简报`

阶段：P3；无人机动画可先用简化表现，队友只要求 3 人纵队。

## 功能

作为玩家，我希望在进入堑壕前看到无人机投射的堑壕平面图、小队配置和任务目标。

```gherkin
# language: zh-CN
功能: 堑壕射击开场任务

  背景:
    假如玩家已选择堑壕地图和武器
    当堑壕任务准备完成
    那么系统应显示“堑壕射击 开场任务”

  场景: 播放无人机起飞并显示地图投影
    当开场简报开始
    那么系统应播放无人机起飞或等效过场
    而且投影区域应显示堑壕入口、队友位置和红色敌情区域
    而且玩家在简报期间不应提前进入堑壕战斗状态

  场景: 显示小队配置
    当简报界面加载完成
    那么左侧应显示玩家在最前
    而且显示二号队友后方掩护
    而且显示三号队友朝后警戒

  场景: 显示任务目标
    当玩家查看任务目标面板
    那么界面应显示进入堑壕
    而且显示搜索路线
    而且显示消灭敌人
    而且显示保持小队队形

  场景: 开始进入堑壕
    当玩家选择“开始进入”
    那么系统应创建堑壕任务 Session
    而且生成 3 到 5 名敌人
    而且生成两名队友并排列为三人纵队
    而且进入“堑壕第一人称HUD”

  场景: 新战壕入口与敌人候选点
    假如模式 03 的新战壕场景已加载
    当玩家选择“开始进入”
    那么玩家与两名队友应出生在可行走的入口位置
    而且 3 到 5 名敌人的候选出生点应位于新战壕的有效导航区域
    而且入口到搜索节点和敌人候选点应存在可通行路径
    而且所有角色脚部应贴合原始演示场景的可见地面

  场景: 新战壕进入实战后保持完整操作
    假如玩家从模式 03 简报开始任务
    当玩家沿战壕移动并向前方开枪
    那么玩家应能沿可见通道连续移动
    而且角色脚部应位于通道地面之上
    而且开枪应正常消耗弹药并产生射击反馈
    而且敌人、队友和搜索节点仍按原有模式 03 规则运行

  场景: 新战壕出生点可见并可拾取武器
    假如玩家进入模式 03 开场简报
    那么玩家身旁的武器锚点应显示训练步枪
    当玩家选择“开始进入”
    那么训练步枪应在玩家可见且伸手可及的位置生成并允许右手抓取
    而且场景预览枪应隐藏，不得与可抓取枪重叠

  场景: 所有敌人候选点脚部贴合可见地面
    当敌人在任一合法候选点生成
    那么脚底应贴合该点的实际可见地面
    而且命中碰撞体应与人物外观保持对齐

  场景: 查看地图
    当玩家选择“查看地图”
    那么系统应放大或聚焦堑壕平面图
    而且玩家应能返回开场简报

  场景: 返回地图选择
    当玩家选择“返回”
    那么系统应返回堑壕地图选择界面
    而且不应创建新的堑壕任务 Session
```

## 应用装配异常（task013）

```gherkin
  场景: 加载失败恢复地图选择
    当选定地图的场景加载失败
    那么系统应保留可重试的地图选择页并显示 ResourceUnavailable
    而且不创建战斗 Session 或角色

  场景: 加载中取消或切换模式
    假如场景仍在加载
    当玩家返回主菜单或切换训练模式
    那么旧加载完成后只清理自己拥有的场景
    而且不得覆盖当前页面或创建旧模式的 Session
```

## Unity 验收点

- 直接启动 `CombatScene` 场景巡检不等于开始简报；巡检加载和复位时无人机保持静止，不自动播放起飞。正式简报的起飞要求保留，由简报流程触发。

- 开始进入时才创建敌人和队友，简报阶段只显示配置预览。
- 队友队形可通过 NavMeshAgent、路径点或自定义跟随逻辑实现，但状态需可测试。
