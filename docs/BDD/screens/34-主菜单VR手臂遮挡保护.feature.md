# 34 主菜单VR手臂遮挡保护

2026-10-23 用户截图反馈启动MainScene后手臂贴入相机。沿用BDD02、接口11、P1 UI task008与P3玩法task019的手部显示组件，本修复提供自动化回归。

```gherkin
# language: zh-CN
功能: 主菜单启动和跟踪丢失时不被手臂挡住
  场景: 手柄尚未获得位置跟踪
    当主菜单中的手柄没有有效位置跟踪
    那么隐藏对应人物手臂网格
    而且不禁用控制器、菜单射线、输入动作或交互组件

  场景: 已跟踪手柄贴入头部
    当手柄与头显间距小于15厘米或手臂网格包围相机
    那么暂时隐藏对应手臂网格
    而且不移动头显或伪造手柄位置

  场景: 跟踪恢复后正常显示
    当手柄位置跟踪恢复并离开头部
    那么自动恢复对应手臂显示
    而且模型定时刷新、重复进入菜单不得让遮挡再次出现

  场景: 保护仅用于主菜单
    当进入训练场景
    那么不继承主菜单的手臂隐藏状态
    而且保留既有握枪、左右手镜像和换弹动作
```
