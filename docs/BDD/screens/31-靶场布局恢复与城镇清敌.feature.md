# 31 靶场布局恢复与城镇清敌

2026-10-23 用户修订，优先于BDD30的25m/50m视觉距离和BDD20/21/25中“搜索所有房间才能胜利”。P1/P2采用10月22日前移靶标之前的保存布局（54073a0场景内容）；P3模式三不变。接口23；沿用P1 task006/012/013、P2 task006/007与P3 task004/009/010/013。

```gherkin
# language: zh-CN
功能: 原靶排布局下准确射击及城镇清敌
  场景: 恢复末端靶排
    当打开模式一或模式二
    那么保存场景和构建器均恢复原100米末端靶排及背景布局
    而且不再自动将中心靶、挡板或移动路线前移
    而且保留弹着坐标、实际补偿和本轮帮助建议修复

  场景: 两发起射前枪线恢复
    假如模式二双手瞄准静止靶面且控制器姿态不变
    当一次快速扣动触发两发
    那么第二发不能因上一发的展示后坐仍未回正而偏离数米
    而且保留枪口、瞄准线、真实Collider、逐发射击与触觉反馈

  场景: 城镇开局能看见并拿到步枪
    当模式四开始或重试
    那么唯一的训练步枪应位于当前玩家视线前下方且伸手可达
    而且有效握持后可正常射击与换弹
    而且不依赖旧出生朝向或位于其他模式的枪架

  场景: 建筑角落敌人可被找到并击杀
    当使用固定种子启动模式四
    那么建筑敌人来自房间角落的稳定候选点
    而且不埋入墙体或地板，进入房间后有可射击角度
    而且同种子重试敌人分布一致

  场景: 全部击杀即成功
    假如模式四玩家仍存活
    当本局全部敌人被服务确认击杀
    那么任务立即成功并只结算一次
    而且不要求逐个房间确认搜索或停留检查区
    而且还有一个敌人存活时不得成功，同批次玩家死亡仍优先失败
```
