# 08 移动靶设置

来源：draw.io 页面 `p08 08 移动靶设置`

阶段：P2。

## 功能

作为玩家，我希望在移动目标射击前选择目标速度。

```gherkin
# language: zh-CN
功能: 移动目标射击模式设置

  背景:
    假如玩家选择了移动目标射击
    那么系统应显示“移动目标射击：模式设置”

  场景: 默认速度
    当移动靶设置界面加载完成
    那么速度选择应显示 3m/s、4m/s、5m/s
    而且默认速度应为 4m/s 或项目配置的默认值

  场景大纲: 选择目标速度
    当玩家选择速度“<速度>”
    那么当前移动靶速度应记录为“<速度>”
    而且开始训练时应使用该速度

    例子:
      | 速度 |
      | 3m/s |
      | 4m/s |
      | 5m/s |

  场景: 开始训练
    假如玩家已选择目标速度
    当玩家点击“开始训练”
    那么系统应创建移动目标训练 Session
    而且应进入移动靶 HUD
    而且训练开始前应进入 3 秒等待状态

  场景: 返回上一级
    当玩家点击“返回”
    那么系统应返回主界面或训练模式选择
    而且不应创建移动目标训练 Session
```

## Unity 验收点

- 速度选择使用同一配置对象传给移动靶状态机。
