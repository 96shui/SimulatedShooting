# 第六轮战斗体验修订（2026-11-14）

本文件覆盖 BDD02/12/15/18/19/20/23/25/27/29/33 中与下述八项冲突的历史条款；阶段、现有输入入口和页面布局不变。接口见27，任务沿用P1 UI task008、P2 UI task005、P3 UI task002/005/008/011及玩法task004/010/015/019/020。

```gherkin
# language: zh-CN
功能: 第六轮战斗体验
  场景: 操作介绍模式二说明
    那么模式二第二行是“双手据枪，采用“跟随射击”或“等待射击”的方式对目标进行射击。”
    而且下一行仍是“右扳机快速扣动起射两发，继续按住可逐发连射。”
  场景: 拐角射击仅显示可用
    当模式三、模式四街道或建筑HUD刷新
    那么文字始终为“拐角射击：可用”，无论能力DTO真假
    而且不修改能力判定、命令或交互
  场景大纲: 五个弹匣
    假如<模式>开始或重试
    那么弹匣容量30、枪内30、备用120，HUD备用弹匣为4
    当依次打空并完成四次换弹
    那么备用依次90、60、30、0，最终第五个弹匣打空后拒绝换弹
    而且结算使用实际剩余弹数，模式一4/8与模式二10发不变
    例子:
      | 模式 |
      | Trench |
      | Urban |
  场景: 进入已开门房间被敌人发现
    假如玩家先进入一层一号房，再打开并进入一层二号房
    当房内存活敌人与玩家30米内且实际视线无遮挡
    那么即使玩家在敌人初始视野背后，敌人也进入攻击状态并平滑转向，对准12度以内后按原间隔开火
    而且其它房间、其它楼层、街道进入建筑采用同一规则，关闭房门、墙体和楼板仍遮挡
  场景: 地图选择每次对齐当前眼高
    当每次打开模式三或四地图选择页，包括返回及重新进入同一页
    那么面板中心位于当前相机水平前方1.3米、当前眼高，正面朝向玩家
    而且不沿用旧位置或固定场景锚点，不移动HMD
  场景: 各模式松枪自然落地
    当玩家移动手柄后松开后握把
    那么支撑手释放，枪不继承投掷线速度或角速度，受重力落到碰撞地面并停止
    而且仍可重拾，保留回架和重试复位规则
  场景: 左肩自然持枪
    当切换左肩
    那么整枪持枪位置向左偏，枪口朝前、枪体正立，瞄具与弹道使用同一枪线
    而且右肩恢复原握持位置和朝向，不累积偏移
  场景: 无敌人也能投手雷
    假如收到有效投雷命令且当前没有活敌
    那么第一名队友沿玩家快照水平Forward投掷，落点为玩家前方GrenadeDetectionRange加竖直0.08米
    而且玩家朝向不可用时回退投掷队友朝向，有敌人时仍朝最近敌人投掷
```
