# 模式三队友按键投掷手雷（2026-09-30 用户新增范围）

```gherkin
功能: 堑壕模式队友按键投掷
  场景: 玩家按键命令第一名队友投掷
    假如模式三正在实战且追踪有效
    而且队友12米内有至少两个存活敌人
    而且存在能把这两个敌人覆盖在5米爆炸半径内的无遮挡落点和可通行抛物线
    当玩家按下右手手柄 A 键且小队手雷冷却结束
    那么第一名存活队友转向落点并抬手投掷
    而且手雷在0.65秒准备动作之后从手中脱离
    而且投掷期间该队友暂停导航并在动作结束后恢复跟随
  场景: 数量距离和冷却门禁
    假如只有一个敌人或敌人超出范围或无法形成可覆盖敌群
    那么不投掷
    而且尸体不计数，两个队友不得同时重复投掷
    而且每次爆炸后小队冷却8秒，未按 A 键不得自动投掷
  场景: 爆炸击杀与表现
    当手雷完成飞行和1.25秒落地延迟
    那么在实际落点播放火光、火星、烟尘、闪光和爆炸声音
    而且仅爆炸5米内且未被实体墙体遮挡的存活敌人直接死亡
    而且玩家和队友不受此次技能伤害
    而且击杀进入正常HUD/地图/结算并保留尸体，重复爆炸不重复计数
  场景: 碰撞与状态中断
    假如飞行过程中出现实体阻挡
    那么手雷停在碰撞位置并在同一计时结束后于该位置爆炸
    当暂停、追踪丢失、玩家死亡、结束、取消或重试
    那么撤销未爆炸手雷和投掷动作，不得在旧Session产生伤害
  场景: 模式隔离
    当进入P1、P2或城镇模式
    那么不启用此按键手雷技能
```

游戏参数可在模式三的 CombatSceneBindings 调整。上述数值是原型玩法默认值，不模拟现实武器数据。无VR走同一生产服务/场景路径，实机舒适度另验。
