# 模式三队友按键投掷手雷（2026-09-30 用户新增范围）

```gherkin
功能: 堑壕模式队友按键投掷
  场景: 玩家按键命令第一名队友投掷
    假如模式三正在实战且追踪有效
    而且场上存在存活敌人
    当玩家按下右手手柄 A 键且距上次投掷至少3秒
    那么第一名存活队友朝最近的敌人转向并抬手投掷
    而且敌人在18米投掷距离外时，手雷朝该敌人方向投到18米处
    而且手雷在0.65秒准备动作之后从手中脱离
    而且投掷期间该队友暂停导航并在动作结束后恢复跟随
  场景: 冷却与空场门禁
    假如场上没有存活敌人或第一个队友倒下
    那么不投掷
    而且尸体不计数，两个队友不得同时重复投掷
    而且投掷之间至少间隔3秒，未按 A 键不得自动投掷

  场景: 不同输入后端的右手 A 键
    当 OpenXR 或 Input System 的右手 primaryButton 报告一次按下
    那么模式三只接收一次投掷命令
    而且无 VR 输入替身可用 H 键触发同一命令
  场景: 爆炸击杀与表现
    当手雷完成飞行和1.25秒落地延迟
    那么在实际落点播放较大范围的灰黑烟尘、少量碎屑、短暂闪光和爆炸声音
    而且仅爆炸5米内且未被实体墙体遮挡的存活敌人直接死亡
    而且玩家和队友不受此次技能伤害
    而且击杀进入正常HUD/地图/结算，尸体显示 5 秒后隐藏，重复爆炸不重复计数
  场景: 碰撞与状态中断
    假如飞行过程中出现实体阻挡
    那么手雷停在碰撞位置并在同一计时结束后于该位置爆炸
    当暂停、追踪丢失、玩家死亡、结束、取消或重试
    那么撤销未爆炸手雷和投掷动作，不得在旧Session产生伤害
  场景: 模式隔离
    当进入P1、P2或城镇模式
    那么不启用此按键手雷技能
```

游戏参数由 CombatConfigDto 提供默认值。上述数值是原型玩法默认值，不模拟现实武器数据。无VR走同一生产服务/场景路径，实机舒适度另验。

2026-10-04 模型可见性修订：脱手点随地形对齐后的队友模型计算，不能沿用未同步高度的定位节点；飞行和落地阶段模型跟随服务实际位置，只在爆炸或取消时移除，不因表现层计时提前消失。

2026-10-05：原M67模型使用独立投射物节点，统一高度0.16游戏米并居中；显式启用渲染和Default层。共享抛物线飞行，停止后不翻滚。碰撞返回距接触面0.085米的模型中心，落地至爆炸前可见，避免埋入地面。保持最近敌人、18米上限、3秒冷却和爆炸伤害。

编辑器检查补充：飞行翻滚导致旋转后的模型垂直包围盒大于落点间距。位置停止且准备阶段结束后，模型恢复直立静止姿态，地面底部不得继续穿入碰撞面。
