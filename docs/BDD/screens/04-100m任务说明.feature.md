## 功能

作为玩家，我希望在开始 100m 精度射校靶前确认训练规则和通过条件。

```gherkin
# language: zh-CN
功能: 100m 精度射校靶任务说明

  背景:
    假如玩家选择了 100m 精度射校靶
    那么系统应显示 100m 任务说明界面
    而且玩家应已位于卧姿固定射击点
    而且任务说明 UI 与训练步枪应位于玩家正前方

  场景: 在射击平台上就位并就近取枪
    当模式一场景加载完成
    那么玩家、VR Origin 和无 VR 测试视点应位于射击平台上的同一前移射击位置
    而且初始步枪应位于玩家右前方自然伸手范围内
    而且不应通过移动真实 HMD 跟踪姿态来靠近步枪

  场景: 展示任务参数
    当任务说明界面加载完成
    那么界面应显示射击距离为 100m
    而且射击模式为单发射
    而且显示每轮 4 发、共 3 轮
    而且显示目标为 50cm×50cm 胸靶
    而且显示 10 环直径为 10cm
    而且显示通过条件：集中且计算集各点距靶心≤10cm、均值距靶心≤5cm、至少一发距靶心≤5cm；或集中且应用后的均值距靶心<5cm

  场景: 显示胸靶示意
    当玩家查看任务说明界面
    那么右侧应显示胸靶示意和中心 10 环
    而且示意图只作为说明，不应消耗射击输入

  场景: 开始射击
    当玩家点击“开始射击”
    那么系统应创建 100m 射校训练 Session
    而且应生成本局固定弹着偏移
    而且系统应进入等待拾枪状态
    而且轮次应为 1/3，弹数应为 4/4
    当玩家随后用右手近距拾取训练步枪
    那么任务说明 UI 应自动隐藏
    而且系统应进入“100m射击HUD”与实弹阶段

  场景: 无 VR 设备时开始射击
    假如当前使用输入替身或 XR Device Simulator
    当测试输入确认“开始射击”
    那么系统应创建 100m 射校训练 Session
    而且应进入等待拾枪状态
    当测试输入随后模拟有效拾枪
    那么任务说明 UI 应自动隐藏
    而且应进入“100m射击HUD”
    而且后续射击输入应由同一输入适配接口驱动

  场景: 返回模式选择
    当玩家点击“返回”
    那么系统应返回“训练模式选择”或上一级模式入口
    而且不应创建 100m 射校训练 Session
```

## Unity 验收点

- 开始训练时初始化 `ZeroingSession`，包含轮次、弹药、固定偏移、弹着记录和调整状态。
- 固定偏移应可注入随机种子，便于自动化测试复现。
- P1 PlayMode Test 必须覆盖无 VR 输入替身启动训练，并断言 Session 与 HUD 初始状态。
- 开始按钮只准备 Session；大型任务说明 UI 在有效拾枪后隐藏，不能由场景脚本直接销毁。
