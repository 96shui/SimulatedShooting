# 23 P3 共用战斗核心

阶段P3，task004；补充BDD15/19/20/21/22。接口以15为准。

```gherkin
# language: zh-CN
功能: 共用战斗规则
  场景: 双手单发与换弹守恒
    假如新局弹药30/120，未持枪
    那么无效持枪不耗弹
    当有效双手跟踪下按下并保持Trigger
    那么只发一发，松开再按才能再次射击
    当主动换弹并经过2秒
    那么保留余弹补满弹匣且弹药总量守恒

  场景: 可见敌人的确定性攻击
    假如敌人在30米内、半视角60度且无遮挡
    当首次发现后经过1秒
    那么玩家受到10点伤害
    而且相同时钟区间的大步长与小步长产生同样结果
    当敌人被遮挡、死亡或玩家已死亡
    那么攻击停止

  场景: 命中与死亡去重
    假如有效子弹命中已绑定敌人
    当同一事件或同一ShotId被重复报告
    那么敌人只死亡一次，中弹反馈只播放一次，尸体保留
    而且非法ShotId、旧会话、非有限伤害不能改变状态
    当同批次玩家受到致命伤害且其已射出的子弹杀死敌人
    那么仍为玩家死亡失败

  场景: 生命周期停止调度
    当暂停、结算、退出或跟踪丢失
    那么人工移动、射击和敌人攻击停止，未完成换弹取消且不消耗备用弹
    当恢复后仍保持Trigger
    那么不自动补射，需松开重新扣动

  场景: 姿态与枪线独立适配
    当无VR替身切换站蹲卧、换肩和移动
    那么服务提供对应姿态步速和眼高，转向只在摇杆越过阈值时发生一次
    当真实VR切换姿态
    那么不输出强制眼高
    当枪口射线先碰到墙或枪口位于墙内
    那么墙后的敌人不被命中
    而且P1/P2始终禁止人工移动和转向
```
