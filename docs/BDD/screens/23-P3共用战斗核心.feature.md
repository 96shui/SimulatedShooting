# 23 P3 共用战斗核心

阶段P3，task004；补充BDD15/19/20/21/22。接口以15为准。

场景美术补充（P3 task014）：敌我军服与骨骼表现。敌军与友军均使用用户提供的 AmericanSoldier 骨骼模型，友军军服配色及蓝色识别标记与敌军明显不同。导航移动驱动腿部动作，服务射击/受击反馈驱动动作，死亡动作只播放一次并保留尸体；复位恢复存活姿态。材质区分不得改变裸露皮肤颜色，识别标记随身体骨骼移动。无设备测试可验证上述行为。

```gherkin
# language: zh-CN
功能: 敌我角色表现（P3 task014）
  场景: 敌我军服与骨骼表现
    假如战斗场景实例化敌军和两名队友
    那么双方均显示已绑定骨骼的 AmericanSoldier 模型
    而且友军的军服和帽子配色与敌军不同，并佩戴蓝色识别标记
    而且双方裸露皮肤保持原始材质，标记随骨骼移动
    当队友沿有效导航路径移动
    那么腿部播放随实际速度变化的走跑动画，动画不驱动导航根节点
    当角色接收有效射击或受击表现事件
    那么播放对应动画，同一事件不重复触发
    当角色死亡
    那么停止导航和有效命中，播放一次倒地动作并保留尸体
    当角色复位
    那么恢复存活姿态、导航和命中体
```

2026-09-16 正式接入：左摇杆移动，右摇杆水平离散转向；右 A 换弹、右 B 换肩、左 X 确认交互、左 Y 循环姿态。Grip 和扳机沿用近距双手门禁；详见接口18。真实头部高度不由姿态命令修改。

```gherkin
# language: zh-CN
功能: 共用战斗规则
  场景: 双手单发与换弹守恒
    假如新局弹药30/120，未持枪
    那么无效持枪不耗弹
    当有效双手跟踪下按下并保持Trigger
    那么只发一发，松开再按才能再次射击
    当主动换弹并经过2秒
    那么保留余弹补满弹匣且弹药总量守恒

  场景: 可见敌人的确定性攻击
    假如敌人在30米内、半视角60度且无遮挡
    当首次发现后经过1秒
    那么玩家受到10点伤害
    而且相同时钟区间的大步长与小步长产生同样结果
    当敌人被遮挡、死亡或玩家已死亡
    那么攻击停止

  场景: 命中与死亡去重
    假如有效子弹命中已绑定敌人
    当同一事件或同一ShotId被重复报告
    那么敌人只死亡一次，中弹反馈只播放一次，尸体保留
    而且非法ShotId、旧会话、非有限伤害不能改变状态
    当同批次玩家受到致命伤害且其已射出的子弹杀死敌人
    那么仍为玩家死亡失败

  场景: 生命周期停止调度
    当暂停、结算、退出或跟踪丢失
    那么人工移动、射击和敌人攻击停止，未完成换弹取消且不消耗备用弹
    当恢复后仍保持Trigger
    那么不自动补射，需松开重新扣动

  场景: 姿态与枪线独立适配
    当无VR替身切换站蹲卧、换肩和移动
    那么服务提供对应姿态步速和眼高，转向只在摇杆越过阈值时发生一次
    当真实VR切换姿态
    那么不输出强制眼高
    当枪口射线先碰到墙或枪口位于墙内
    那么墙后的敌人不被命中
    而且P1/P2始终禁止人工移动和转向
```
