# 24 P3 堑壕任务与队形

task007，补充BDD12/14/15/17，接口16定义批次与导航应答。

```gherkin
# language: zh-CN
功能: 堑壕服务闭环
  场景: 预览不生成与固定种子
    当查询地图和开场简报
    那么不创建会话或角色且不请求导航
    当开始同种子同候选地图
    那么生成相同的3到5名敌人位置，预估点不暴露实际偏移

  场景: 搜索和击杀分别不足以胜利
    假如只完成全部搜索或只消灭全部敌人
    当请求完成
    那么返回InvalidState
    当全部搜索和击杀完成且玩家存活
    那么结果只发布一次且统计来自服务

  场景: 同批死亡优先与重试隔离
    假如同批输入包含最后节点、最后击杀与玩家致命伤害
    当结束批次
    那么结果为失败并保留该批统计
    当取消并重新开始
    那么使用新会话且旧事件不再影响节点、敌人、队伍或结果

  场景: 三人沿折线路径跟随
    当玩家沿拐角移动
    那么二号在路径后1.5米朝前，三号在路径后3米朝后
    而且仅导航到达事实更新队友位置，不移动玩家
    当导航失败
    那么队友保持原位并在1秒后重试
    而且指令列表为空，战术请求不能假成功

  场景: 当前快照与生命周期
    当弹药、搜索、死亡或队伍变化
    那么HUD、任务、视觉查询与事件对应同一当前版本
    当暂停、跟踪失效、终局或取消
    那么计时和队形调度停止，迟到导航不能改变旧状态
```
