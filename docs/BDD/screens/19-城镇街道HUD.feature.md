# 19 城镇街道HUD

## 扫描人物与建筑材质验收（2026-09-15）

- 六栋外围房屋的独立静态假人使用真人扫描外观，保留位置、测试 ID 和入口；不增加 CombatActorView，不改变敌人数量或搜索规则。
- 外墙使用有出处的建筑磁砖漫反射、法线和粗糙度材质；整栋台湾街屋模型须另行取得并验收，不能将材质替换称为台北建筑扫描复刻。
- 场景外圈移除球形土堆背景，改用臺北市政府都市發展局 `LOD1T_2017` I3S 服务中的真实台北建筑节点；外围模型只作无碰撞视觉背景，六栋可进入建筑继续提供房间、假人与碰撞。
- 检查人物约 1.78m 身高、自然站姿、贴图完整；回归全部房屋进出与防坠。战壕军人外观仍待符合要求的素材。
- 室内地板与旧地基顶面必须保持至少 2.5cm 高差，行走与转头时不得出现共面闪烁。

来源：draw.io 页面 `p19 19 城镇街道HUD`

阶段：P3。

## 功能

作为玩家，我希望在城镇街道 HUD 中查看小地图、建筑入口、任务提示、弹药和姿态状态，并进入可搜索建筑。

```gherkin
# language: zh-CN
功能: 城镇街道 HUD

  背景:
    假如玩家已进入城镇攻防街道场景
    而且玩家与两名队友保持纵队
    那么系统应显示城镇街道第一人称 HUD

  场景: HUD 显示街道任务信息
    当城镇街道 HUD 加载完成
    那么小地图应显示玩家、队友和建筑入口
    而且小地图应显示红色敌情预估
    而且任务提示应显示进入建筑、搜索房间、消灭敌人
    而且弹药应显示 30 / 120

  场景: 建筑入口显示可交互提示
    假如玩家靠近可进入建筑入口
    当玩家视线或 XR 射线指向入口
    那么界面应显示“建筑入口 / 可交互提示”
    而且入口高亮不应遮挡战斗 HUD

  场景: 进入建筑搜索阶段
    假如玩家位于建筑入口交互范围内
    当玩家确认进入
    那么系统应切换到建筑内部场景或楼层区域
    而且 HUD 应切换为“建筑搜索HUD”
    而且街道已清除状态应保存在城镇 Session 中

  场景: 街道敌人未清除时提示风险
    假如街道敌人仍存活
    当玩家尝试进入建筑
    那么系统应允许进入或提示风险，取决于项目规则
    而且任务状态应保留未清除的街道敌人

  场景: 姿态、换肩和拐角状态显示
    当玩家切换姿态或换肩状态
    那么底部状态栏应实时更新姿态、右肩/左肩和拐角射击可用状态
```

## Unity 验收点

- 建筑入口建议使用触发器和可交互组件双重判断：进入范围后才允许确认。
- 街道敌人清除状态、建筑入口状态和玩家位置应属于 `UrbanSession`。
- P3 仅要求一条街、一栋 3 层楼和简单敌人 AI；复杂战术交互和高级队友行为为 Later。
- 城镇 HUD 必须复用输入适配，支持无 VR 输入替身完成建筑入口确认。


## 场景层补充验收（2026-09-10）

场景边界回归：外围房屋之间、街道边缘及建筑后方必须有连续地面碰撞；城镇外圈围墙阻挡步行，战壕连接口保持通行。沿围墙直行或斜向挤压不能穿出并掉落。出生及复位后应稳定站立。

堑壕与城镇共用 `CombatScene.unity`，保留各自逻辑 SceneId。无 VR 场景巡检可以从堑壕步行至街道，再经入口到达三层五个房间并返回；区域只上报进入/退出/确认，房门仅响应接受的表现输出。此场景巡检不创建生产 Session、不推进搜索或结算。


## 2026-09-14 场景通行修复

按用户要求，现有六栋外围建筑均开放首层入口和内部空间，每栋至少放置一个静态假人（复用角色视觉，不计入生产敌人数或搜索规则）。主楼保留三层五房和巡检角色。可行走地面必须连续承托；楼梯、平台和楼层外露边缘设置可见且与碰撞一致的防坠护栏；移除旧街道内部边界障碍。保持保存场景的建筑位置、外观和既有服务端口。

验收：无 VR CharacterController 从街道逐栋进入并返回，检查假人；网格采样地面，逐段向高处边缘直行和斜向挤压，不能坠落。对应 CombatScenePlayModeTests 的 Bdd19 通行与防坠测试。VR 实机舒适度待验。

## 2026-09-14 台湾街景与真实战壕美术迭代

用户明确要求“台湾街景 + 真实战壕”。在现有 CombatScene 内保留建筑、门洞、假人、通行与防坠结构，更新磁砖外墙、繁体中文虚构商铺招牌、骑楼雨棚、铁窗、冷气外机、屋顶水塔、机车停放区和道路设施；战壕增加湿泥、排水细节、支撑件、沙袋使用痕迹。替换泛化废墟天空和不匹配的部分建筑装饰。此要求取代此前“不设置路牌式文字”的美术限制；文字是环境店招，不是业务 UI。

保持场景表现层边界，不新增生产玩法或现实作战信息。新增实体设施提供贴合视觉的碰撞，重烘焙导航，回归所有房屋进出和防坠。验收包含保存场景结构测试、完整 CombatScene PlayMode 回归、近景/街道/战壕截图和 Editor 性能采样；VR 实机画质与性能仍需设备验收。


## 2026-09-15 实际素材与台湾繁体字修订

按用户反馈，街边机车使用外部实际建模素材替换基础几何拼装，保存作者及许可证；房屋优先使用有许可的台湾街屋素材。导入模型按真实尺度配置材质和贴合外形的碰撞，保持已有入口、假人、防坠和导航可用。场景店招、路牌及本地巡检界面使用台湾繁体字及 Noto Sans TC 字体；内部稳定 ID、事件字符串和按键名称保持接口不变。验收检查模型源引用、尺寸、字形，以及房屋通行回归。未取得下载文件的建筑素材须明确列为未完成，不能以白盒贴图宣称已替换。
