# 09 移动靶 HUD

来源：draw.io 页面 `p09 09 移动靶HUD`

阶段：P2。

## 功能

作为玩家，我希望在移动靶 HUD 中使用觇孔完成两发起射或长按连射，并看到弹药、命中、速度、方向和可射击状态。

```gherkin
# language: zh-CN
功能: 移动目标 HUD

  背景:
    假如玩家开始移动目标射击
    而且目标速度为 4m/s
    那么系统应显示移动靶第一人称 HUD
    而且玩家应位于卧姿固定射击点
    而且大型设置 UI 已在拾枪后隐藏

  场景: 训练开始前等待 3 秒
    当 HUD 加载完成
    那么系统应显示等待开始状态
    而且目标在倒计时结束前不应移动
    而且玩家扳机输入不应计入射击记录

  场景: HUD 显示训练状态
    当目标开始从右向左移动
    那么 HUD 应显示弹药 10 发
    而且应显示“两发起射 / 长按连射”模式
    而且应显示命中 0/10
    而且应显示目标速度 4m/s
    而且应显示方向右→左和状态可射击

  场景: 快速扣动一次固定射出两发
    假如目标处于可射击状态
    而且当前弹药不少于 2 发
    当玩家快速扣动并释放右手 Trigger
    那么系统应接受一个具有唯一 SequenceId 的射击序列
    而且该序列应按配置间隔产生恰好 2 发有效射击
    而且弹药应减少 2 发
    而且 HUD 应逐发刷新剩余弹药和命中数

  场景: 长按扳机在前两发后继续连射
    假如目标处于可射击状态
    而且当前弹药为 10 发
    当玩家扣住右手 Trigger 并在第二发后继续保持
    那么前两发应与快速扣动使用相同的射击间隔
    而且第二发之后应按配置射速继续逐发射击
    而且每发有效射击只消耗 1 发弹药
    当玩家释放右手 Trigger
    那么系统不应再生成新的射击

  场景: 长按连射在禁射阶段立即终止
    假如玩家正在保持 Trigger 连射
    当目标进入左端 2 秒停留
    那么当前连射序列应立即终止
    而且停留期间不应继续消耗弹药或生成射击记录
    当目标离开左端并恢复可射击
    那么系统不应因扳机仍被按住而自动恢复射击
    而且玩家必须先释放并重新扣动 Trigger 才能开始新序列

  场景: 长按连射在弹药耗尽时停止
    假如目标处于可射击状态
    而且当前弹药为 10 发
    当玩家持续按住右手 Trigger 直到弹药耗尽
    那么系统应产生恰好 10 发有效射击
    而且弹药不得小于 0
    而且系统不应产生第 11 发射击

  场景: 命中目标后更新命中数
    当一次射击序列中的子弹命中侧身跑步靶
    那么命中数应增加对应命中发数
    而且命中反馈应在 HUD 中刷新

  场景: 目标到达左端后禁止射击
    假如目标到达左侧端点并进入 2 秒停留
    当玩家扣动扳机
    那么系统不应消耗弹药
    而且不应新增射击序列或子弹记录
    而且 HUD 应提示端点停留禁射

  场景: 目标抵达右侧终点后进入结算
    假如目标完成右→左→右运动
    当目标抵达右侧端点
    那么系统应结束训练
    而且进入“移动目标射击 训练结算”
    而且结算 UI 应自动显示在卧姿玩家正前方
    而且有效射击应被禁用

  场景: 卧姿移动靶模式不提供人工移动
    当玩家输入连续移动、传送或无 VR 平移命令
    那么玩家根节点不应离开卧姿固定射击点
    而且目标运动和射击计时应继续由玩法状态机推进
    但是 HMD 和双手的真实跟踪姿态仍应正常更新
```

## Unity 验收点

- 移动靶运动、端点停留和可射击状态应由状态机控制，测试可快进时间。
- P2 必须实现两发起射和长按连射；起射两发为一次已接受的最小射击单元，持续段逐发校验弹药与可射击状态。
- 连射间隔由可注入配置与测试时钟驱动，不得直接依赖帧率或在 UI/场景脚本中计时。
- P2 必须复用 P1 的输入适配，支持无 VR 输入替身和真实 XR 输入两条测试路径。
- 大型交互 UI 在实弹阶段隐藏；最小只读 HUD 可保留，但不得遮挡觇孔和移动目标。
