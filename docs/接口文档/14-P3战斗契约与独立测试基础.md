# 14 P3 战斗契约与独立测试基础

版本：P3.Contracts.v1，2026-09-10。task001 负责契约、配置校验与测试替身；生产战斗、任务结算、UI 与场景分别属于 task004/007/010/013 及对应 UI/场景 task。技术候选可编译验证不等于审核人/实机签核。

## 冻结规则（C01–C16）

| 项 | v1 决定 |
|---|---|
| C01 移动姿态 | P3 Running 且存活时允许地面连续移动与 30° 离散转向，禁传送/攀爬。站/蹲/卧速度默认 1.5/0.9/0.4 m/s；无 VR 眼高 1.65/1.1/0.65m。VR 姿态只改变逻辑/身体碰撞体，眼高来自 HMD，不强推头部高度；正常移动仅由 Locomotion 适配器移动玩家根。暂停/终局停人工移动、开火和攻击，真实头手跟踪保留。P1/P2 策略不变。 |
| C02 武器 | P3 固定 SingleShot，每次有效按下发一发；不继承 P2 两发起射。双手有效且有跟踪才允许开火。初始 30/120，总量 150，换弹默认 2s，保留弹匣余弹并从备用补足，不自动换弹。不新增高拟真装填。 |
| C03 伤害 | 玩家默认生命 100，敌人可见且无遮挡、距玩家≤30m、夹角≤60°，才可每 1s 攻击一次，命中伤害 10。数值为可注入原型配置。敌人接受一次有效命中即死亡，本局尸体保留。伤害去重键为 SessionId+EventId，射击命中另带 ShotId。 |
| C04 场景事实 | 感知/命中/区域/导航结果由 ICombatWorldInputPort 提交值类型输入，含 SessionId、EventId、Tick；服务只依赖事实。ICombatSceneView.Apply 消费完整视觉快照；不含 Transform/Collider/Canvas/XR 类型。时钟 ICombatClock、随机 ICombatRandom、导航 ICombatNavigationPort 可替换。 |
| C05 地图 | 稳定 MapId：trench-a、urban-a；SceneId：TrenchScene、UrbanScene。实际敌人位置从场景预先校验的候选点中无放回选择，每点距对应预估中心≤2m且可导航。固定 seed、按 PointId 排序的候选表产生相同结果；无合法候选/容量不足返回 ResourceUnavailable。小地图仅发布预估中心，不能发布候选点/真实偏移。 |
| C06 搜索 | 堑壕无需固定搜索顺序；玩家进入有效搜索节点范围上报 InRange=true 后，服务登记一次完成。无节点、重复 ID 配置非法；范围外命令 InvalidState，未知节点 NotFound，重复已完成节点成功且不增加修订号。 |
| C07 队形 | 玩家最前，二号沿玩家行走路径落后 1.5m 朝前，三号再落后 1.5m 朝后。导航失败保持当前位置并上报失败，1s 后可重试；不瞬移/拉动玩家。CommandMenuAvailable=false，可用命令为空；Issue/OnReloadStarted 的战术行为返回 InvalidState。 |
| C08 入口 | 街道仍有敌人时允许范围内进入并显示风险，保留街道敌人/计数；玩家可以经同一入口返回街道（ExitBuilding）。建筑切换不换 Session。入口范围外 InvalidState，未知入口 NotFound。街道残敌始终阻止胜利。 |
| C09 房间 | 合法范围内 OpenRoomDoor 后 Unsearched→Searching；在检查区确认 MarkRoomSearched 且该房间活敌为零才变 Searched。空房也须开门并确认检查。重复开门/已搜索成功不重复计数。ObserveRoom 及复杂观察/伸枪为 Later，隐藏入口，直接请求 InvalidState。 |
| C10 结算 | 同一 Tick 先归集全部输入，先处理伤害/死亡，再击杀/搜索，最后评估结果；生命归零优先失败。终局不可变，只结算一次；重复同一终局查询返回既有结果，旧会话输入 NotFound；Cancelled 不生成胜负结果。 |
| C11 查询事件 | ITrenchService/IUrbanService 增加 GetSession/GetResult、Cancel、SessionChanged/ResultReady，完整快照携带 Revision（单会话严格递增，只在有效变更时递增）；UI 以 SessionId+Revision 防过期。HUD 继续使用 IHUDService；队伍和楼层状态包含在任务快照中。 |
| C12 地图 B | GetMaps 只返回 P3 已交付地图 A；B 场景标 Later，未开放配置不生成会话，未知/B 选择 NotFound。 |
| C13 Later | BDD 15 的自动换弹掩护、BDD 16 全部、BDD 20 的复杂观察/伸枪带 @Later；不纳入 P3 必验。普通枪线与环境碰撞仍要有效。 |
| C14 保存 | ICombatSummaryStore.SaveLatest/GetLatest 按 TrainingMode 保存最近结果摘要，包含 SessionId/MapId/Victory/ElapsedSeconds/RemainingAmmo/CompletedAtUtc。失败 PersistenceFailed，保留结果供重试，仍可返回主菜单；不新增档案浏览或长期历史。 |
| C15 ID | UI/场景公共 ID 与配置校验见下表；重复或空 ID 为 InvalidInput，资源尚未就绪 ResourceUnavailable。快照含稳定实体 ID、地图资源键、当前楼层与门状态。 |
| C16 性能 | 原型预算配置为目标 72Hz（13.89ms 帧预算），CPU/GPU 各≤11ms、稳定战斗托管分配目标 0B/frame、单场景加载≤5s。该预算是验收目标，不是已有测量；实际设备型号由场景/审核在实机 D 登记，不阻塞纯契约验证。最坏配置：堑壕5、城镇2+6敌人及2队友，尸体全部保留；热机后采样60s。 |

## 程序集与兼容

共享 Contracts、Dto、Enums 由 VRShooting.Contracts 编译，允许 Unity 数学值类型，禁止 UI、XR、场景程序集依赖。既有命名空间、文件路径、.meta GUID 和枚举序号保留；新增枚举只追加。运行时 VRShooting.Runtime 显式引用该程序集。

Trench/Urban/战斗 DTO 复用 AmmoDto、PlayerStatusDto、SquadStatusDto、HudDto、MiniMapDto、RandomSeed、ServiceResult。新增 DTO 的集合 getter 默认空且 init 时复制成只读集合；字符串默认空；显式 Empty 不包含假的胜利/有效会话。既有 DTO 的默认语义不改变。

测试替身单独编译到 VRShooting.P3.TestSupport，仅 UNITY_INCLUDE_TESTS/TestAssemblies 可见，不注册到 ApplicationServices 或生产场景。假服务按脚本快照返回，不实现完整伤害/搜索/胜负规则。

## 公共结构与端口

- TrenchMapDto/TrenchBriefingDto/TrenchSessionDto/TrenchResultDto 继承接口08字段；Session 新增 Revision，Result 新增 Revision。
- UrbanMapDto/FloorDto/RoomDto/UrbanSessionDto/UrbanResultDto 继承接口09字段；Session 新增 State、Revision、CurrentFloorId、Floors；Result 新增 Revision、FloorMaps；RoomDto 新增 DoorOpen，FloorDto 新增 MiniMap。
- CombatConfigDto：生命、攻击范围/夹角/间隔/伤害、步速/姿态眼高、转向角、换弹时间、队伍间距、生成偏移半径、目标刷新率/CPU/GPU/GC/加载预算；Default 提供上表值，Validate 返回 ServiceResult<Unit>。
- CombatSceneDefinitionDto：MapId/SceneId/Mode/EntranceId、Projections、SpawnPoints、SearchNodes、Floors。SceneSpawnPointDto：PointId、EstimateAreaId、Group、FloorId、RoomId、WorldPosition、EstimatePosition、Navigable。Group 为 Trench/Street/Building。MapProjectionDto：FloorId、ResourceKey、WorldBoundsXZ。
- CombatInputDto：SessionId/EventId/Tick、Kind、EntityId/TargetId、Position/Direction、Value、Flag；Kind 为 PlayerPose/Posture/Hit/Perception/AreaPresence/NavigationResult。Hit.Value 为伤害，Hit.TargetId 为受击者，Hit.ShotId 为射击唯一键；Perception.Flag=可见且无遮挡、Value=距离；AreaPresence.EntityId=区域ID、Flag=范围内；NavigationResult.Flag=到达。字段校验由生产服务实现，Fixture 只记录输入。
- CombatVisualSnapshotDto：SessionId/Revision、Entities、Doors。CombatEntityVisualDto：EntityId/Role/State、Position/Forward、CorpseVisible；CombatDoorVisualDto：RoomId/Open。角色 role 为 Player/Teammate/Enemy；状态 Spawned/Idle/Attacking/Dead；导航命令包含 SessionId/RequestId/EntityId/Tick/Destination/Forward。
- ICombatClock：double Now、long Tick；ICombatRandom：Reset(RandomSeed)、NextInt(minInclusive,maxExclusive)；ICombatNavigationPort：ServiceResult<Unit> Move(CombatNavigationRequestDto)。
- ICombatWorldInputPort：ServiceResult<Unit> Submit(CombatInputDto)；ICombatSceneView：void Apply(CombatVisualSnapshotDto)。
- ICombatStateService：GetPlayer、GetSquadStatus、GetVisualSnapshot、PlayerChanged/SquadChanged/VisualChanged；均按当前 SessionId 查询，事件快照带 SessionId+Revision。
- ICombatSummaryStore：SaveLatest(CombatSummaryDto)、GetLatest(TrainingMode)；空记录 NotFound，非法 mode/input InvalidInput。

这些是基础接口，不代表生产状态机在 task001 实现。生产接口签名见同名 C# 文件与08/09，本文件定义新增语义。

## 统一命令错误

空参数/非法数值 InvalidInput；未知实体/会话/地图 NotFound；合法 ID 但阶段/范围/状态不许可 InvalidState；加载或执行中 Busy；资源不可用 ResourceUnavailable；存储失败 PersistenceFailed。失败不变更状态、不发变更事件。重复同一有效状态命令返回当前快照，不增加 Revision。Cancel 对已取消的当前会话幂等，过期会话 NotFound。

## 导航与稳定 ID

UIEventId 保留已有0–19，追加 Trench_SelectMap/Start/ViewMap/Retry/BackToMainMenu、Urban_SelectMap/EnterBuilding/ExitBuilding/OpenRoomDoor/MarkRoomSearched/Retry/BackToMainMenu。开始需配置/场景已就绪；SelectMap 本身不创建实体。Trench_Start 调 StartSession；Urban_SelectMap 的应用命令先 SelectMap 再 StartSession，成功后进街道。重试 Cancel 旧局并回准备，返回先保存已有结果再 Cancel。具体装配在 task013。

| 用途 | 稳定值/格式 |
|---|---|
| 页面 | Screen_TrenchMapSelection/TrenchBriefing/TrenchHud/TrenchResults、Screen_UrbanMapSelection/UrbanStreetHud/UrbanBuildingHud/UrbanResults |
| 按钮 | Button_<ScreenId>_<Action>；Action 与任务中的 SelectMap/Start/ViewMap/Back/Retry/BackToMainMenu/EnterBuilding/ExitBuilding/OpenDoor/CheckRoom 对齐 |
| HUD | Hud_<Trench/UrbanStreet/UrbanBuilding>_<Health/Ammo/MiniMap/Squad/Posture/Shoulder/SearchProgress/Rooms/Prompt> |
| 场景锚点 | <Trench/Urban>.Anchor.<Player/Weapon/Briefing/Hud/Results> |
| 地图节点 | trench-a.node-001…；urban-a.entrance；urban-a.floor-1/2/3；urban-a.room-001… |
| 生成点 | <MapId>.spawn-001…；预估区域 <MapId>.estimate-001… |
| 实体 | <SessionId>.player / teammate-2 / teammate-3 / enemy-001… |
