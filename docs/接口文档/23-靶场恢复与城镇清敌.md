# 23 靶场恢复与城镇清敌

2026-10-23 对应BDD31，覆盖接口22的视觉前移和接口09/17的搜索胜利前置。任务沿用P1玩法task006/013与场景task012、P2场景task006/玩法task007、P3玩法task004/010/013与场景task009。

- 两个靶场保存文件恢复`54073a0`的完整末端靶排，构建流程移除RangeVisualDistanceMigration及RangeAssistanceSceneMigration调用。恢复原100m布局，不新增靶、辅助环或改变FOV/HMD；继续使用显式靶面厘米坐标、同发服务弹着、实际补偿及本轮建议。
- 靶场枪械的展示后坐应在P2默认两发间隔之前回正。旧3度左右的枪口后坐若持续0.3秒，会让100m的第二发偏离数米；回正时程缩至80ms，保留峰值后坐、位移、触觉和真实枪线。只作用于靶场场景控制器，P3武器配置不变。
- 模式四拾枪位置由当前PlayerCamera实际位置和水平朝向计算，后握把在视线前约0.45m、下方约0.28m；按真实后握把偏移放置枪体，避免枪身原点或旧根节点朝向造成不可达。玩家HMD不移动，保留XRI后手/支撑手门禁；重试重建一把枪。桌面入口保留E拿枪/G支撑。
- 模式四建筑生成仍为固定种子3–6名，街道1–2名保持既有契约；六个已有建筑候选点放在房间角落，复用实体ID、FloorId、RoomId，检查NavMesh及墙/地板间距。服务仅从候选点生成，场景不直接计算击杀或胜负。
- UrbanService胜利条件改为玩家存活、当前批次已完成处理、本局所有敌人均死亡。房门和搜索API保留查询/交互兼容，但搜索数不再是胜利门槛，结果保留真实搜索数量，不伪造全部搜索。保留死亡优先、重复结果幂等、重试和旧会话隔离。
- HUD与结算目标文字应明确“消灭全部敌人即可完成”，不能继续提示必须搜索全部房间。未击杀实体或仅伪造RegisterEnemyKilled命令不能通关。
- EditMode验证全歼无搜索成功、剩余敌人阻挡、死亡优先与幂等；PlayMode验证恢复后的100m真实枪线、两发前回正、模式四实际枪与后握把可见/可达、角落敌人可击中、零房间确认的生产胜利与重试。VR实际取枪和舒适度单列待验。
