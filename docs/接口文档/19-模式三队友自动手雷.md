# 模式三手雷扩展

本次用户要求覆盖历史 Later 中的“模式三队友自动手雷”子集，不启用环形菜单或城镇技能。

- `SquadGrenadeTacticService` 负责确定性选队友/敌群、准备动作、飞行/落地延迟、冷却；没有场景端口时不运行。按队友ID和敌人ID排序，遍历可覆盖的敌对，选择覆盖最多的落点，数量相同保留稳定顺序。
- `ICombatGrenadeWorld` 提供队友实测位置/脱手点、球扫碰撞和实体遮挡事实。服务使用核心敌人快照判定数量/死亡；场景不计算伤害和胜负。
- `GrenadeThrowPlanDto` 描述唯一GrenadeId、SessionId、ThrowerId、起终点、准备/飞行/爆炸时间；`GrenadeTrajectory.Position` 为规则和表现共享抛物线。服务暴露当前计划、进度与实际位置；渲染不能独立用Time.time倒计时炸雷。
- 核心 `ApplyGrenadeExplosion` 在无待处理输入边界校验Session、来源、半径、目标列表并去重，生成普通EnemyHit/EnemyDied事件。返回已死亡敌人ID。伤害事件不携带无穷值。爆炸后由任务服务重新对账并判胜；同批玩家死亡优先取消未爆炸雷。
- `ICombatSceneLease.Activate` 接收手雷服务（城镇为null）；模式三先绑定模型/VFX资源，再配置世界查询端口。资源缺失明确返回ResourceUnavailable，不能用球体冒充导入模型。
- `ICombatGrenadeTacticService.RequestFirstTeammateThrow` 是模式三唯一投掷命令。Unity XR 适配器把右手手柄 primaryButton（A）转换为该命令；命令只选择队友二号，仍执行范围、遮挡、冷却和两名敌人门禁。未收到命令时服务不自动投掷。VR换弹改为左摇杆按下。
- 暂停/追踪丢失/终止清空当前计划与投掷动作；冷却不因暂停跳过。Dispose退订核心和表现回调。重试新Session清空雷和爆炸特效。
- 队友DTO沿用ThrowingGrenade状态，导航在准备/抛出动作结束前暂停。Prefab模型规范高度0.11游戏米，按原始比例统一缩放，标准PBR使用BaseColor、Normal、Metallic与1-Roughness作为Smoothness。
