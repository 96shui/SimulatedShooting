# 模式三手雷扩展

2026-10-04 可见性修订：世界端口的队友脚底高度取实际地表，脱手点取地形对齐后的 VisualRoot 投掷动作终点，并保证高于地表。提供服务位置源的 CombatGrenadeProjectile 不使用独立寿命计时销毁；由 GrenadeExploded/GrenadeCancelled 清理。

本次用户要求覆盖历史 Later 中的“模式三队友自动手雷”子集，不启用环形菜单或城镇技能。

- `SquadGrenadeTacticService` 负责确定性选第一名队友/最近的存活敌人、准备动作、飞行/落地延迟、冷却；没有场景端口时不运行。等距离按敌人ID稳定排序。18米内瞄准敌人位置，超过18米则沿敌人方向落到18米处；实际碰撞可提前终止飞行。
- `ICombatGrenadeWorld` 提供队友实测位置/脱手点、球扫碰撞和实体遮挡事实。服务使用核心敌人快照判定数量/死亡；场景不计算伤害和胜负。
- `GrenadeThrowPlanDto` 描述唯一GrenadeId、SessionId、ThrowerId、起终点、准备/飞行/爆炸时间；`GrenadeTrajectory.Position` 为规则和表现共享抛物线。服务暴露当前计划、进度与实际位置；渲染不能独立用Time.time倒计时炸雷。
- 核心 `ApplyGrenadeExplosion` 在无待处理输入边界校验Session、来源、半径、目标列表并去重，生成普通EnemyHit/EnemyDied事件。返回已死亡敌人ID。伤害事件不携带无穷值。爆炸后由任务服务重新对账并判胜；同批玩家死亡优先取消未爆炸雷。
- `ICombatSceneLease.Activate` 接收手雷服务（城镇为null）；模式三先绑定模型/VFX资源，再配置世界查询端口。资源缺失明确返回ResourceUnavailable，不能用球体冒充导入模型。
- `ICombatGrenadeTacticService.RequestFirstTeammateThrow` 是模式三唯一投掷命令。Unity XR 适配器兼容 Input System 与 OpenXR 的右手 primaryButton（A），在采样时锁存按下沿；无 VR 的 H 键走同一命令。命令只选择队友二号，朝最近的存活敌人投掷，不预先以敌人数量或抛物线通畅度拒绝命令。上次投掷后至少3秒才接受下一次；未收到命令时服务不自动投掷。VR 换弹为左摇杆按下。
- 暂停/追踪丢失/终止清空当前计划与投掷动作；冷却不因暂停跳过。Dispose退订核心和表现回调。重试新Session清空雷和爆炸特效。
- 队友DTO沿用ThrowingGrenade状态，导航在准备/抛出动作结束前暂停。Prefab模型规范高度0.11游戏米，按原始比例统一缩放，标准PBR使用BaseColor、Normal、Metallic与1-Roughness作为Smoothness。

2026-10-05 覆盖旧0.11米规范：视觉高度0.16米，归一化/居中仅作用于模型子节点；投射物世界节点缩放1，原Renderer显式启用，视觉碰撞体禁用。Sweep返回接触点加法线0.085米，落地停止翻滚，爆炸/取消统一移除。接口签名不变。

落地表现补充：服务实际位置停止后，准备阶段之外的模型恢复直立姿态，防止飞行翻滚后的垂直包围盒穿入地面；不改变服务位置和爆炸计时。


2026-10-07 手雷模型可见性修订：投掷根节点保持世界单位缩放，M67显示高度调整到22cm；强制可见LOD与不透明双面URP材质，降低金属度并增加很低的环境可读性补光。缺失模型/Renderer时输出明确警告。保持3秒冷却、轨迹、碰撞、爆炸和伤害规则不变。按用户要求不运行测试用例，编辑器直接检查实际投掷入口生成的模型尺寸与渲染。
