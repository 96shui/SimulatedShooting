# 15 P3 共用战斗核心（task004，v1.1）

2026-09-14。在接口14候选契约之上细化本线生产实现；不替代独立签核，不实现任务搜索/队形/胜负页面。task007/010/013 消费核心快照与反馈。

## API 与快照

`ICombatCoreService : ICombatWorldInputPort, IDisposable`：`Start(sessionId, mode, enemies)`、`GetSnapshot(sessionId)`、`SetState(sessionId, SessionState)`、`SetTracking(sessionId, bool)`、`SetGrip(WeaponGripStateInputDto)`、`SetPosture(sessionId, PlayerPosture)`、`ToggleShoulder(sessionId)`、`SetCornerAvailable(sessionId, bool)`、`Fire(WeaponFireInputDto)`、`Reload(sessionId)`、`Advance(sessionId)`，以及 `Changed(CombatCoreSnapshotDto)`、`Feedback(CombatFeedbackDto)`。

Start 只接受 Trench/Urban 和新的非空 SessionId；敌人配置只含稳定 EntityId/Position/Forward，拒绝重复、玩家ID、非有限值、零朝向。敌人数量/随机分布由任务层决定；核心没有隐藏随机。启动即 Running、生命100、训练步枪30/120单发、未持枪。核心内部复用 WeaponControlService，禁止 UI 绕过核心直接改武器状态。

CombatCoreSnapshotDto 含 SessionId/Revision/State、PlayerStatusDto、AmmoDto、WeaponControlStateDto、CombatVisualSnapshotDto；查询和事件为同一不可变快照。有效变化才递增，事件订阅可退订，Dispose 清空订阅与会话。该核心不提供虚假的队伍数据；ICombatStateService 的队伍聚合由 task007/013 完成。

CombatFeedbackDto 包含 SessionId/EventId/Tick、Kind（ShotFired/EnemyHit/EnemyDied/EnemyAttack/PlayerDamaged/PlayerDied）、EntityId/TargetId/ShotId、Damage。ShotFired 携带有效射击的 ShotId；Fire 返回 CombatShotDto(ShotId, WeaponShotResultDto)。音效/确认反馈消费 EnemyHit，同一死亡只通知一次；尸体一直在视觉快照中。

## 时钟、事实与幂等

时钟单调；输入 Tick 必须等于当前 ICombatClock.Tick，过期批次 InvalidState。调用方先采集当批次全部事实，Submit 排队，最后 Advance。相同 SessionId+EventId 幂等；相同 ID 不同载荷 InvalidInput。未知会话/实体 NotFound、非法数值 InvalidInput、不支持 Kind 或禁止阶段 InvalidState。失败不发 Changed。队列在暂停、失踪、退出与新局时清空。

Perception.EntityId 为敌人，TargetId 为玩家，Flag 表示无遮挡，Position 是敌人位置，Direction 是敌人朝向；服务从玩家姿态与敌人姿态重新计算距离/视角，不信任 Value 单独放行。PlayerPose.Position/Direction 更新玩家位置朝向。新发现时从当前 Now+间隔安排首次攻击，不追溯新发现之前的时间；失去视线立即取消截止时刻，重新发现重新计时。保持可见期间按固定截止时刻推进，大步长与多个小步长同样累计，按时刻再按实体ID稳定排序；死亡后立即停止，无补偿爆发。

当批次先应用姿态/感知事实，再处理玩家伤害及已到期敌人攻击，之后处理玩家射击命中。外部 Hit 指向玩家时必须来自当前可攻击的敌人、数值等于配置伤害且达到该敌人下一攻击时刻；它消费同一攻击截止时刻，不额外叠加自动攻击。内部伤害也携带唯一事件ID。玩家生命下限0、死亡一次、状态Failed；同批次已发出的有效玩家子弹仍可杀敌，供任务层执行死亡优先失败。

Hit 指向敌人必须来自本会话玩家、携带核心已发出的 ShotId、Flag=true（枪线第一碰撞命中），每发最多命中一个实体；更换 EventId 不能重复使用子弹。敌人一次有效命中死亡，不再射击。枪线被环境先挡住则消耗正常射击弹药，但不提交敌人命中。

## 武器、生命周期与输入

双手有效且头手跟踪正常、Running、存活、非换弹、有弹才 CanShoot。Reload 由时钟等待配置2秒，保留余弹并补足；满弹匣幂等，不自动换弹。暂停/终局/跟踪失效取消未完成换弹，弹药不变；恢复后重新换弹。终局不可恢复Running；新局必须新ID，旧事件不污染。

`CombatInputController` 复用 IXRTrainingInput，外部 CombatInputFrameDto 提供当前武器近距握持事实、头手跟踪、枪口/枪线、姿态选择及真实VR标志。只有真实握把范围事实和Grip共同成立才认可拾取；追踪丢失清持枪并要求重新松按Trigger。每帧只识别一次Trigger上升沿，持续按压不连射。换肩修改服务状态，枪口数据由绑定提供方按该状态给出。

`ICombatLocomotionPort.Apply(CombatLocomotionIntentDto)` 输出地面移动速度、30度离散转向、逻辑姿态与无VR眼高（VR时 nullable 为空，绝不强改相机高度）。P1/P2禁人工移动/转向；暂停/失踪/终局输出零意图，真实跟踪保留。端口失败返回失败，不由核心直接修改Transform。导航继续使用接口14，队伍路径实现在task007。

`ICombatShotQuery.Cast(origin, direction)` 返回第一碰撞（CombatRayHitDto）；Unity适配器使用环境与实体同一次Physics.Raycast，忽略Trigger，以稳定实体绑定报告敌人。枪口近距离重叠环境也阻挡，不能从墙内穿出；碰撞层必须包含环境且排除持枪自身。核心不引用Physics/Collider，真实场景绑定由task006/012完成。

## 验证范围

参数还需满足伤害在初始生命精度下能实际降低数值；时钟必须能表示下一攻击/换弹时刻，否则 InvalidInput，避免极端注入值令循环不收敛。终局后跟踪命令幂等返回、快照不变。消费者可在事件回调中 Dispose，取消剩余反馈；回调中重入其他写命令返回 Busy。

输入帧同时包含 PlayerPosition/PlayerForward，由绑定提供方采集当前玩家根状态；控制器每个时钟 Tick 只能 Step 一次。移动意图包含 DeltaSeconds/BodyHeight，CharacterController 负责身体碰撞与根移动；真实VR不写眼高。每次完成本批次采样后调用 Step（或直接 Advance），禁止带着未处理事实跨 Tick。
