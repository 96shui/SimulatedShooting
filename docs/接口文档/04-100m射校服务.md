## 业务规则

- 每局最多 3 轮，每轮 3 发。
- 开局生成一次固定弹着偏移，3 轮共用。
- 10 环判定为距中心 `<= 5cm`。
- 垂直调整：偏上提示准星柱逆时针，偏下提示顺时针。
- 水平调整：偏左提示觇孔向前，偏右提示向后。
- 水平一格 2cm，向上取整。
- 23cm 一周，0.064cm 约等于 1 度。
- `AverageOffsetCm` 为本轮 3 发 X、Y 坐标分别求算术平均，保持只读；默认 `ProposedCorrectionCm = QuantizeCorrection(-AverageOffsetCm)`，`PreviewAverageOffsetCm = AverageOffsetCm + ProposedCorrectionCm`。
- `AdjustImpactPoint` 的 `direction` 只能为 `-1` 或 `+1`，每次仅在指定轴调整：水平 2cm、垂直 0.32cm，并将该轴待应用补偿限制在 ±50cm。X 正向为右，Y 正向为上；返回最新预览 DTO，不修改已发射的记录。
- `ApplyAdjustment` 将 `ProposedCorrectionCm` 一次性加到后续射击使用的 `FixedImpactOffsetCm`，同轮重复调用幂等；`CurrentAdjustment` 按实际应用的两轴补偿量记录准星柱角度和觇孔格数。进入下一轮后重置待应用补偿。
- 第一轮通过为优秀，第二轮良好，第三轮及格，未通过不及格。

## 错误处理

| 条件 | 错误码 |
|---|---|
| Session 不存在 | NotFound |
| 弹数为 0 仍记录射击 | InvalidState |
| 一轮未满 3 发请求分析 | InvalidState |
| 同一轮重复应用调整 | None，返回原分析结果 |
| 未完成 3 发或已应用后继续调节 | InvalidState |
| 调节轴无效或方向不是 ±1 | InvalidInput |
| 第 3 轮后请求下一轮 | InvalidState 或返回最终结果 |
