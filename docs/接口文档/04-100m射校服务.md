# 04 100m 射校服务契约

仅适用于模式一；行为以 BDD04–07 为准。100m、单发、每轮 4 发、最多 3 轮。`RandomSeed` 可复现，固定偏移每轴独立取有符号 5–20cm（含端点），只在开局生成；应用调整按 `固定偏移 += 本轮实际补偿` 传到后续轮。

## DTO

- `ZeroingSessionDto`：`SessionId`、`CurrentRound`、`MaxRounds`、`ShotsRemainingInRound`、`DistanceMeters`、`FixedImpactOffsetCm`、`CanShoot`、`CurrentAdjustment`。
- `ZeroingShotDto`：`RoundIndex`、`ShotIndex`、`ImpactPointCm`、`WeaponStability`、`InsideTenRing`、`MissedTargetPlane`。有效弹着为未脱靶且两轴绝对值均≤25cm。
- `SightAdjustmentDto`：`RearSightClicks` 正向前、负向后；`FrontSightDegrees` 正顺时针、负逆时针。初始 +1 格、+5°。
- `ZeroingRoundAnalysisDto.Shots` 保存全部四发；UI 显示四发全部记录，不对被舍弃的一发做额外标注或视觉区分；无法投影或靶外发次在靶图旁显示带脱靶标签的记录标记，不伪造靶内坐标；`AverageOffsetCm` 是计算集三发的平均（无计算集时为零）；`CalculationSetAvailable` 表示是否形成三发计算集，`SpreadRulePassed` 是集中是否成立，`SpreadRejected` 是分散，`DiscardedShotIndex` 是原始 Shots 零基索引，无舍弃为 -1；`AppliedCorrectionCm` 为本轮实际应用补偿，未应用为零。
- `ProposedCorrectionCm` 为当前待应用补偿，初始零；`PreviewAverageOffsetCm = AverageOffsetCm + ProposedCorrectionCm`。蓝点定位于 `ProposedCorrectionCm`，不用于通过判定；黄点定位于 `AverageOffsetCm`。
- `CurrentAdjustment`、`FixedImpactOffsetCm`、`ProposedAdjustment` 继续提供机械和偏移读数；`PredictedOffsetMagnitudeCm` 是计算集均值加待应用补偿的模长（已应用时加实际应用量），`PredictedOffsetPasses` 由服务按集中且模长严格小于 5cm 计算，UI 只显示该结论；`VerticalDirection`、`FrontSightDegreesToAdjust`、`HorizontalDirection`、`RearSightClicksToAdjust` 为计算集均值生成的建议；`PassedTenRing` 保留字段名，含义为满足任一新通过路径；`AdjustmentApplied`、`FinalResultAvailable` 表示应用和终局状态。
- 新增字段只用于 P1；`Empty` 中舍弃索引为 -1，其余新增值为 false/零；默认结构体不得改变模式二三四语义。
- `ZeroingResultDto`：`SessionId`、`Grade`、`PassedRoundIndex`、`Rounds`。未通过为 0；第 1/2/3 轮通过分别优秀/良好/及格，三轮未过不及格。

## 类型与方法签名

```csharp
public enum VerticalAdjustmentDirection { None, Clockwise, CounterClockwise }
public enum HorizontalAdjustmentDirection { None, Forward, Backward }
public enum ZeroingAdjustmentAxis { Horizontal, Vertical }

public readonly struct ShotInputDto
{
    public Vector3 WeaponPosition { get; init; }
    public Vector3 AimDirection { get; init; }
    public float WeaponStability { get; init; }
    public double FireTime { get; init; }
}

public interface IZeroingService
{
    ServiceResult<ZeroingSessionDto> StartSession(RandomSeed seed, string weaponId);
    ServiceResult<ZeroingSessionDto> GetSession(string sessionId);
    ServiceResult<ZeroingShotDto> RecordShot(string sessionId, ShotInputDto input);
    ServiceResult<ZeroingRoundAnalysisDto> CompleteRound(string sessionId);
    ServiceResult<ZeroingRoundAnalysisDto> AdjustImpactPoint(string sessionId, int roundIndex, ZeroingAdjustmentAxis axis, int direction);
    ServiceResult<ZeroingRoundAnalysisDto> ApplyAdjustment(string sessionId, int roundIndex);
    ServiceResult<ZeroingSessionDto> ContinueAfterAnalysis(string sessionId);
    ServiceResult<ZeroingResultDto> GetFinalResult(string sessionId);
}
```

`direction` 只接受 -1 或 +1，水平符号为负向后/正向前，垂直符号为负逆时针/正顺时针。`FinalResultAvailable` 在已通过或完成第三轮时为真；第三轮集中但尚未通过时仍允许应用一次调整。显示、按钮和建议只能使用服务 DTO，不从靶图反算业务结果。

## 规则

四发都有效时，求四发平均并移除距其最远的首个弹着（并列取原始索引最小）；恰好三发有效时不剔除；不足三发分散。对计算集，逐点距三发均值须严格 <10cm，三对间距须严格 <15cm，否则分散。

集中为通过前提。路径一：计算集每发距靶心≤10cm、均值距靶心≤5cm、至少一发距靶心≤5cm，满发当场判定。路径二：应用调整后 `|AverageOffsetCm + AppliedCorrectionCm| < 5cm`，等号不通过。两条为或，均不读取蓝点或固定偏移模长。

水平向前/向后补偿 X 分别 +2/-2cm；垂直顺时针/逆时针补偿 Y 分别 +0.32/-0.32cm；初始待应用量零。水平每格 2cm 限 ±50cm，垂直 5° 为 0.32cm 限 ±49.92cm；建议偏上逆时针、偏下顺时针。

## 接口及错误

`IZeroingService` 提供 `StartSession`、`GetSession`、`RecordShot`、`CompleteRound`、`AdjustImpactPoint`、`ApplyAdjustment`、`ContinueAfterAnalysis`、`GetFinalResult`。缺失会话返回 `NotFound`；未满四发、已应用后修改、已通过后调整或分散时调整/应用返回 `InvalidState`；轮次或方向无效返回 `InvalidInput`。同轮重复应用幂等。分散轮允许不应用而继续下一轮，第三轮允许查看评级。

`ZeroingShotRecordedEvent` 通知逐发数据，`ZeroingRoundCompletedEvent` 在第四发后仅发布一次，`ZeroingAdjustmentAppliedEvent` 与 `ZeroingRoundStartedEvent` 分别通知应用和新轮。场景层订阅轮次完成事件并清除当前训练靶各实例的物理弹孔，应用层不引用 Unity 场景对象；分析 UI 与结算图按 DTO 渲染。

## 测试

EditMode 覆盖计算集、并列、有效数、集中边界、两条通过路径、方向/量化、分散拒绝、轮次及幂等。PlayMode 覆盖四点无额外标注、脱靶标签、按钮状态、蓝点及弹孔清理；VR 实机验证可读性和交互。
