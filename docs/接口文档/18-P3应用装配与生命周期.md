# P3 应用装配与生命周期（task013）

本扩展不修改 task004/007/010 的玩法判定。公开类型位于 Contracts 程序集，应用实现位于 `Runtime/Application/Combat/`。

- `ICombatSceneLoader.LoadAsync(mode, cancellationToken)` 返回独占的 `ICombatSceneLease`。加载只准备场景、定义、时钟和导航，不创建战斗角色。即使底层 Unity 加载不可取消，也必须把迟到的 lease 返回给调用者清理，不得修改另一轮加载的场景或全局服务。
- lease 提供 `Definition/Clock/Random/Navigation`。`Activate(core, world, state, hud, squad, tick, sessionId)` 在服务创建 Session 后绑定输入、导航、角色、HUD；每帧先收集事实和输入，再调用 `ICombatTickPort.Advance()` 统一推进玩法任务（只推进 core 不能结算搜索任务）。`Deactivate()` 必须幂等且不抛出异常，停止输入、AI 动画与导航、移除角色、退订所有事实/反馈回调。`Dispose()` 同样幂等且不抛出异常，还释放本 lease 拥有的场景，不能释放其他 lease。
- `CombatApplicationCoordinator.OpenMode` 打开模式地图页；`SelectMapAsync` 校验地图后加载。堑壕完成加载进入简报，`Start` 才创建 Session；城镇地图选择完成加载后创建 Session 并进入街道。加载期间其他开始/选择命令返回 `Busy`；再次切模式或返回可取消当前加载。
- `Retry` 仅在结果页有效，清理旧 Session 和场景角色，保留已加载场景、地图、武器和随机种子。堑壕返回简报；城镇重新创建 Session。每次创建使用新 SessionId，旧回调不能改变新页面。
- `BackToMaps` 取消当前 Session，释放场景并返回本模式地图。`ReturnToMainMenu` 在有结果时先调用 `ICombatSummaryStore.SaveLatest`，成功才释放场景并回主菜单；`PersistenceFailed` 保留结果页，允许再次保存。正在进行的训练取消不产生结果摘要。
- `CombatApplicationSnapshotDto` 提供页面、模式、Busy、SessionId、错误与最近结果摘要。`CombatApplicationPresenter` 只将快照交给 `ICombatApplicationView.Render`；业务 HUD、简报、结果继续查询任务服务 DTO，不从 View 反推。
- 全部命令在 Unity 主线程调用。Changed 回调期间重入命令返回 Busy；异步完成通过调用方同步上下文恢复。Dispose 后拒绝命令、退订事件并清理迟到 lease。
- `CombatSummaryFileStore` 每模式仅一个最近摘要，用临时文件和同目录原子替换提交；写入失败保留旧文件。损坏/未知版本返回 `PersistenceFailed`，不存在返回 `NotFound`。不建立历史系统。

## 正式接入门禁

组合根允许注入正式 scene loader 与存储；未注册 scene loader 时返回 `ResourceUnavailable`。禁止默认注册测试 Fixture 或启用未接通的主菜单按钮。UI task002/005/008/011 和场景 task003/006/009/012 的正式产物通过接口验收后，由 task013 完成真实 UI/场景无 VR E2E。替身 PlayMode 仅证明应用生命周期，不能替代该门禁。
