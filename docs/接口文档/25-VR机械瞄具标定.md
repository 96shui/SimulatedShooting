# 25 VR机械瞄具标定

BDD33覆盖将BDD32桌面输入回归当作VR验收的做法；沿用P1功能B task013、场景task012。保持原100m靶场和补偿规则。

- QBZ191的AimLinePoint必须以模型上的实际觇孔中心为原点，以准星柱顶部为方向。源OBJ的X轴经Unity导入镜像，必须核对导入后的真实网格，不能仅沿枪体+Z设置。
- 标定依据：源OBJ后觇孔内圈包络中心约(0.0057315,0.0573025,-0.118108)，前准星柱顶约(0.005689,0.050240,0.228503)，单位米；Unity枪体空间X取反。锚点放在后觇孔中心，旋转沿两点连线。生产Prefab与构建器使用相同标定。
- 服务DTO、补偿、评分和碰撞规则不变。继续从真实枪口指向可见瞄具在靶面上的交点，保留遮挡检测和同发反馈。
- VR只通过真实XRI握持和可替换跟踪/扳机输入取样，不控制HMD、FOV或吸附靶心。相同枪械Prefab共享模型标定，其他模式需回归。
- EditMode验证导入网格、觇孔通光和准星几何对应关系；PlayMode通过真实XRDirectInteractor与XRInteractionManager双手选择，移动跟踪替身而非枪体，验证扳机、两轮射校、头部独立运动及松手禁射。头显实机验收单列，不能由替身冒充。
