# 26 主菜单手部显示保护

BDD34，沿用接口11、P1 UI task008与P3玩法task019。只改Unity显示层，不改服务DTO或命令。

- VRHandPresentation在MainScene中检查对应手柄的isTracked与位置跟踪状态；Input System设备优先，旧XR设备接口回退。
- 未获得位置跟踪、手柄距当前XROrigin相机小于0.15m、对应手臂Renderer包围相机或距离包围盒小于0.03m时，仅设置人物网格forceRenderingOff，不关闭GameObject、交互器、LineRenderer、输入Action或移动HMD。
- 跟踪和距离恢复后恢复网格；定时扫描保留隐藏前状态，组件禁用/场景退出时恢复原渲染标志。非MainScene不启用该保护，保留训练中的手部显示、握持与换弹。
- PlayMode使用真实MainScene、输入动作、TrackedPoseDriver及XR设备状态替身，验证未跟踪、位置恢复、贴头、再次丢失和定时扫描。保留现有真实扳机点击主菜单按钮的回归。
