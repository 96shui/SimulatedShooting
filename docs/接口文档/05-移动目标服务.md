## 两发起射与长按连射规则

1. P2 一次合法 `TriggerPressed` 创建唯一 `SequenceId`，并原子承诺前两发。
2. 接受新序列前至少需要 2 发弹药；不足 2 发时整次拒绝，不生成第一发。
3. 前两发按 `ShotIntervalSeconds` 依次产生；快速释放扳机也必须完成已经接受的两发。
4. 第二发产生后，如果 Trigger 仍处于保持状态，则按相同的可配置间隔继续逐发射击。
5. 持续段每一发单独校验扳机保持、弹药、武器持有/跟踪和 `CanShoot`，每发只消耗 1 发。
6. Trigger 释放、弹药耗尽、进入左端禁射、训练完成或武器失效时，立即停止继续调度。
7. 因禁射或武器失效停止后，即使 Trigger 物理值仍高于阈值，也不得自动恢复；必须检测到释放后再出现新的按下边沿。
8. 所有间隔使用注入时钟或显式 Tick，不能用帧数计数；同一输入时间线必须得到相同射击序列。

## 移动靶业务规则

- 速度只能为 3m/s、4m/s、5m/s。
- 有效拾枪后先等待 3 秒，等待期间 `CanShoot == false`。
- 目标先右到左，再左到右。
- 左端点停留 2 秒，停留期间 `CanShoot == false`。
- 总弹药 10 发；一个长按序列允许消耗 2-10 发，序列数只由实际扣动次数决定。
- 抵达右侧终点后自动结算并终止当前连射。
- 命中 3 发及格，4 发良好，5 发及以上优秀。
- 沿用 P1 训练主武器与觇孔，但 P1 仍保持一次按下只射 1 发。
- Start 命令成功后先进入等待拾枪；有效拾枪后大型设置 UI 隐藏，并从 3 秒倒计时开始推进移动靶状态机。
- 玩家固定在卧姿射击点，人工移动输入不影响路线、Session 或玩家根节点。

## 错误处理

| 条件 | 错误码/处理 |
|---|---|
| 速度非法 | `InvalidInput` |
| 禁射状态开始新射击序列 | `InvalidState`，不耗弹 |
| 弹药不足 2 发时开始新序列 | `InvalidState`，不产生部分起射 |
| 同一 `SequenceId` 重复开始 | 幂等返回已有序列，不重复耗弹 |
| 连射中进入左端禁射/训练完成 | 正常终止序列，不作为服务错误 |
| 未释放 Trigger 就尝试自动恢复 | 安全忽略，等待新的按下边沿 |
| 未完成路线请求结算 | `InvalidState` |

## UI 绑定

- 设置页使用 `GetAvailableSpeeds` 刷新速度按钮。
- HUD 的“可射击/禁止射击”只读取 `CanShoot`，连射状态只读取 `FirePhase`。
- HUD 不根据枪口焰、声音或 Trigger 值自行增加射击数/扣减弹药。
- 结算页只读取 `MovingTargetResultDto` 的序列与逐发记录。
- 设置页/结算页显隐读取 `TrainingPresentationDto`，不从 `TargetMovePhase` 或目标 Transform 推断。
