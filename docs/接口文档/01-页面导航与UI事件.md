# 01 页面导航与 UI 事件

## 2026-11-10 分析页帮助与答案互斥

`Button_ZeroingImpactAnalysis_Help` 和 `Button_ZeroingImpactAnalysis_Answer` 是当前页本地显隐事件，不触发导航或玩法命令。收起态两按钮同时可见、帮助与答案隐藏、坐标可见；点击帮助后仅保留帮助按钮，显示帮助内容和准心柱/觇孔提示、隐藏坐标及答案；点击答案后仅保留答案按钮，显示答案、隐藏帮助及提示、坐标保持可见。再点击已展开按钮回到收起态。离开或重新进入分析页以及切换轮次均重置为收起，不改变按钮及答案面板的原坐标尺寸。

## 2026-11-09 分析答案与取枪提示
`Button_ZeroingImpactAnalysis_Answer` 与帮助同排右侧、同尺寸，点击切换 `Panel_ZeroingImpactAnalysis_Answer`，默认隐藏；帮助与答案的显隐以2026-11-10互斥修订为准。数据来自当前分析DTO，调整、应用、重新进入时刷新；离开分析或下一轮自动收起，不改变导航门禁或其他按钮坐标。`Text_TrainingShared_PickupPrompt` 的主菜单简报与靶场取枪页两个实例均保持各自面板框外的底部安全区，靶场页绝对定位文字不得被小胶囊样式覆盖；不更改文案或显隐逻辑。世界提示的文字正读且不挡枪械。

## 2026-11-09 主菜单操作介绍
`Button_MainMenu_Controls` 打开默认隐藏的 `Panel_MainMenu_Controls`；`Button_MainMenu_Controls_Back` 关闭该面板，均保持当前 MainMenu 路由。复用现有 UI 按钮/射线及稳定测试 ID；四个训练科目按钮坐标尺寸不变。内容只反映实际 VR 绑定和各模式固定点/切肩差异，不新增玩法命令。

2026-11-08：移除主菜单制作人入口及其完整面板，不新增服务或路由；四个训练入口和其他点击遮挡层保持原有行为。

## 路由约束

- `IsTransitioning == true` 时，UI 必须禁用所有会导致切页的按钮。
- `Back()` 必须返回上一业务页面，而不是固定返回主菜单。
- 打开环形菜单属于叠层 UI，关闭后应回到原 HUD。
- P1/P2 进入训练场景后先显示正前方准备页面；Start 成功只进入 `AwaitingWeaponPickup`，有效拾枪后才隐藏大型 UI 并进入实弹/倒计时。
- P1 `Zeroing_NextRound` 成功后必须隐藏弹着分析；若武器已经释放，仍保持大型 UI 隐藏，仅由最小 HUD 提示重新取枪，重新有效持枪前禁止射击。
- P1/P2 完成事件必须自动打开对应分析/结算页面，不要求玩家通过场景按钮触发。

## 事件传递

```csharp
public readonly struct UICommand
{
    public UIEventId EventId { get; init; }
```

UI 只发送事件和参数，不直接调用场景物体；Presenter 或 Controller 将事件转成服务命令。

## P3 v1 补充
