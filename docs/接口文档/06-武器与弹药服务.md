# 06 武器与弹药服务

## 目标

约束武器库、装备、VR 拾取/持枪状态、武器属性、弹药显示、换弹、后坐力和射击消耗接口。

## 阶段范围

| 阶段 | 武器与弹药范围 |
|---|---|
| P1 | 训练步枪在架、右手近距 Grip 拾取、左手前握把支撑、左前右后双手持枪、右手 Trigger 单发、真实 HMD 自然机瞄、无 VR 调试输入替身、按钮换弹、左右肩切换、确定性后坐力冲量与阻尼回正、可选手柄触觉、可见弹道或曳光、100m 射校弹药/HUD 刷新 |
| P2 | 武器库原型、训练模式可用武器筛选、移动靶点射消耗、弹药/HUD 共用服务 |
| P3 | 堑壕/城镇武器装备、战斗弹药、命中敌人反馈 |
| Later | 真实弹匣插拔、拉机柄、保险、卡弹、复杂枪械拆装、细分枪械动画 |
 
P1 不要求真实弹匣插拔、拉机柄或保险机制；这些行为不得阻塞 100m 射校闭环交付。

P1 武器控制由输入适配层下发抽象命令，例如开火、换弹、切换肩侧和切换瞄准模式。服务层负责弹药、可射击状态、肩侧、瞄准模式和射击结果数据；Unity 场景层负责双手持枪姿态、后坐力、ADS 视角对齐、弹道可视化和命中表现。
场景层先从姿态历史计算 `RawAimDirection`、`Stability01` 和 `AimMotionOffsetCm`，再得到已经包含枪体晃动影响的有效 `AimDirection`。命中检测、曳光和 `HitPoint` 必须使用该有效枪线。服务层必须先判断 `CanShoot` 和弹药，再决定该命中是否成为有效射击结果，并为有效射击返回确定性的 `RecoilImpulse`。

`WeaponShotResultDto` 是射击时刻快照。事件消费者必须读取其中的稳定度、双手状态、肩侧、枪线和后坐力冲量，不得在收到事件后重新查询当前武器状态来补齐这些字段。

`IWeaponHapticOutput` 是 Unity/XR 输出适配器，不属于玩法规则服务。真实 XR 实现向控制器发送脉冲；无 VR 和不支持触觉的设备使用空实现。触觉失败不得使有效射击失败。

## P1 VR 拾取与双手持枪契约

### 固定手别与动作

P1 固定为右利手训练配置：右手是后手/扳机手，左手是前手。左右肩切换不交换左右手职责。

| 语义动作 | 默认 XRI Action | 限定 |
|---|---|---|
| 拾取/保持后握把 | `XRI RightHand Interaction/Select` | 右手 Direct Interactor 位于后握把抓取区内 |
| 选择/保持前握把 | `XRI LeftHand Interaction/Select` | 已处于 `RearHandHeld` 且左手位于前握把抓取区内 |
| 单发击发 | `XRI RightHand Interaction/Activate` | `HoldState=TwoHandHeld` 且 `CanShoot=true` |

- Grip/Select 是保持式抓取：按住保持，释放结束选择。P1 不提供切换式抓取。
- Trigger/Activate 必须使用带迟滞的模拟量边沿，建议击发阈值 `0.75`、释放阈值 `0.25`；阈值由输入配置集中提供。
- 拾枪和前手支撑是 Unity 场景交互，必须通过 `XRDirectInteractor + XRGrabInteractable` 或等效组件的 Hover/Select 结果进入持枪控制器；玩法服务不读取具体 Interactor 或设备 API。
- 无 VR 与 PlayMode 替身必须能够注入相同的左右 Grip 按下/保持/释放、右手 Trigger 模拟量和三组跟踪姿态。

### 状态机与服务规则

| 状态 | 后手 | 前手 | 服务 `CanShoot` |
|---|---:|---:|---:|
| `OnRack` | 否 | 否 | 否 |
| `RearHandHeld` | 是 | 否 | 否 |
| `TwoHandHeld` | 是 | 是 | 还需双手跟踪有效、训练允许射击、弹药充足 |
| `Dropped` | 否 | 否 | 否 |

- 合法转换为：`OnRack/Dropped → RearHandHeld → TwoHandHeld`、`TwoHandHeld → RearHandHeld`、`RearHandHeld/TwoHandHeld → Dropped`、`Dropped → OnRack`。
- 左手不能单独把枪从 `OnRack` 或 `Dropped` 变为持有状态。释放右手必须同时清除前手状态。
- `TwoHandGripActive` 是兼容字段，必须等于 `HoldState == WeaponHoldState.TwoHandHeld`，不得再由左右控制器 GameObject 是否激活推导。
- `SetGripState` 接收场景层已验证的持有状态、跟踪有效性和稳定度，服务据此计算 `CanShoot` 并发布 `WeaponStateChangedEvent`。
- `Fire` 必须再次验证 `HoldState=TwoHandHeld` 及双手跟踪有效；校验失败返回 `InvalidState`，不消耗弹药，不产生有效 `RecoilImpulse`。
- 任一手跟踪丢失超过场景层 `0.15s` 缓冲后，场景层必须提交跟踪无效状态；服务立即令 `CanShoot=false`。

### 枪体姿态与视角责任

- 场景层以右手后握把为位置主锚，以右手到左手前握把的轴线确定枪管前向，并用右手姿态约束滚转；玩法服务只保存状态和稳定度，不直接驱动 Transform。
- 枪械初始位于枪架/武器台，不得挂在相机、HMD 或控制器层级下。选择后可以由 XRI/双手解算器接管，释放后恢复 Rigidbody 和场景碰撞。
- 真实 VR 中 HMD Camera 是唯一观察姿态来源。武器控制不得写入 HMD Camera、XR Origin 或 XR 投影/FOV；VR 机瞄由玩家实际对齐眼位和机械瞄具完成。
- VR `AimMode` 可由眼位与 `AimLine` 的几何关系推断，用于状态显示和射击快照，但不得驱动相机吸附。无 VR 可保留按键切换 ADS 代理。
- 枪口/瞄准线是射击权威方向；HMD forward 只代表观察方向。

## P1 后坐力与稳定度契约

### 初始训练步枪调参范围

以下范围用于 P1 训练步枪的首版调参和自动化门禁。具体默认值应集中在可注入配置中，不得散落硬编码在 View 或多个场景脚本中。

| 参数 | 单发基础范围 | 硬限制/说明 |
|---|---:|---|
| 枪口上跳 | `2.5-4.0°` | 三发累计不得超过 `8.0°` |
| 横向偏转绝对值 | `0.15-0.60°` | 累计绝对值不得超过 `1.5°` |
| 枪体后退 | `0.020-0.040m` | 累计不得超过 `0.070m` |
| 枪体上移 | `0.008-0.020m` | 不得导致枪体穿过 ADS 相机 |
| 击发冲量时间 | `0.04-0.08s` | 一个渲染帧内必须开始响应 |
| 阻尼回正时间 | `0.20-0.35s` | 总回稳时间不得超过 `0.45s` |
| 无 VR 相机附加上跳 | `0.15-0.50°` | 硬上限 `0.60°`；VR 固定为 `0°` |
| 无 VR 相机横摆 | `0.05-0.20°` | 硬上限 `0.25°`；VR 固定为 `0°` |
| 后手触觉 | `0.55-0.75` | 持续 `0.04-0.07s` |
| 前手触觉 | `0.20-0.35` | 必须弱于后手；持续时间相同 |

### 规则

- `RecoilLevel` 定义武器基础冲量；有效双手持枪时由 `Stability01` 调制玩家对枪体运动的控制响应。P1 单手状态不允许有效射击。
- 建议首版控制倍率为 `Lerp(1.45, 0.85, Stability01)`，最终限制在 `0.80-1.45`。测试以最终配置值为准。
- 横向偏转符号和小幅变化由 `SessionSeed + ShotSequence` 确定；同一输入必须可重复，不得使用全局随机状态。
- `AimMotionOffsetCm` 来自射击前 `0.12-0.20s` 的枪线角速度和漂移方向。低稳定度扩大实际姿态产生的偏移，但不得生成与姿态历史无关的纯随机弹着。
- 本发 `AimDirection`、射线命中、曳光和弹着使用施加本发 `RecoilImpulse` 之前的枪线快照。
- 本发冲量施加后立即改变当前枪体/瞄准线；未回稳时的下一发使用当前受力枪线。
- 回正使用阻尼弹簧、动画曲线或等效二阶响应；回稳后相对持枪基准的位置误差不得超过 `0.005m`、旋转误差不得超过 `0.25°`。
- VR 后坐力叠加在双手解算后的枪体局部表现层；击发峰值期间后握把与右手视觉分离不得超过 `0.015m`，前握把与左手视觉分离不得超过 `0.025m`。
- VR 不得写入 HMD 相机、XR Origin 或 XR 投影/FOV。无 VR ADS 代理可应用受限相机反馈，但射击权威方向仍来自枪口/瞄准线。
- 禁射、无弹、非法枪线等无效结果的 `RecoilImpulse` 必须为零值，且不得生成视觉后坐力或触觉。

## 业务规则

- 武器库选择武器只更新预览，不改变已装备武器。
- 点击“装备”后才改变当前武器。
- 进入堑壕或城镇任务时读取已装备武器。
- 弹药显示格式为当前弹匣/备用弹药，例如 30/120。
- 玩家自行换弹；换弹开始时可通知队友服务进入掩护状态。
- 弹药不足时不能生成有效射击。
- P1 按钮换弹可以直接完成或经过短暂换弹状态，但必须通过 `StartReload` / `CompleteReload` 或等效命令刷新弹药 DTO。
- P1 左右肩切换影响武器射击参考点和 HUD 提示；不改变弹药规则。
- P1 枪械初始处于 `OnRack`；只有右手在后握把近距范围内触发 Grip/Select 才能拾取，左手只能在右手已持枪后选择前握把。
- P1 非瞄准模式下，玩家观察方向由头显或无 VR 调试视角控制；有效射击方向仍以枪口或瞄准线为准。
- P1 真实 VR 瞄准通过玩家自然对齐 HMD 眼位与机械瞄具完成，不做相机吸附或 FOV 变化；无 VR 才允许 ADS 代理。射击方向、可见弹道和命中计算必须使用同一枪线。
- P1 双手持枪时，前手位置必须影响枪口方向和稳定度；松开前手时允许继续由右手保持武器，但 `CanShoot=false`，直至前手重新有效选择。
- P1 释放后手时必须取消前手选择并进入 `Dropped`，不得让武器继续挂在左手。
- P1 稳定度必须包含近期枪线运动信息；只根据手距返回静态稳定度不足以完成 task013。
- P1 有效开火必须返回射击时刻快照和确定性后坐力冲量；Unity 场景层依据同一冲量驱动枪体、ADS 代理和触觉。
- P1 后坐力使用冲量和阻尼回正，支持连续射击累积并设置旋转/位移硬上限。
- 真实 VR 路径禁止强制改写 HMD 姿态、XR Origin、投影或 FOV；触觉不可用时必须安全降级。
- P1 有效开火必须在 Unity 场景层生成从枪口出发的可见弹道或曳光，命中计算可先使用射线或简化弹道。
- 禁止射击状态必须在消耗弹药前判断。
- 真实弹匣插拔、拉机柄和保险属于 Later，不进入 P1/P2 验收。

## 事件

| 事件 | 数据 | 触发 |
|---|---|---|
| WeaponChangedEvent | WeaponDefinitionDto | 装备成功 |
| AmmoChangedEvent | AmmoDto | 射击、换弹开始、换弹完成 |
| ReloadStartedEvent | sessionId | 玩家开始换弹 |
| ReloadCompletedEvent | sessionId | 换弹完成 |
| WeaponStateChangedEvent | WeaponControlStateDto | 弹药、肩侧、瞄准模式、可射击状态或稳定度变化 |
| WeaponHoldStateChangedEvent | sessionId、WeaponHoldState、左右手跟踪有效性 | 拾取、前手接入、放手、掉落、复位或跟踪状态改变 |
| WeaponShotResultEvent | WeaponShotResultDto（含射击时刻持有/跟踪状态、稳定度、枪线、射击序号和后坐力冲量） | 有效或无效开火流程完成 |
| ShoulderChangedEvent | sessionId、ShoulderSide | 玩家切换左右肩 |
| AimModeChangedEvent | sessionId、WeaponAimMode | 玩家进入或退出瞄准模式 |

## 错误处理

| 条件 | 错误码 |
|---|---|
| 武器不存在 | NotFound |
| 武器不适用于当前模式 | InvalidInput |
| 当前弹药不足 | InvalidState |
| 已在换弹中再次换弹 | Busy |
| Session 未初始化 | InvalidState |
| 未拾枪、非双手持枪或双手跟踪无效时击发 | InvalidState |
| 非法持有状态转换或左右手职责不符合 P1 配置 | InvalidInput |
| 枪口位置或枪线方向非法 | InvalidInput |
