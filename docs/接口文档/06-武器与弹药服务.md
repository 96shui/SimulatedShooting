# 06 武器与弹药服务

## 目标

约束武器库、装备、武器属性、弹药显示、换弹和射击消耗接口。

## 阶段范围

| 阶段 | 武器与弹药范围 |
|---|---|
| P1 | 第一人称训练用主武器原型、VR 双手一前一后持枪、无 VR 调试输入替身、非瞄准/瞄准两种视角模式、扳机开火、按钮换弹、左右肩切换、简单后坐力、可见弹道或曳光、100m 射校弹药/HUD 刷新 |
| P2 | 武器库原型、训练模式可用武器筛选、移动靶点射消耗、弹药/HUD 共用服务 |
| P3 | 堑壕/城镇武器装备、战斗弹药、命中敌人反馈 |
| Later | 真实弹匣插拔、拉机柄、保险、卡弹、复杂枪械拆装、细分枪械动画 |
 
P1 不要求真实弹匣插拔、拉机柄或保险机制；这些行为不得阻塞 100m 射校闭环交付。

## 服务接口

```csharp
public interface IWeaponService
{
    ServiceResult<IReadOnlyList<WeaponDefinitionDto>> GetWeapons();
    ServiceResult<WeaponDefinitionDto> GetWeapon(string weaponId);
    ServiceResult<WeaponDefinitionDto> GetEquippedWeapon();
    ServiceResult<WeaponDefinitionDto> SelectPreview(string weaponId);
    ServiceResult<WeaponDefinitionDto> Equip(string weaponId, TrainingMode? mode);
}

public interface IAmmoService
{
    ServiceResult<AmmoDto> GetAmmo(string sessionId);
    ServiceResult<AmmoDto> ConsumeAmmo(string sessionId, int amount);
    ServiceResult<AmmoDto> StartReload(string sessionId);
    ServiceResult<AmmoDto> CompleteReload(string sessionId);
}

public interface IWeaponControlService
{
    ServiceResult<WeaponControlStateDto> StartSession(string sessionId, string weaponId, TrainingMode mode);
    ServiceResult<WeaponControlStateDto> GetState(string sessionId);
    ServiceResult<WeaponShotResultDto> Fire(WeaponFireInputDto input);
    ServiceResult<WeaponControlStateDto> Reload(string sessionId);
    ServiceResult<WeaponControlStateDto> SetShoulder(string sessionId, ShoulderSide shoulderSide);
    ServiceResult<WeaponControlStateDto> ToggleShoulder(string sessionId);
    ServiceResult<WeaponControlStateDto> SetAimMode(string sessionId, WeaponAimMode aimMode);
    ServiceResult<WeaponControlStateDto> SetGripState(string sessionId, bool twoHandGripActive, float stability01);
}
```

P1 武器控制由输入适配层下发抽象命令，例如开火、换弹、切换肩侧和切换瞄准模式。服务层负责弹药、可射击状态、肩侧、瞄准模式和射击结果数据；Unity 场景层负责双手持枪姿态、后坐力、ADS 视角对齐、弹道可视化和命中表现。
场景层可先完成射线检测并把 `Hit`、`HitPoint`、`HitObjectId` 传入 `WeaponFireInputDto`；服务层必须先判断 `CanShoot` 和弹药，再决定该命中是否成为有效射击结果。

## 业务规则

- 武器库选择武器只更新预览，不改变已装备武器。
- 点击“装备”后才改变当前武器。
- 进入堑壕或城镇任务时读取已装备武器。
- 弹药显示格式为当前弹匣/备用弹药，例如 30/120。
- 玩家自行换弹；换弹开始时可通知队友服务进入掩护状态。
- 弹药不足时不能生成有效射击。
- P1 按钮换弹可以直接完成或经过短暂换弹状态，但必须通过 `StartReload` / `CompleteReload` 或等效命令刷新弹药 DTO。
- P1 左右肩切换影响武器射击参考点和 HUD 提示；不改变弹药规则。
- P1 非瞄准模式下，玩家观察方向由头显或无 VR 调试视角控制；有效射击方向仍以枪口或瞄准线为准。
- P1 瞄准模式下，画面必须表现为沿枪线观察，射击方向、可见弹道和命中计算必须使用同一枪线。
- P1 双手持枪时，前手位置必须影响枪口方向、稳定度或两者；松开前手时允许继续后手持枪，但应降低稳定度或增加枪口抖动。
- P1 有效开火必须在 Unity 场景层生成从枪口出发的可见弹道或曳光，命中计算可先使用射线或简化弹道。
- 禁止射击状态必须在消耗弹药前判断。
- 真实弹匣插拔、拉机柄和保险属于 Later，不进入 P1/P2 验收。

## 事件

| 事件 | 数据 | 触发 |
|---|---|---|
| WeaponChangedEvent | WeaponDefinitionDto | 装备成功 |
| AmmoChangedEvent | AmmoDto | 射击、换弹开始、换弹完成 |
| ReloadStartedEvent | sessionId | 玩家开始换弹 |
| ReloadCompletedEvent | sessionId | 换弹完成 |
| WeaponStateChangedEvent | WeaponControlStateDto | 弹药、肩侧、瞄准模式、可射击状态或稳定度变化 |
| WeaponShotResultEvent | WeaponShotResultDto | 有效或无效开火流程完成 |
| ShoulderChangedEvent | sessionId、ShoulderSide | 玩家切换左右肩 |
| AimModeChangedEvent | sessionId、WeaponAimMode | 玩家进入或退出瞄准模式 |

## 错误处理

| 条件 | 错误码 |
|---|---|
| 武器不存在 | NotFound |
| 武器不适用于当前模式 | InvalidInput |
| 当前弹药不足 | InvalidState |
| 已在换弹中再次换弹 | Busy |
| Session 未初始化 | InvalidState |
| 枪口位置或枪线方向非法 | InvalidInput |
