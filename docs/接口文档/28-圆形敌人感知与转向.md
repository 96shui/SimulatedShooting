# 圆形敌人感知与转向（P3，2026-11-15）

对应 BDD36，覆盖接口15/17/27中敌人发现的角度、单点射线及门登记门禁。沿用 Perception、Visual/Feedback；UI 无业务变更。

- CombatConfigDto.EnemyRange 为水平圆半径，默认30m；新增 EnemyVerticalTolerance=2.5m、EnemyHeadSampleHeight=1.65m、EnemyChestSampleHeight=1.2m、EnemyFootSampleHeight=0.15m、EnemyTurnSpeedDegrees=180°/s。采样相对玩家脚底；垂直差比较敌人感知原点和玩家胸部。参数须有限正数且头>胸>脚；复制配置保留新增字段。
- ICombatCoreService.Config 只读暴露实际配置给场景，避免规则与场景各取默认值。核心发现判断存活、Visible、水平半径及垂直容差；不使用 EnemyHalfViewAngle。该旧字段仅保留兼容，开火仍要求水平误差≤12°和原攻击间隔。
- 场景从 PerceptionOrigin（缺失回退胸口）向头/胸/脚分别 Physics.RaycastAll，过滤敌人自身、玩家层级、持枪与触发器，任一通畅即 Visible。使用全部物理层；真实墙体、关闭门扇、楼板遮挡，不以层2一律透明。
- 圆内且无遮挡立即平滑转向后提交真实位置/Forward/Visible，不以 Attacking 为转向前置。核心位置输入仍为脚底，核心以双方胸部估算垂直差，真实感知原点容差由场景精确判定。
- UrbanService 不因 Room.Open=false 拒绝真实 Perception=true。CombatDoorView.Apply/ResetView 同步门扇 Collider 与 NavMeshObstacle，开时禁用，关时恢复；同 RoomId 门视图全部同步。
- 场景诊断默认关闭；开启逐帧每敌人输出距离、垂直差、圆内、各采样最近遮挡物、Visible、提交返回、状态、水平夹角、actor 存在性。缺失 actor 从权威快照补齐并记录，不得静默跳过。

验证为规则 EditMode、生产城镇跨房间/闭门/楼板/局部遮挡/自身碰撞及模式三 PlayMode，完整 fullname 基线逐名比较，证据与实机待验见 round7 报告。
