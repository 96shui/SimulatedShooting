# 阶段三 P3：小型堑壕与城镇战斗原型

## 本次分配

2026-09-09 按现有第三阶段范围分配：**13 个生产 task，玩法功能 5 个、UI 4 个、场景 4 个**。审核测试与优化不领取 task 编号。当前仅完成任务拆分，不代表实现、契约签核或阶段验收已完成。本次不拆第四阶段，也不启动生产实现。

## 阶段边界

- 堑壕：1 张小地图，简化无人机/平面图简报，固定种子生成 3–5 个简单敌人，玩家与两队友三人纵队，小地图/搜索/胜负闭环。
- 城镇：1 条街、1 栋三层楼，**总计** 3–5 个可搜索房间；街道 1–2 个敌人、建筑 3–6 个敌人，入口/开门/检查/结算闭环。
- 共用：训练主武器、30/120 战斗弹药、简单血量、命中音效、敌人死亡后本局内尸体保留、姿态/换肩和简化拐角射击。
- 胜利同时要求搜索完成、全部敌人清除、玩家存活；死亡失败。同批次事件优先级在 task001 冻结。
- 保留无 VR 输入路径；P1/P2 固定卧姿、无人工移动及射击规则必须回归。
- Later：第二张地图、多栋建筑、高级 AI、换弹掩护、队友环形菜单、手榴弹/火力支援/自动拉回、复杂观察和穿墙校验、高拟真装填、医疗与大型开放世界。引用整份 BDD 不等于领取其中 Later 场景。

范围遵循 [阶段化整体需求](../../需求/阶段化整体需求说明书.md)，布局遵循 [draw.io](../../../UI/Sample/vr-shooting-ui-reference-wireframes.drawio)。未定规则集中在 [契约冻结清单](契约冻结清单.md)，不能由各线分别猜测。
