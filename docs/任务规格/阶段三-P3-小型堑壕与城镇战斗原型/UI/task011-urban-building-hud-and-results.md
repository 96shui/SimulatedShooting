## 实现内容

### 1. 数据与入口

制作 Screen_UrbanBuildingHud、Screen_UrbanResults，复用弹药/血量/姿态/队友和地图组件；显示当前楼层、房间状态、敌情预估与任务进度。

### 2. 状态与交互

按服务给出的 IsInteractive/IsEnabled 显示房门和检查提示；只开放 P3 冻结支持的交互，Later 观察/复杂伸枪不以可点击假按钮交付。

### 3. 服务与适配

开门/检查确认只提交对应命令；已搜索青蓝色、未搜索/搜索中按状态区分，不根据门动画结束或角色走过自行认定房间完成。

### 4. 边界与幂等

结算展示 StreetCleared、建筑搜索完成度、房间数、总击杀数、剩余弹药、队友与 1F/2F/3F 缩略图及死亡标记。

### 5. 事件与生命周期

处理死亡中途结果、空楼层/空列表、资源缺失、旧 Session 数据、防重复重试和返回；终局事件自动切结果页。

### 6. 交付与兼容

稳定 ID 包括 Hud_UrbanBuilding_MiniMap/Rooms/Ammo/Health/Prompt，Button_UrbanBuildingHud_OpenDoor；检查动作 ID 随节点 A 冻结登记；Button_UrbanResults_Retry/BackToMainMenu、Text_UrbanResults_Summary。

## 测试要求

先补或更新本任务的自动化测试，再实现业务/适配逻辑。以下均为待新增或待更新的测试要求，不代表当前已有通过结果。

- PlayMode：切楼层、三种房间状态、队友/敌情/弹药更新、交互不可用/Busy/错误。
- PlayMode：开门命令不立即把房间画成已搜索；收到搜索完成 DTO 才更新；房门/检查重复点击只发一次有效请求。
