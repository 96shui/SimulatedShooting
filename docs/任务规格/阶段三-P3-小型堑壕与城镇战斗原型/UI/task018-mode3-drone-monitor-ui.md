## 目标与交付内容

- 更新简报开始按钮：提交应用开始命令后先进入无人机开场，防重复提交；到正式 `Running` 后才显示可操作的 `Screen_TrenchHud`。
- 交付 `Screen_TrenchDroneRecon` View/Presenter 和 Prefab：真实摄像头视频区、中心观察框/十字标、边角刻度、无人机/视频状态、任务阶段、侦察用时及返回操作。
- 视觉参考现代战场无人机监控画面的观察框、低饱和灰绿/黑白色调、轻微噪点/扫描线/暗角；滤镜强度可配置，必须保留敌人与堑壕细节，不用强闪烁干扰观察。
- “LIVE”表示当前实时画面；本任务不要求录制视频文件，不能以“REC”虚构正在落盘。视频来自当前地图的场景 Camera，不能用静态占位图或外部战争视频替代。
- 高度/速度等遥测若显示，只能读取接口20的实测 DTO；无有效数据时隐藏或显示“--”。侦察用时与战斗用时分别显示；不写死敌人数、命中数、GPS 或敌人锁定框。
- 状态文本覆盖“起飞/侦察/返航/降落/恢复视角”；起飞时保留玩家看到无人机的场景视野，仅侦察阶段显示监控并隐藏大型简报面板和战斗 HUD。按 2026-10-04 用户反馈，单次巡航结束即关闭监控，返航与降落使用玩家视角，避免呈现第二次巡航；正式行动仍须等待服务解除开场锁。
- 返回/取消走应用服务；显示资源错误并允许返回或重试。没有跳过开场入口，不允许 View 调用正式开战、角色开火或解除行为锁。
- 桌面与 VR 复用同一视频和 DTO。VR 观察屏摆放交由场景适配，保证 UI 可读且保留头部跟踪。
