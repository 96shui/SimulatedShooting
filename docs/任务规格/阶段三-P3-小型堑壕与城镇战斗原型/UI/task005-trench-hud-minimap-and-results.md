## 实现内容

### 1. 数据与入口

制作 Screen_TrenchHud 与 Screen_TrenchResults；HUD 展示血量/存活、30/120 弹药、姿态/肩侧、拐角许可、任务进度和队友状态。

### 2. 状态与交互

实现可复用小地图 Presenter：按 MapId/资源键加载底图，只按归一化坐标渲染玩家、队友、预估敌情、搜索区域与死亡标记；不读取敌人 Transform 暴露真实随机偏移。

### 3. 服务与适配

结算严格渲染 TrenchResultDto 的胜负、消灭数/总数、搜索进度、剩余弹药、队友、用时与 ResultMap；失败中途保留真实部分进度。

### 4. 边界与幂等

实现重试、返回主菜单、防重复提交、Busy 与失败提示；重试页面去向由应用服务决定，不由 View 重置场景或弹药。

### 5. 事件与生命周期

对空地图/队友数据、安全默认值、过期会话事件、反复启用/禁用与销毁退订提供稳定处理；公共小地图实现供城镇 UI 复用。

### 6. 交付与兼容

提供 Hud_Trench_Health/Ammo/MiniMap/Squad/Posture/Shoulder/SearchProgress，Button_TrenchResults_Retry/BackToMainMenu，Text_TrenchResults_Summary 等稳定测试 ID；完整清单交付时登记。

## 测试要求

先补或更新本任务的自动化测试，再实现业务/适配逻辑。以下均为待新增或待更新的测试要求，不代表当前已有通过结果。

- PlayMode：血量/弹药/姿态/肩侧事件逐项刷新；敌情只显示预估点；队友移动和搜索区域变化更新小地图。
