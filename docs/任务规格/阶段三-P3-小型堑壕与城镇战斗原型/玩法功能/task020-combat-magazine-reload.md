## 交付范围

1. 每轮开局30发枪内弹匣与两个30发备用弹匣，共90发；提前换弹丢弃旧弹匣余弹，每次成功换弹消耗一个完整备用弹匣。
2. 桌面R与模式三VR左手柄X键（primaryButton）经IXRTrainingInput触发；模式四保留左摇杆按压。有效双手持枪启动，两秒期间不能开火。满弹、无备用与重复请求不启动动作、不扣备用。
3. 左人物手离开护木握住真实弹匣，下拔后移动到相机视野下方，取新弹匣上推插入；到两秒结束由服务补满，不由动画修改弹药。模式三换弹时清除左手握枪状态、取消左手XRI选择并锁定前握把，人物左手临时由动画控制、不跟随手柄；完成/取消后恢复手柄控制与握枪入口，松开再按Grip重建双手握持。实际HMD、手柄跟踪、右手握持与UI射线正常。
4. 暂停、追踪失效、结束、退出取消动作并恢复弹匣/手姿态，不扣备用；新局恢复三个弹匣。模式四街道/建筑沿用同一轮库存。
5. HUD显示当前/备用弹数、备用弹匣数与换弹状态，均来自DTO。
