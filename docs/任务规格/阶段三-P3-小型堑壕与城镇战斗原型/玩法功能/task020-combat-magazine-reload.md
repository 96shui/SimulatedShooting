# task020：模式三与四的弹匣换弹动作

- 阶段：P3；负责人：玩法功能；场景负责枪械与人物手表现，UI消费弹药DTO。
- 授权：2026-10-11用户要求模式三/四手动换弹、手拔下弹匣移出视野再装入、动作结束补满、每轮三个弹匣，并推送main。
- BDD：[23-P3共用战斗核心](../../../BDD/screens/23-P3共用战斗核心.feature.md)「三个弹匣与动作结束装填」「提前换弹与无效请求」「取消换弹与新局复位」；HUD见BDD15/19/20。
- 接口：15-P3共用战斗核心、06-武器与弹药服务、02-训练Session数据模型、11-Unity场景与Prefab约定。

## 交付范围

1. 每轮开局30发枪内弹匣与两个30发备用弹匣，共90发；提前换弹丢弃旧弹匣余弹，每次成功换弹消耗一个完整备用弹匣。
2. 沿用桌面R与VR左摇杆按压，经IXRTrainingInput触发；有效双手持枪启动，两秒期间不能开火。满弹、无备用与重复请求不启动动作、不扣备用。
3. 左人物手离开护木握住真实弹匣，下拔后移动到相机视野下方，取新弹匣上推插入，左手回护木；到两秒结束由服务补满，不由动画修改弹药。VR不修改HMD、手柄输入或XRI交互器。
4. 暂停、追踪失效、结束、退出取消动作并恢复弹匣/手姿态，不扣备用；新局恢复三个弹匣。模式四街道/建筑沿用同一轮库存。
5. HUD显示当前/备用弹数、备用弹匣数与换弹状态，均来自DTO。

## 测试及交付

- EditMode：双模式三弹匣耗尽、提前换弹、精确完成边界、拒绝无效/重复请求、暂停/追踪/终局取消与新局重置、P1/P2弹药回归。
- PlayMode：真实枪与手资产、逐段动作和视野外位置、服务结束装填、输入替身/HUD、禁射、取消恢复、双模式生产装配。
- VR实机待验：双眼动作/弹匣可见性、手握姿、运动中换弹、摇杆输入、取消恢复与舒适度；不可用无设备检查替代实机结论。
- 回归门禁发现P2既有场景缺少P1起始区的非交互`WeaponReference_Blockout`副本，允许从P1补齐同位置的静态参考锚点；不改变P2输入、弹药或训练规则。
