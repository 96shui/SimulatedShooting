# task005 第一人称双手武器控制：持枪、瞄准、开火、换弹、切肩

## 负责人

功能B-武器输入与AI基础

## 目标

完成 P1 100m 射校所需的第一人称主武器原型。玩家在 Unity Editor、XR Device Simulator 或真实 VR 设备中都应能看到一把位于第一人称视野内的训练步枪，并通过双手一前一后持枪、扳机开火、按钮换弹、左右肩切换和瞄准模式切换完成基础射击。

本任务不接受只用空物体、调试射线或 HUD 文本替代武器表现。交付结果必须能在 Unity 里直观看到枪体、枪口方向、后坐力、可见弹道或曳光、靶面命中反馈和弹药状态变化。

## 交付内容

- 训练用第一人称主武器原型：
  - 枪体在第一人称视角中可见，至少包含枪托、后手握把、前手托/护木、枪管、枪口和机械瞄具或等效瞄准参考。
  - 可使用已授权低模资产或程序化 blockout，占位资产必须符合写实军事训练方向，不能用空 GameObject 或单条线作为最终交付。
  - 武器 Prefab 必须暴露稳定绑定点：后手握把、前手握把、枪托/肩托、枪口、瞄准线、弹匣位置、左右肩参考点。
- 双手持枪基础交互：
  - 真实 VR 时，后手控制握把、扳机和主方向，前手控制护木/前握把，枪体姿态由两只手柄共同决定，形成一前一后端枪的感觉。
  - XR Grab / XR Direct Interactor / XR Socket 或等效接入点必须实际可绑定，不再只做空预留。
  - 无 VR 时，提供 Unity Editor 可用的调试输入替身，能模拟头部视角、后手、前手、扳机、换弹、切肩和瞄准切换。
- 两种第一人称视角模式：
  - 非瞄准模式：视角由 VR 头显或无 VR 调试视角控制，玩家可以自由转头观察；枪体由双手控制并保持在视野内，开火方向以枪口/枪线为准。
  - 瞄准模式：进入类似第一人称机瞄/ADS 的枪线视角，画面主要对齐枪的瞄准线；此时视角或瞄准参考由双手控制枪体移动，头部自由视角不再单独决定射击方向。
  - VR 舒适性要求：如果直接强制旋转 HMD 相机会造成不适，允许使用 ADS 相机代理、瞄准遮罩或视角父级对齐方案，但玩家看到的效果必须清楚表现为“沿枪线瞄准”，并可通过双手移动枪线。
- 基础射击动作：
  - 后手扳机触发开火。
  - 按钮换弹，P1 可直接完成或短暂播放换弹状态，但必须通过服务层刷新弹药 DTO 或事件。
  - 左右肩切换改变枪托/肩侧参考点和第一人称枪体位置，HUD 或调试信息可显示当前肩侧。
  - 开火时必须有可感知后坐力：枪体上跳/后退、枪口抖动或短暂相机/ADS 反馈。
- 可见弹道与命中：
  - 每次有效开火必须生成可见弹道表现，例如曳光弹、快速飞行弹体或沿枪线前进的 tracer。
  - 命中计算可以先使用射线或简化弹道，但视觉表现不能只是一帧 Debug.DrawRay。
  - 子弹/曳光应从枪口出发，沿当前枪线飞向 100m 靶面或环境碰撞体。
  - 命中靶面后应出现可见弹着点或命中反馈，并把射击结果传给 100m 射校服务或后续联调接口。
- 状态输出：
  - 当前弹匣、备用弹药、可射击状态 `CanShoot`。
  - 当前肩侧。
  - 当前视角模式：非瞄准 / 瞄准。
  - 最近一次开火结果：是否有效、枪口位置、枪线方向、命中点、命中对象或未命中原因。

## 无 VR 调试输入要求

无 VR 设备时，玩家必须能在 Unity Editor 的 Play Mode 中看到并测试完整效果。默认建议输入如下，最终实现可按项目输入适配层调整，但必须在交付说明中列出实际按键：

- 鼠标移动或右摇杆替身：非瞄准模式下控制第一人称观察方向。
- 后手替身：控制枪体基础朝向和扳机输入。
- 前手替身：控制枪口微调，能明显影响枪线方向。
- 左键或 `F`：开火。
- `R`：换弹。
- `Q`：左右肩切换。
- 右键、`Mouse1` 或 `LeftShift`：按住或切换瞄准模式。

无 VR 路径不能绕过武器服务、弹药服务或射击结果事件；它只是输入来源替身。

## 真实 VR 控制要求

- 后手控制器抓住后手握把后，可用扳机开火。
- 前手控制器抓住前手握把或靠近护木后，枪体姿态受前手影响，能模拟双手端枪。
- 进入瞄准模式后，玩家通过双手移动枪体来移动枪线；枪线、机械瞄具和弹道方向应一致。
- 松开前手时，武器仍可由后手保持，但稳定度下降或枪口抖动增加。
- 换弹和切肩应绑定到 XR 控制器按钮或输入适配层命令，不允许场景脚本直接读取某个硬编码设备 API 后绕过服务层。

## 不包含

- 不做真实弹匣插拔。
- 不做拉机柄、保险、卡弹。
- 不做多武器完整切换。
- 不做完整真实外弹道、风偏、重力下坠和穿透。
- 不做完整手部 IK、手指动画和高拟真枪械拆装。

## 素材预检与授权要求

- 实现前必须检查仓库内是否已有可用武器模型、材质、瞄具、弹道 VFX、命中贴花和音效。
- 使用外部武器模型、贴图、音效或 VFX 时，必须记录来源、许可证、下载文件名和导入路径；授权不清的素材不能作为交付依赖。
- 如果缺少正式素材，可以先交付程序化 blockout 武器，但必须具备清晰枪形、枪口、握把、护木和瞄准线，不影响双手持枪、ADS、弹道和自动化测试。

## 测试要求

- EditMode 单元测试：
  - 弹药消耗。
  - 弹药不足时不能开火，且不能先扣弹再回滚。
  - 换弹后弹匣和备用弹药正确。
  - 左右肩切换状态正确。
  - 非瞄准 / 瞄准模式切换状态正确。
  - 开火结果包含枪口位置、枪线方向、弹药状态和有效/无效原因。
- PlayMode 自动化测试：
  - 无 VR 输入替身触发开火后产生射击结果、可见弹道对象和靶面命中反馈。
  - 无 VR 输入替身触发换弹和切肩后 HUD 或状态输出可收到变化。
  - 无 VR 输入替身能切换非瞄准 / 瞄准模式，并验证瞄准模式下射击方向来自枪线。
  - 场景中的训练武器 Prefab 绑定点完整，不允许缺少枪口、后手、前手、瞄准线或肩侧参考点。
- VR / XR Device Simulator 验收：
  - 双手一前一后持枪时，前手移动会改变枪口方向。
  - 扳机、换弹、切肩和瞄准输入可用。
  - 瞄准模式下能看到类似机瞄的枪线视角，弹道沿枪线飞出。
  - 若无法在自动化测试中覆盖真实 VR 设备，必须在交付说明中列出手工验收步骤和未覆盖风险。

## 验收标准

- 基于 `origin/main` 的新实现能在 Unity Editor Play Mode 中直接看到第一人称武器和射击效果。
- 无 VR 设备时可以完成自由观察、双手持枪替身控制、瞄准模式、开火、换弹、切肩和命中靶面。
- 有 VR 设备或 XR Device Simulator 时可以通过双手控制器完成一前一后持枪，前手会实际影响枪线。
- 非瞄准模式下视角由头显/调试视角自由控制；瞄准模式下画面对齐枪线并由双手控制枪线移动。
- 每次有效开火都能看到从枪口飞出的弹道或曳光，并在命中后出现弹着反馈。
- 开火前检查 `CanShoot` 和弹药，不允许先扣弹再回滚。
- 武器状态、弹药状态、肩侧、瞄准模式和射击结果能被 P1 HUD 和 100m 服务消费。
- EditMode 和 PlayMode 测试通过；测试缺失时不得标记 task005 完成。
