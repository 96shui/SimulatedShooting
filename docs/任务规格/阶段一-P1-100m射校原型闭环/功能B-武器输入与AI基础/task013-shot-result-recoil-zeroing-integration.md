# task013 VR 拾枪、双手持枪、后坐力与射击结果接入

## 负责人

功能B-武器输入与AI基础

## 目标

把真实 VR 设备上的训练步枪拾取、左前右后双手持枪、右手扳机击发、自然机瞄、后坐力、稳定度、命中点和弹药变化接入 100m 射校服务，形成从手柄交互到弹着记录的完整链路，并保留无 VR 可自动化验证路径。

## 当前实现阶段

task013 当前为**已完成（开发、自动化验证与真实 VR 核心交互验收均已完成）**：

- 已完成 XRI 近距拾取链路：训练步枪初始处于 `OnRack`，右手靠近后握把并按住 Grip 后进入 `RearHandHeld`，左手选择前握把后进入 `TwoHandHeld`；释放左手会禁射，释放右手会原子取消前手并恢复掉落物理。
- 已完成输入与服务状态机：左右 Grip、右手模拟量 Trigger 迟滞、双手跟踪有效性和无 VR 输入替身均通过可替换适配层进入服务；仅 `TwoHandHeld` 且双手跟踪有效时允许开火。
- 已完成 VR/无 VR 运行模式：检测到运行中的 XR Display 时启用 `XR Origin`/HMD Camera，否则启用 `Camera_NoVR`；运行态只保留一个玩家相机、一个 `AudioListener` 和一个 `XRInteractionManager`。
- 已完成确定性后坐力：每发由 `SessionSeed + ShotSequence` 生成枪体上跳、后退、横向扰动、阻尼回正和前后手不同强度的触觉请求；不改写 HMD、XR Origin 或 VR FOV。
- 已完成射击时刻快照：持有状态、双手跟踪、稳定度、原始/有效枪线、射击序号和后坐力冲量随 `WeaponShotResultDto` 冻结，并继续进入射校、弹着和 HUD 链路。
- 自动化与 Editor 运行态已验证：EditMode 73/73、PlayMode 43/43；无头显运行时为 `OnRack`、`CanShoot=false`，稳定态控制台 0 Error / 0 Warning。
- 真实 VR 核心交互已于 2026-07-22 由用户验收通过：OpenXR 能进入场景，移动与头部视角正常，训练步枪能够拾取并使用右手扳机开火。设备型号、Runtime、连接方式和刷新率尚未补录；MainScene 菜单在头显中不可见属于 UI/总联调后续问题。

本次细化后的完成边界是：task013 同时收口 task005 尚未完成的真实 XR 拾取与双手持枪路径，先完成 P1 右利手训练步枪的“在架 → 右手拾取 → 左手支撑 → 双手可射击 → 放手/掉落”闭环，再完成后坐力、稳定度和射校数据闭环；不扩展到真实枪械型号标定、高级外弹道或完整身体 IK。

## 已采用的交互决策

本轮开发按以下已细化方案实现；如后续要改变任一项，应先同步调整本文件、BDD 与接口契约：

1. 主手配置：P1 是否固定左前右后（**默认：固定右利手；左手前握把、右手后握把和扳机**）。
2. 拾取方式：Grip 是按住保持还是按一次切换（**默认：按住保持，松开即释放**）。
3. 击发门槛：仅右手持枪时能否射击（**默认：不能；必须进入 `TwoHandHeld`**）。
4. 抓取距离：是否允许射线远距吸枪（**默认：不允许，只接受 Direct Interactor 近距抓取**）。
5. VR 瞄准：是否提供相机吸附或 FOV 放大（**默认：不提供，完全使用 HMD 自然机瞄**）。
6. 掉落处理：枪械掉出可操作范围后是否自动回架（**默认：无有效抓取且越界后安全复位**）。
7. 视觉手范围：是否要求完整手臂/身体 IK（**默认：只要求左右虚拟手和握把姿势，不要求完整手臂与身体**）。

## 交付内容

### P1 操作基线与输入映射

P1 本任务固定采用右利手训练配置，防止“肩侧”“主手”和“拾取手”概念混用：

| 玩家动作 | 默认 XR Input Action | P1 结果 |
|---|---|---|
| 右手靠近后握把并按住 Grip | `XRI RightHand Interaction/Select` | 拾取并持续握住后手握把 |
| 左手靠近前握把并按住 Grip | `XRI LeftHand Interaction/Select` | 接入前手支撑，进入双手持枪 |
| 右手按动 Trigger | `XRI RightHand Interaction/Activate` | 仅在双手持枪且 `CanShoot` 时触发单发射击 |
| 左手松开 Grip | 左手 `Select` 取消 | 回到仅右手持枪并禁止有效射击 |
| 右手松开 Grip | 右手 `Select` 取消 | 强制取消前手选择并掉落武器 |

- 拾枪使用握把键/Grip，不使用扳机；扳机只负责击发。
- 输入必须通过 XRI/Input System Action 或等效可替换适配器进入，不得在武器脚本里按设备名称直接读取 Oculus、PICO、SteamVR 等厂商 API。
- `Trigger` 使用模拟量迟滞：建议越过 `0.75` 产生一次击发边沿，回落到 `0.25` 以下后才允许下一次击发；阈值集中配置。
- P1 左手固定为前手、右手固定为后手和扳机手。左利手角色、左右手角色互换属于后续范围；现有“左右肩切换”只改变枪托/肩侧参考，不交换控制器职责。
- 无 VR 输入替身必须提供相同的右手 Grip、左手 Grip、右手 Trigger 按下/保持/释放语义，不能通过 `FireOnceForTests()` 绕过拾枪状态机作为 task013 完成证据。

### 武器持有状态机

武器必须有明确且可查询的状态，不允许通过控制器对象是否激活推断玩家已经抓枪：

| 当前状态 | 允许转换 | `CanShoot` | 说明 |
|---|---|---:|---|
| `OnRack` | 右手近距拾取 → `RearHandHeld` | 否 | 初始位于射击台/枪架，启用近距抓取 |
| `RearHandHeld` | 左手前握把选择 → `TwoHandHeld`；右手释放 → `Dropped` | 否 | 右手负责武器主位置，属于过渡持枪状态 |
| `TwoHandHeld` | 左手释放 → `RearHandHeld`；右手释放 → `Dropped` | 条件成立 | 左前右后，且双手跟踪、弹药和训练规则均有效时才可射击 |
| `Dropped` | 右手近距拾取 → `RearHandHeld`；场景复位 → `OnRack` | 否 | 恢复 Rigidbody/碰撞和重力 |

- 玩家进入 HUD 时枪械默认处于 `OnRack`，不得已经挂在相机、HMD 或手柄下面。
- 右手必须进入后握把近距抓取区后产生一次新的 Grip/Select 按下边沿才能拾取；不得通过远距离射线或在范围外按键把枪吸到手中。
- 右手 Hover 后显示贴近后握把且不遮挡瞄准区域的“按住右手 Grip 拾取”文字或控制器图标；离开范围或拾取成功后立即隐藏。提示只反映可拾取状态，不直接改变武器状态。
- 后握把默认有效抓取距离为 `0.10m`，可调范围 `0.08-0.12m`；前握把默认有效距离为 `0.12m`，可调范围 `0.10-0.15m`。
- 右手拾取后一个渲染帧内，枪械后握把附着点与右手抓取姿态的位置误差应不超过 `0.02m`、角度误差不超过 `8°`。
- 左手选择前握把后，前手虚拟手与前握把位置误差应不超过 `0.03m`；左手移动必须连续改变枪口方向，不允许在两种预设角度之间跳变。
- 右手是主选择。释放右手时必须原子地取消左手选择，防止枪械仅挂在前手或出现双重所有权。
- 枪械掉出射击位、低于场景安全高度或超过可配置距离后，应在无有效抓取时安全复位到枪架；复位不得发生在玩家仍握持武器时。
- 右手或左手跟踪丢失超过 `0.15s` 时立即令 `CanShoot=false`；短暂丢失期间保持最后安全姿态或受限预测，不得把枪移到世界原点。跟踪恢复且 Grip 仍保持时可重新建立状态。

### 双手枪体解算与虚拟手

- 右手后握把是枪体位置主锚点，左手前握把位置决定枪管前向；枪体滚转由右手姿态与双手轴线共同约束，不能只把枪固定偏移在 HMD 前方。
- 双手解算必须保持 Unity 世界比例 `1 Unit = 1m`，不缩短真实手间距来强行让瞄具进入视野。
- 跟踪姿态到枪体显示的额外延迟不得超过一个显示帧；平滑只能过滤高频噪声，不能产生明显拖尾、橡皮筋回弹或快速转手时的穿模。
- 场景必须显示基础左右手网格或明确的控制器手替身，最终交付不得继续使用立方体占位。未抓取时随控制器 `1:1` 跟踪；抓取时只允许虚拟手网格对齐握把姿势，不得移动真实控制器姿态、HMD 或 XR Origin。
- 右手网格使用后握把握持姿势，左手网格使用护木/前握把姿势；允许用基础关节弯曲或预设握持姿势，不要求连续手指追踪动画、手臂 IK 或全身 Avatar。
- 持枪时枪体碰撞不得反向推动 XR Origin 或造成 HMD 抖动；释放后才恢复正常掉落物理。手、枪、玩家碰撞层必须避免自碰撞抖动。

### 真实 VR 视角与自然机瞄

- OpenXR 成功启动并检测到 HMD 时，运行时自动启用 `XR Origin` 和 HMD Camera，禁用 `Camera_NoVR` 及其 `AudioListener`；无 XR 设备时执行相反路径。正常调试不应要求人工在 Hierarchy 中切换对象。
- 任一时刻只能有一个活动玩家相机和一个活动 `AudioListener`。
- 真实 VR 中 HMD Camera 的位置、旋转和投影完全由 XR 跟踪负责。枪械、ADS、切肩和后坐力不得写入 HMD Camera 或 XR Origin 的局部/世界姿态。
- 真实 VR 不通过修改 FOV、把相机吸附到 `AimLine`、切换代理 ADS 相机或强制旋转画面实现瞄准。玩家必须实际移动头部和双手，使照门、准星和目标自然共线。
- VR 中 `AimMode` 只可作为姿态分析状态：由眼位到瞄准线的距离和角度阈值推断，用于 HUD/统计，不得反向驱动相机。无 VR 路径仍可保留按键 ADS 代理。
- 射击权威方向始终来自枪口/瞄准线，不来自 HMD forward。玩家转头观察不应改变已持枪械的枪线。
- HMD 常规机瞄距离下不得出现武器被近裁剪面大面积切除、单眼强制黑屏、画面缩放跳变或枪体穿过相机；近裁剪面和武器渲染方案应集中配置并通过实机复核。

### 射击时刻快照

每次开火结果必须冻结射击时刻的数据，不能在事件消费者中重新读取可能已经变化的武器状态：

- `SessionId`、`ShotSequence` 和武器 ID。
- 原始枪线、应用枪体晃动后的有效枪线、命中点和命中对象。
- `WeaponHoldState`、左右手跟踪有效性、`Stability01`、当前肩侧和瞄准模式。
- 由近期枪线运动计算出的 100m 等效晃动偏移。
- 弹药消耗结果和本次后坐力冲量参数。

### 稳定度与枪体晃动

- 稳定度必须基于射击前最近 `0.12-0.20s` 的枪线角速度/漂移和有效双手握持状态计算，不能只根据前后手距离或控制器激活状态给出静态常量。
- 实际玩家路径使用枪线姿态历史生成有方向的晃动偏移；不得把纯随机散布当作稳定度效果。
- `Stability01 >= 0.80` 视为稳定据枪，`Stability01 <= 0.40` 视为明显不稳定；阈值必须集中配置。
- PlayMode Test 可直接注入稳定度、枪线运动偏移和固定时间步，不依赖真实控制器。
- 同一输入、Session 随机种子和射击序号必须产生相同结果。

### P1 训练步枪后坐力

后坐力必须使用“击发冲量 → 短暂回弹/阻尼振荡 → 回到持枪基准”的分阶段响应，不能只使用单次固定位置跳变后线性归零。

- 有效射击后一个渲染帧内，枪体应同时出现向后位移、枪口上跳和轻微横向偏转。
- 建议基础调参范围以 `docs/接口文档/06-武器与弹药服务.md` 为准：单发上跳 `2.5-4.0°`、横向偏转绝对值 `0.15-0.60°`、后退 `0.020-0.040m`、上移 `0.008-0.020m`。
- 击发冲量阶段为 `0.04-0.08s`，阻尼回正阶段为 `0.20-0.35s`，从击发到基本回稳不得超过 `0.45s`。
- 双手稳定据枪时，枪体响应应小于低稳定度双手状态；低稳定度影响玩家对后坐力的控制能力，但不改变武器基础能量等级。P1 单手状态禁止有效射击，不产生单手击发后坐力。
- 连续快速射击时允许后坐力累积，但必须限制最大旋转和位移，三发内不得出现枪体翻转、穿过相机或离开可操作范围。
- 横向偏转可使用 `SessionSeed + ShotSequence` 生成确定性序列，禁止直接依赖全局 `UnityEngine.Random`。
- 本发命中、曳光和射击结果使用**施加本发后坐力之前**采样的有效枪线；如果玩家在尚未回稳时射出下一发，下一发必须使用仍受上一次后坐力影响的当前枪线。

### VR 与无 VR 反馈

- VR 路径不得强制旋转或平移 HMD 相机，也不得修改 XR 投影/FOV；后坐力主要通过枪体/瞄准线脱离、回正动画和手柄触觉表达。
- VR 枪体后坐力必须叠加在双手解算后的局部表现层，不得反向移动控制器或 XR Origin；击发峰值期间后握把与右手视觉分离不超过 `0.015m`，前握把与左手视觉分离不超过 `0.025m`。
- 支持触觉的设备必须向后手输出主要短脉冲，前手输出较弱脉冲；不支持触觉或无设备时使用空实现，不得阻断开火。
- 无 VR 调试路径允许对 ADS 代理相机添加极轻微视觉冲击，但相机附加上跳不得超过 `0.6°`、横摆不得超过 `0.25°`、持续不得超过 `0.12s`。
- 后坐力视觉、触觉和瞄准线必须来自同一次 `WeaponShotResultDto`，不得分别生成互不一致的随机值。

### 服务接入

- 有效射击通过 `WeaponShotResultEvent` 调用 `IZeroingService.RecordShot` 或等效命令。
- 未拾枪、仅右手持枪、控制器跟踪失效、禁射、无弹或非法枪线等无效射击不得生成曳光、弹着、后坐力或触觉反馈。
- HUD 只消费武器/射校 DTO 与事件，不在 View 中推算稳定度或后坐力。

## 不包含

- 不做真实枪械后坐力曲线。
- 不按 19-1、95-1 等具体枪型进行实测参数标定。
- 不做高级弹道学。
- 不做物理枪托对玩家身体的力反馈设备接入。
- 不通过强制晃动 HMD 制造后坐力。
- 不做左利手主握与左右手职责互换；P1 固定左前右后。
- 不做完整手指动画、手臂 IK、全身 Avatar、身体碰撞或真实枪托肩部追踪。
- 不做独立物理弹丸权威、高级外弹道、穿透或跳弹；移动弹体/VFX 只表现既有有效射击结果。

## 测试要求

- EditMode 单元测试：
  - `OnRack → RearHandHeld → TwoHandHeld → RearHandHeld → Dropped` 状态转换正确，右手释放会同时清除前手选择。
  - 范围外右手 Grip、左手尝试拾取后握把、左手先抓前握把均不能建立持枪状态。
  - 只有 `TwoHandHeld`、双手跟踪有效、弹药充足且训练允许射击时 `CanShoot=true`；其余状态扳机结果均无弹药消耗。
  - 右手 Trigger 迟滞阈值只在越过击发阈值时产生一次命令，保持扳机不重复单发，回落到释放阈值后才可再次击发。
  - 双手枪体解算以右手为位置锚点、以前后手轴线决定枪口方向；固定手柄姿态产生确定且有限的枪体姿态。
  - 控制器跟踪失效会禁止射击，短暂丢失不会把枪体姿态重置到世界原点。
  - 同一姿态历史、随机种子和射击序号产生相同稳定度偏移和后坐力冲量。
  - 低稳定度的枪线晃动偏移大于高稳定度，方向来自姿态历史或固定测试样本，而不是不可控随机数。
  - 双手稳定据枪的响应倍率小于低稳定度双手状态；单手状态不生成有效后坐力冲量。
  - 后坐力冲量、累计旋转/位移和回正误差不超过接口文档规定的范围。
  - 禁射或无弹时允许发布带错误码的失败 `WeaponShotResultEvent`，但不得产生有效射击、弹药消耗或射校记录。
  - 无效射击不产生后坐力冲量或触觉请求。
- PlayMode 测试：
  - 场景启动后训练步枪位于枪架/武器台，未挂在相机或手柄层级下，初始 `WeaponHoldState=OnRack` 且 `CanShoot=false`。
  - 可注入的右手姿态进入后握把范围并按 Grip 后，一个渲染帧内进入 `RearHandHeld`；范围外按键不移动枪械。
  - 可注入的左手姿态进入前握把范围并按 Grip 后进入 `TwoHandHeld`；移动左手会连续改变枪口方向。
  - `ManualXRTrainingInput` 必须先完成右手拾取和左手支撑，再由右手 Trigger 连续驱动 3 发；HUD 弹数从 3 变为 0，靶面、射校服务和 HUD 均记录 3 个对应弹着。
  - 在 `OnRack`、`RearHandHeld`、`Dropped` 或跟踪无效状态按 Trigger 时，弹药、弹着、曳光、后坐力和触觉计数均不增加。
  - 左手释放后回到 `RearHandHeld` 并禁止击发；右手释放后前手同步取消、武器进入 `Dropped` 并恢复掉落物理。
  - 使用测试 XR 运行状态验证：XR 可用时只启用 XR Origin/HMD Camera，XR 不可用时只启用 `Camera_NoVR`，始终只有一个活动 AudioListener。
  - 每次有效开火后一帧内，枪体后退并上跳；按固定帧推进后在 `0.45s` 内回到允许误差范围。
  - 第二发在第一发尚未回稳时开火，第二发枪线使用当前后坐力姿态；等待回稳后开火则恢复接近基准枪线。
  - 命中计算、曳光终点、`WeaponShotResultDto` 和射校记录使用同一次有效枪线。
  - 切肩后射击结果肩侧正确，枪体仍在对应肩侧参考点附近完成后坐力和回正。
  - 固定 HMD、XR Origin 和 XR 投影状态在拾枪、自然机瞄、切肩和后坐力期间不被武器脚本改写；触觉测试替身收到后手主脉冲和前手弱脉冲。
  - 无弹继续触发扳机时，弹着数、曳光数、后坐力次数和触觉次数均不增加。
  - 左右虚拟手含可渲染手部网格且不再包含立方体占位；未抓取与双手持枪状态可切换自然/握持姿势，控制器与 HMD Transform 保持不变。
  - 有效射击的枪口焰、移动弹体/曳光、击发声、破空声与命中反馈使用同一射击快照；无效射击的反馈计数不增加。

## 验收标准

- 真实 VR 可以从枪架近距拾枪、左前右后双手持枪、右手扳机射击、放开前手、放下武器并再次拾取，过程中持枪状态可查询且转换一致。
- 枪械不再默认跟随相机；VR 枪体姿态由左右手控制器决定，HMD 只决定玩家观察视角。
- 只有双手持枪且跟踪有效时允许有效射击；未拾枪、单手持枪、掉落或失去跟踪时均不消耗弹药。
- VR 运行时 HMD Camera 是唯一视角权威，不修改其姿态或 FOV；自然机瞄、枪线、曳光和命中方向一致。
- 一次开火能完整触发弹药消耗、命中检测、射校记录和 HUD 刷新。
- 有效射击产生可感知的击发冲量、轻微横向扰动和阻尼回正；同一测试输入下结果确定。
- 枪体在 `0.45s` 内回稳，最终位置误差不超过 `0.005m`、旋转误差不超过 `0.25°`。
- 双手稳定度会影响枪线晃动及玩家控制后坐力的难度，但不会引入纯随机弹着。
- VR 不改写 HMD 姿态；支持触觉时后手主脉冲和前手弱脉冲均可被验证。
- 无 VR 输入替身能先执行与 VR 等价的拾枪/双手状态转换，再完成 3 发一轮。
- 三发链路中的弹药、有效枪线、曳光、靶面弹着、射校记录和 HUD 数量一致。
- 相关 EditMode/PlayMode 测试通过。
