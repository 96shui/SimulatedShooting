# task010 弹着分析 UI

阶段 P1；依据 BDD06、接口04，与功能A task006/task007 及场景 task012 对齐。四发后展示分析页，从 DTO 绘制四发、计算集黄点和初始位于靶心的待应用补偿蓝点；不对被舍弃的一发做额外标注或视觉区分，靶外或无法投影的发次在靶图旁脱靶区显示脱靶标签。按钮原有名称、位置与测试 ID 不变。偏上建议逆时针、偏下顺时针；顺时针补偿向上，逆时针向下，水平每步 2cm、垂直每步 0.32cm，支持长按。

分散时显示 BDD06 原文，四个调整按钮与应用按钮禁用置灰，建议与答案按钮隐藏；前两轮可进入下一轮，第三轮查看评级。集中时展示建议与答案，帮助/答案互斥；实际应用和通过状态来自服务，应用后幂等并立即刷新，不以蓝点作判定。靶图使用统一半身胸靶，以记录数据绘制；场景弹孔清除不影响 UI。

测试：PlayMode 验证四发无额外标注、脱靶标签、分散提示和门禁、帮助/答案、顺时针蓝点上移与应用后导航；VR 实机验证 UI 可读、手柄点击和长按。
