# task010 弹着分析弹窗 UI

## 负责人

UI

## 目标

2026-10-03 后续修订：靶图统一为场景实际半身胸靶，具体交付、坐标映射和新增测试由 [task017](task017-ui-bust-target-consistency.md) 承接；本任务历史验收保留。旧参考图的环形靶示例不作为靶型依据。

实现每轮 3 发后的弹着分析弹窗，展示靶图、3 个弹着点、垂直/水平偏差、准星柱和觇孔调整建议，并支持应用调整和进入下一步。

## 2026-10-05 修订：机械调节与点击帮助（覆盖旧厘米按钮、偏差文本要求）

- 分析页不显示垂直/水平厘米偏差和自动说明；显示觇孔前后格数、准心柱顺逆时针角度，调节按钮分别为一格（2cm）和一度（0.064cm）。服务内部厘米坐标、弹着记录和应用补偿流程保留。
- 觇孔向前使弹着向右，向后使弹着向左；准心柱顺时针使弹着向下，逆时针使弹着向上。准心柱建议方向同步按此规则显示。
- “帮助”默认收起，点击显示：弹着点偏左时觇孔向前调整，弹着点偏右时觇孔向后调整，100m射击距离时觇孔调整一格为两厘米。弹着点偏上时顺时针调整准心柱，弹着点偏下时逆时针调整准心柱，100m射击距离时准心柱调整一圈约为23厘米，调整1度约0.064厘米。
- 最终评级三个靶图按 RoundIndex 分别显示各轮 Shots 原始弹着点，提前通过后未射击的轮次不显示点。标记不得因靶图透明区域采样而不可见，坐标只换算一次。
- 本次按用户要求不运行自动测试；更新回归断言并在编辑器检查编译、靶图渲染和帮助开关。VR实机需确认手柄点击帮助和调节按钮。

## 2026-10-07 垂直微调可见性
- 垂直点击仍为1度=0.064cm，蓝点按 DTO 的 PreviewAverageOffsetCm 真实比例移动，不放大实际补偿。
- 蓝色预览标记缩小，采用固定尺寸、中心位置更新；调节按钮支持按住连续步进，松开、移出、禁用或页面关闭即停止。一次短点击仍只调节一次，长按松开不得额外点击。
- 保留水平一格=2cm。按用户要求不运行测试用例，编辑器直接检查服务返回值与蓝点位置。

## 2026-10-21 新反馈：模式一两轴归零一致性（覆盖旧回退中的弹孔与坐标路径）

用户再次要求修复模式一瞄准后仍无法归零、垂直调整不明显的问题。本次不恢复据枪平滑，不改变HMD相机、初始固定偏移、10环算法、轮次或服务方法/DTO。

- 适配层对靶内和靶外都使用枪线与绑定TargetCenter平面交点，保持靶心原点、X右Y上和厘米单位，继续用既有HitPoint=(xCm,yCm,100)约定传输。兼容射线算法求世界z平面交点时需扣除枪口origin.z。
- ZeroingShotRecordedEvent.Shot.ImpactPointCm是模式一场景弹孔、曳光、HUD、分析和评级的共同来源。场景只显示同发服务弹着，不再次叠加偏移，不显示另一套未补偿弹孔；靶外点不得裁剪到10环内。模式二保留物理命中链路。
- 短按水平仍为一格2cm，垂直仍为一度0.064cm；垂直长按1秒后每周期5度、2秒后每周期15度，由重复单度服务命令实现。保持真实比例，松开、移出、禁用和关页立即停止，松开不追加点击。

验收场景（BDD06，本次新增）：
1. 同一稳定枪线连续三发后，场景弹孔与服务ImpactPointCm一致；默认补偿后同样枪线的下一轮三发，场景和评分都进入10环。
2. 单独水平或垂直补偿真实改变下一轮弹孔、服务记录并与上一轮预览一致，不改变本轮历史点；偏离10环的点不得强制吸附。
3. 瞄准点跨越靶面上下左右边界，厘米坐标连续，不因碰到背板或地面跳变单位或世界原点。
4. 单次垂直点击只移动0.064cm，长按加速可见且释放不追加，另一轴不变。

## 2026-10-21 用户纠正：恢复准心柱原始机械调节节奏

本条覆盖上一修订中新增的长按加速与准心柱±50cm限制；其余弹孔/评分一致性修复保留。
- 准心柱短按每次1度，按0.064cm换算；长按仍以相同单度步长匀速重复，不切换5度/15度。移出、松开、禁用或关页停止，长按松开不追加点击。
- 准心柱可按顺/逆时针连续多圈累计，不设置截断建议角度的±50cm（约±781度）上限。默认补偿超出旧范围时，下一次点击也只能增加/减少1度，不得突然钳回50cm。
- 保留现有默认补偿预览、方向含义、水平每格2cm及其现有范围、同轮应用幂等与原始弹着不变。
- BDD06验收：正负64cm偏差的建议角度大于781度时仍能逐度调整；双向累计1600度不提前停止；实际应用只发生一次；UI长按超过2秒仍是匀速单度，松开不追加。
- P1 task006与UI task010共同修复；EditMode覆盖大建议角度、多圈与幂等，PlayMode覆盖短按、长按和分析预览。头显手柄操作保留实机验收。
