# task010 弹着分析弹窗 UI

## 负责人

UI

## 目标

2026-10-03 后续修订：靶图统一为场景实际半身胸靶，具体交付、坐标映射和新增测试由 [task017](task017-ui-bust-target-consistency.md) 承接；本任务历史验收保留。旧参考图的环形靶示例不作为靶型依据。

实现每轮 3 发后的弹着分析弹窗，展示靶图、3 个弹着点、垂直/水平偏差、准星柱和觇孔调整建议，并支持应用调整和进入下一步。

## 交付内容

- `Screen_ZeroingImpactAnalysis`
- 靶图显示区域。
- 3 个弹着点显示。
- 偏差数据文本：
  - 垂直偏差。
  - 水平偏差。
  - 准星柱方向和角度。
  - 觇孔方向和格数。
- 显示 3 发坐标均值、两轴待应用补偿和补偿后的弹着中心预览；水平与垂直各有 ±1cm 按钮，均有稳定测试 ID。
- `Button_ZeroingImpactAnalysis_ApplyAdjustment`
- `Button_ZeroingImpactAnalysis_NextRound`
- 已应用状态显示。

## 2026-10-05 修订：机械调节与点击帮助（覆盖旧厘米按钮、偏差文本要求）

- 分析页不显示垂直/水平厘米偏差和自动说明；显示觇孔前后格数、准心柱顺逆时针角度，调节按钮分别为一格（2cm）和一度（0.064cm）。服务内部厘米坐标、弹着记录和应用补偿流程保留。
- 觇孔向前使弹着向右，向后使弹着向左；准心柱顺时针使弹着向下，逆时针使弹着向上。准心柱建议方向同步按此规则显示。
- “帮助”默认收起，点击显示：弹着点偏左时觇孔向前调整，弹着点偏右时觇孔向后调整，100m射击距离时觇孔调整一格为两厘米。弹着点偏上时顺时针调整准心柱，弹着点偏下时逆时针调整准心柱，100m射击距离时准心柱调整一圈约为23厘米，调整1度约0.064厘米。
- 最终评级三个靶图按 RoundIndex 分别显示各轮 Shots 原始弹着点，提前通过后未射击的轮次不显示点。标记不得因靶图透明区域采样而不可见，坐标只换算一次。
- 本次按用户要求不运行自动测试；更新回归断言并在编辑器检查编译、靶图渲染和帮助开关。VR实机需确认手柄点击帮助和调节按钮。

## 2026-10-07 垂直微调可见性
- 垂直点击仍为1度=0.064cm，蓝点按 DTO 的 PreviewAverageOffsetCm 真实比例移动，不放大实际补偿。
- 蓝色预览标记缩小，采用固定尺寸、中心位置更新；调节按钮支持按住连续步进，松开、移出、禁用或页面关闭即停止。一次短点击仍只调节一次，长按松开不得额外点击。
- 保留水平一格=2cm。按用户要求不运行测试用例，编辑器直接检查服务返回值与蓝点位置。
