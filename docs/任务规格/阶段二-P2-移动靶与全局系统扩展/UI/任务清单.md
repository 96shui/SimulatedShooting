# P2 UI 任务清单

## 负责范围

在 P1 UI、路由和输入基线之上完成移动靶设置、昼夜 HUD、移动靶结算、武器库原型、设置界面原型，以及全部 P2 页面统一视觉、稳定测试 ID、无 VR 自动化和 VR 可读性收口。

UI 只负责显示 DTO、维护界面临时交互状态和转发命令，不计算移动靶状态、命中评级、点射弹药、武器适用性或设置持久化结果。

## 需要联调

- 功能A：P2 路由、移动靶设置与 Session、`HudDto`、`MovingTargetResultDto`、设置 Pending/持久化结果、端到端门禁。
- 功能B：两发点射后的弹药和命中刷新、昼夜瞄具状态、武器定义与装备结果、设置运行时预览和应用结果。
- 场景：移动靶靶场 HUD 空间位置、昼夜/微光视觉、武器墙展示位、World Space Canvas 和 VR 射线交互。

## 阶段边界

- P2 只开放移动靶、武器库和设置的完整 UI 流程；堑壕、城镇入口及其页面属于 P3。
- 队友指令、高级 AI、真实弹匣插拔、拉机柄、保险、卡弹和高级夜视模拟属于 Later。
- P2 页面必须复用 P1 的路由、输入适配、Canvas/XR UI 与测试基础，不创建仅供 P2 UI 使用的第二套输入或业务状态。
