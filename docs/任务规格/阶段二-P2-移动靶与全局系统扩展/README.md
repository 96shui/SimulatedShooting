# 阶段二 P2：移动靶与全局系统扩展

## 阶段目标

在 P1 稳定基础上扩展移动目标射击，并补齐武器库原型、设置原型、弹药/HUD 复用系统。

## 阶段入口门禁

- 当前仓库仍处于 P1 端到端联调收口，详见 [P1 任务进度](../阶段一-P1-100m射校原型闭环/任务进度.md)。
- P2 规格可以提前完成，但实现不得绕过 P1 task014；P1 task014、task015、task016 完整收口并完成当前基线回归后，才能把 P2 标记为“进行中”。
- P2 task001 是文档、接口与测试基线冻结门禁。它必须先解决两发点射原子命令、唯一弹药权威、路线进度、Session 生命周期、P2 UI 事件、HUD 稳定键、设置预览/训练暂停、评级摘要和 Unity 绑定等缺口。
- task001 完成前，其他任务只能制作不依赖未冻结接口的视觉稿、测试计划或场景 Blockout，不得各自发明替代 DTO、事件或服务。

## 范围口径

- 移动靶：白天/夜晚、合法速度、3 秒等待、右→左→右 40m 路线、左端停留 2 秒禁射、10 发/5 次两发点射、命中评级与结算。
- 武器库：按当前 BDD/接口提供四把公开武器的目录、属性、预览和装备状态；至少训练主武器可在 P2 训练中实际使用。堑壕/城镇中的实际生成与完整战斗行为属于 P3。
- 设置：按当前 `22-设置界面.feature.md` 和 `10-设置服务.md` 实现字段、Pending 预览、应用、恢复默认、返回不保存与简单本地持久化；Unity 运行时映射必须由适配层完成。
- 复用：输入、双手持枪、射击快照、后坐力、弹药、HUD、路由和 Session 必须在 P1 能力上扩展，不建立 P2 专用旁路。
- 排除：敌人/队友 AI、堑壕/城镇战斗、完整训练历史、高拟真夜视、真实弹匣插拔、拉机柄、保险和卡弹。
