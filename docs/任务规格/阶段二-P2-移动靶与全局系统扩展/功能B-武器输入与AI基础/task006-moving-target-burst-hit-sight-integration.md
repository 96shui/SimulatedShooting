# task006 移动靶两发点射、命中与昼夜瞄具接入

## 负责人

功能B-武器输入与AI基础

## 目标

复用 P1 输入、双手持枪和射击快照链路，把一次有效扳机输入转换为移动靶的两发点射，并把每发命中、弹药和昼夜瞄具状态可靠交给移动靶服务和场景表现层。

## 交付内容

- task001 冻结后的点射输入/结果契约及功能侧协调器：
  - 一个 `TriggerPressed` 最多生成一次两发点射命令。
  - 两发共享同一个 `BurstIndex`，但各自保留可追踪的射击序号、枪线快照和命中结果。
  - 点射开始前一次性校验移动靶 `CanShoot`、双手持枪/跟踪状态、剩余弹药和点射次数。
  - 合法点射原子预留或消耗 2 发；不得出现只扣 1 发、失败后由 UI 回滚的路径。
  - 等待期、左端停留、路线结束、非法持枪、弹药不足和第 6 次点射不产生有效射击、后坐力、枪口焰、曳光、命中或弹药消耗。
- 两发命中接入：
  - 命中只来自同一有效枪线的场景检测结果，不由 HUD 推断。
  - 将 0、1 或 2 发命中以及目标位置/时间点写入 `BurstRecordDto` 或 task001 更新后的等效 DTO。
  - 同一发不能因重复事件订阅被记录两次。
- 昼夜瞄具状态：
  - 白天使用觇孔/机械瞄具状态。
  - 夜晚启用微光瞄准镜状态，并通知 task011 的视觉适配器。
  - 真实 VR 继续由 HMD 自然机瞄，不改写 HMD Camera、XR Origin 或 FOV；无 VR 使用同一枪线的测试瞄准替身。
- 复用 `IXRTrainingInput`、`IWeaponPoseInput`、`IWeaponControlService` 和有效射击反馈事件，不创建移动靶专用硬件读取路径。

## 不包含

- 不实现目标运动状态机、路线计时或评级。
- 不实现 HUD 排版、结算页或微光镜后处理材质。
- 不实现全自动连发、复杂外弹道、纯随机散布或高级夜视模拟。

## 联调说明

- 与 功能A 联调：点射前读取 `CanShoot`，点射后提交逐发命中与一次 `BurstRecordDto`；由移动靶服务决定是否接受。
- 与 场景 联调：目标碰撞、枪线命中、白天觇孔和夜晚微光镜状态；视觉反馈只消费有效射击快照。
- 与 UI 联调：只提供事件/DTO，HUD 读取点射数、弹药、命中和瞄具状态。

## 测试要求

- EditMode 单元测试：
  - 一次触发生成恰好两发且只形成一条点射记录。
  - 0/1/2 发命中正确汇总，重复射击事件不会重复计数。
  - 第 5 次点射后弹药为 0，第 6 次返回 `InvalidState`。
  - 等待、端点停留和路线完成状态先拦截，弹药与命中不变。
  - 白天/夜晚映射到正确瞄具状态。
- PlayMode 测试：
  - 无 VR 输入替身按 P1 的右手拾取、左手支撑、右手扳机链路完成一次两发点射。
  - 合法点射产生两次有效射击表现且一条点射记录；禁射输入不产生枪口焰、曳光、后坐力或命中反馈。
  - 夜晚状态能驱动 task011 可观察的微光镜适配入口。
- VR 实机验收：点射节奏、双手持枪、觇孔/微光镜可用性和 HMD 视角不被强制改变。

## 验收标准

- 点射、扣弹、逐发命中和点射记录形成一条可追踪、不会重复提交的链路。
- 所有禁射分支在任何真实射击反馈之前完成拦截。
- 无 VR 与真实 XR 复用同一业务命令和枪线规则。
- EditMode/PlayMode 测试通过，VR 手工验收项已记录。
