## 需要联调

- 功能A：点射消耗、禁射拦截、命中回传、设置预览/正式事件、训练暂停路由和 Session 不变量。
- UI：弹药、命中、瞄具状态、武器目录/装备状态，以及设置 Pending/应用/回滚的可观察状态。
- 场景：移动靶碰撞、夜视视觉、武器墙模型、XRI 移动/转向 Provider、HUD CanvasGroup、AudioMixer 和曝光适配根节点。

## 阶段边界

- P2 复用 P1 的输入、双手持枪、后坐力、射击快照和无 VR 替身，不建立第二套输入或武器控制链路。
- P2 不实现敌人/队友 AI；目录名中的“AI 基础”只保留后续承接关系。
- 堑壕/城镇实际生成四类武器属于 P3；真实弹匣插拔、拉机柄、保险、卡弹属于 Later。
