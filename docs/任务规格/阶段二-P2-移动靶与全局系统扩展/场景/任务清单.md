# P2 场景任务清单

## 负责范围

移动靶靶场、左右端点标识、移动路线、昼夜表现、武器库场景或武器墙区域。

## 任务清单

| 编号 | 任务 | 规格文件 | 主要依赖 | 联调对象 |
|---|---|---|---|---|
| task005 | 移动靶靶场 Blockout 与路线绑定 | [task005-scene-moving-target-range-blockout.md](task005-scene-moving-target-range-blockout.md) | task001 | UI、功能A、功能B |
| task011 | 昼夜环境、目标运动与微光镜表现接入 | [task011-scene-day-night-lowlight-integration.md](task011-scene-day-night-lowlight-integration.md) | task005、task006 | UI、功能A、功能B |
| task012 | 武器库武器墙与展示挂点 | [task012-scene-armory-weapon-wall.md](task012-scene-armory-weapon-wall.md) | task003 | UI、功能A、功能B |
| task018 | P2 场景视觉、性能与总联调收口 | [task018-scene-p2-visual-performance-integration.md](task018-scene-p2-visual-performance-integration.md) | task005、task011、task012、task016、task017 | UI、功能A、功能B |

任务实现必须保留 `MovingTargetRangeScene` / `MainMenuScene` 的 `SceneId` 语义和稳定测试 ID。场景脚本只负责 Unity 对象、视觉表现和服务状态到 Transform 的绑定，不得另建移动靶状态机或决定禁射、弹药、命中评级和结算。

## 需要联调

- UI：HUD 空间位置、武器库 UI/场景交互。
- 功能A：移动路线状态、端点禁射、场景加载。
- 功能B：点射命中、夜视瞄具、武器模型挂点。
