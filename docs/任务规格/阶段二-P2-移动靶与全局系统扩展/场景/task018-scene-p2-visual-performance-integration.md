## 交付内容

- P2 场景视觉收口：
  - 统一移动靶靶场白天、夜晚、端点标识、目标轮廓和 HUD 的训练模拟器风格。
  - 统一武器墙、四个展示位、选中/已装备标识和属性 UI 的空间层级。
  - 保留 task005/task011/task012 已公布的 SceneId、对象绑定和测试 ID，不因美术命名调整而改变。
- 性能与资源收口：
  - 复用材质、灯光和几何体，端点标识优先使用自发光材质而非额外实时阴影灯。
  - 默认原型预算：`MovingTargetRangeScene` 活动 Renderer 不超过 320、独立材质不超过 32、活动实时阴影灯不超过 2、后处理 Volume 不超过 1。
  - 微光镜 RenderTexture 或等效离屏输出单路分辨率不高于 `1024x1024`，可按设备质量档下降；辅助瞄具 Camera 不得携带 `AudioListener`。
  - 禁止每帧实例化材质、复制目标或创建无上限弹着/VFX；临时对象必须池化或有明确释放上限。
- 运行模式收口：
  - OpenXR 可用时启用 Floor Tracking 的 XR Origin/HMD Camera；无 XR 时启用 `Camera_NoVR`。
  - 任一时刻只有一个活动玩家 Camera 和一个活动 `AudioListener`；允许受控微光辅助 Camera，但不得成为玩家视角或携带监听器。
  - 场景脚本不改写 HMD 姿态、XR Origin 或 FOV，不依赖人工切换 Hierarchy。
- 总联调检查：
  - 模式选择 → 设置 → 日/夜移动靶 → 端点停留 → 完成路线 → 结算 → 重训/返回流程可在同一套场景对象上运行。
  - 武器库四展示位、选择/装备视觉和返回流程不污染移动靶 Session。
  - 重新加载/重训后无重复 EventSystem、XR Interaction Manager、Camera、AudioListener、路线、灯光或武器墙对象。
  - `ZeroingRangeScene` 可加载并完成 P1 场景烟雾检查，P2 资源与服务接入不破坏 P1 测试 ID、相机和武器锚点。
- 输出 P2 场景验收说明，记录实际对象预算、测试结果、目标 VR 设备和未覆盖风险。

## 不包含

- 不新增 P3 堑壕、城镇、敌人 AI、队友、战斗武器生成或血量系统。
- 不以本任务替代 task016/task017 的服务/UI 端到端测试，也不在场景中补写玩法规则。
- 不承诺未指定目标设备上的固定帧率；必须记录实测帧时间和设备信息，不能用 Editor 帧率冒充 VR 性能。
- 不做最终商业级美术资产、高级夜视或完整武器展示动画。

## 联调说明

- 与 功能A 联调：场景加载、移动靶权威状态/时间驱动、路线完成、结算和重训清理。
- 与 功能B 联调：点射命中、微光瞄具、武器定义/装备事件、弹道和目标命中面。
- 与 UI 联调：日/夜 HUD、禁射提示、结算、武器墙属性面板、Busy 状态和稳定测试 ID。
- 与 P1 回归联调：确认共享输入、武器、HUD、相机和事件系统没有破坏 100m 射校。

## 测试要求

- PlayMode 测试：
  - 加载 `MovingTargetRangeScene`，验证 task005/task011 全部关键测试 ID、SceneId 和绑定引用仍存在。
  - 加载 `MainMenuScene` 武器库状态，验证 task012 四展示位和选择/已装备表现。
  - 使用可替换时间与输入测试替身运行 task017 定义的白天、夜晚关键流程，确认场景对象不重复、目标位置与服务状态一致。
  - 日/夜切换、完成、重训和返回后只有一个玩家 Camera、一个 `AudioListener`、一个 EventSystem 和一个 XR Interaction Manager。
  - Renderer、材质、实时阴影灯、后处理和微光输出满足本任务预算；预算如需调整，必须先更新本规格和验收说明。
  - 禁射状态、弹药和评级只能从服务断言；测试不得通过端点 Transform 或视觉根节点推导业务结论。
  - 加载 `ZeroingRangeScene` 完成 P1 场景烟雾测试，确认关键测试 ID、相机/监听器互斥和主靶射线未回归。
  - 测试可在无 VR 设备环境运行，不依赖真实时间、随机结果或手工 Hierarchy 切换。
- 测试名称或说明必须引用上表中的 BDD 文件和精确场景名。

## VR 手工验收

- 从 MainMenuScene 进入武器库，四武器展示、选中/已装备反馈和左右手 UI 射线均清晰可用。
- 白天移动靶在完整 40m 路线和 100m 射距上可辨，HUD、武器和目标互不遮挡。
- 夜晚微光镜中心目标可读，端点标识不过曝，HUD 不受染色/裁切，HMD 无吸附或 FOV 跳变。
- 完成、重训、返回及昼夜切换期间无黑屏、相机争抢、重复音频、明显卡顿或残留场景对象。
- 在目标设备记录 OpenXR Runtime、连接方式、刷新率、平均/高分位帧时间、微光效果舒适度和任何不适。
- 复验 P1 100m 靶场的 HMD 视角、武器拾取、HUD 可读性和场景加载没有明显回归。

## 验收标准

- task005、task011、task012 的场景交付在同一 P2 流程中稳定工作，且 task016/task017 门禁已通过。
- 无 VR PlayMode 测试覆盖场景加载、日/夜、路线、武器墙、重训清理和 P1 烟雾回归。
- VR 手工验收覆盖武器墙、白天移动靶、夜晚微光、性能和 P1 回归，并形成记录。
- 场景对象、视觉效果和性能优化没有引入第二套业务状态或破坏稳定测试 ID。
