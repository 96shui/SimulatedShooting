# 阶段二 P2：移动靶闭环

## 阶段目标

在 P1 稳定基础上扩展移动目标射击闭环。沿用 P1 的输入、双手持枪、训练主武器、觇孔、弹药、HUD、路由和 Session。

## 阶段入口门禁

- 当前仓库仍处于 P1 端到端联调收口，详见 [P1 任务进度](../阶段一-P1-100m射校原型闭环/任务进度.md)。
- P2 规格可以提前完成，但实现不得绕过 P1 task014；P1 task014、task015、task016 完整收口并完成当前基线回归后，才能把 P2 标记为“进行中”。
- P2 task001 是文档、接口与测试基线冻结门禁。它必须先解决两发点射原子命令、弹药权威、路线进度、Session 生命周期、移动靶 UI 事件、HUD 稳定键和 Unity 绑定等缺口。
- task001 完成前，其他任务只能制作不依赖未冻结接口的视觉稿、测试计划或场景 Blockout，不得各自发明替代 DTO、事件或服务。

## 范围口径

- 移动靶：速度 3/4/5 m/s、3 秒等待、右→左→右 路线、左端停留 2 秒禁射、10 发/5 次两发点射、命中评级与结算。
- 复用：输入、双手持枪、射击快照、后坐力、弹药、HUD、路由和 Session 必须在 P1 能力上扩展，不建立 P2 专用旁路。
- 排除：敌人/队友 AI、堑壕/城镇、完整训练历史、高拟真枪械操作（属其他阶段或不做）。
