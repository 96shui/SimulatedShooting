# P2 场景任务清单

## 负责范围

本角色负责 P1/P2 场景壳、固定卧姿射击点、XR Rig 策略落地、UI/枪独立锚点、移动靶靶场与路线、命中表面和白天视觉。场景只提供 Unity 对象绑定和表现，不承载训练或连射规则。

## 任务

| 编号 | 任务 | 规格文件 | 同线前置 | 对外输出 |
|---|---|---|---|---|
| task003 | P1/P2 场景壳与卧姿射击点重构 | [task003](task003-prone-range-scene-shells.md) | 无 | 共用场景绑定、卧姿站位、独立 Anchor、场景校验测试 |
| task006 | 移动靶场、40m 路线与白天视觉 | [task006](task006-moving-target-range-and-route.md) | task003 | P2 场景、路线/端点/靶面、逐发视觉驱动与性能基线 |

交付记录见 [task003/task006 场景交付说明](task003-task006-场景交付说明.md)。

## 独立性要求

- 场景不保存 UI Presenter、Canvas、Session、玩法具体服务或业务状态机引用。
- 场景通过稳定 Binding 暴露 Anchor/路线/命中表面，通过 Fake 或真实视觉状态驱动表现。
- 场景可用 Fake 目标进度和 Fake ShotId 独立测试，不等待 UI 或玩法实现。
- 场景内不得计算 Trigger 连射、倒计时、禁射、弹药、命中率、评级或完成条件。

## 不负责

- 不实现 UI 页面和玩法规则。
- 不制作昼夜切换、夜间/低照度、夜视、敌人 AI、武器库、设置区或玩家行走区域。
