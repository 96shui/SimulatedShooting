# P2 玩法功能任务清单

## 负责范围

本角色统一承担原“功能 A / 功能 B”的生产玩法，包括训练状态、卧姿固定策略、移动靶规则、两发起射/长按连射、武器与弹药、逐发命中、HUD/结算 DTO 和应用流程协调。

## 任务

| 编号 | 任务 | 规格文件 | 同线前置 | 对外输出 |
|---|---|---|---|---|
| task001 | P1/P2 共用卧姿、禁移动与界面显隐状态机 | [task001](task001-prone-presentation-state-machine.md) | 无 | 展示状态 DTO、移动策略、命令与事件 |
| task004 | 移动靶核心、路线、逐发记录、计分与结算 | [task004](task004-moving-target-core-and-results.md) | task001 | 移动靶状态/HUD/结果 DTO 与确定性规则 |
| task007 | 两发起射/长按连射、武器弹药、命中与应用流程 | [task007](task007-auto-fire-weapon-hit-and-flow.md) · [交付记录](task007-交付记录.md) | task001、task004 | Trigger 状态、连射序列、逐发快照和流程协调 |

## 独立性要求

- 玩法实现不得引用 UI View、Presenter、具体场景、Prefab、Canvas、XR 组件或 Transform。
- UI 通过命令、查询、DTO、事件接入；场景通过输入/枪线/命中与视觉端口接入。
- 使用固定时钟、固定随机种子、取枪/Trigger/命中 Fake 和内存事件总线自测，不等待真实 UI 或场景。
- task007 的连射调度属于玩法规则，不能放到枪口动画、场景 Coroutine 或 UI 中。

## 不负责

- 不制作 UI 或场景视觉，不决定空间摆位。
- 不实现昼夜系统、夜视、敌人 AI、玩家移动、武器库、选枪或设置页面。
