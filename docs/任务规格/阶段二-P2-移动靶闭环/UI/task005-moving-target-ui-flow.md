# task005：移动靶设置、连射 HUD 与结算 UI

## 负责人

UI。

## 目标

基于 task002 共用框架实现 P2 移动靶的速度设置、等待取枪提示、倒计时/连射最小 HUD 和训练结算 UI，并用 Fake DTO 覆盖快速两发与长按连射，不依赖真实玩法或场景。

## 前置条件

仅依赖 UI 同线 task002。接口字段以已冻结接口为准，不依赖 task004 或 task006 的实现完成。

## 实现内容

### 1. 速度设置与开始

- 显示 3 / 4 / 5 m/s 三个明确选项和当前选择。
- 开始按钮只发送带速度的命令；防重复点击并展示服务错误，不自行创建 Session。
- 开始命令成功后仍保持大型 UI，显示“请拿起正前方训练枪”等待提示。
- 只有收到进入倒计时/实射的展示 DTO 后才隐藏大型 UI。

### 2. 倒计时与最小 HUD

- 倒计时在 `MinimalHudRoot` 显示 3、2、1 和开始提示，数据来自 HUD DTO。
- 实射最小 HUD 显示“两发起射 / 长按连射”、弹药、命中/进度、速度、方向与禁射提示。
- 使用 `HudDto.FireSequence` 显示 Idle、InitialTwoShots、ContinuousFire、Stopped 或对应中文状态；状态文本只做映射，不自行计时。
- 快速扣动时 HUD 按两个逐发快照更新；长按时继续逐发刷新弹药和命中，不能一次把 UI 直接跳到最终弹药数。
- 因释放、无弹、禁射、训练完成或武器失效停止时，按 DTO 显示必要提示；UI 不决定是否重新武装 Trigger。
- HUD 不从目标 Transform 推断方向或进度，不从武器对象读取弹药。
- 左端 2 秒停留时按 DTO 明确显示禁射；不得用颜色动画自行判断开火许可。

### 3. 结算与重试

- 训练完成状态到达后自动隐藏最小 HUD并显示正前方结算大型 UI。
- 显示总射击、命中、命中率、速度、用时和评级；格式化与空值策略集中在 Presenter。
- 按扣动次数显示射击序列；每个序列显示“快速两发/进入连射”、实际发数、命中发数和停止原因，并可展示逐发记录。
- 结算按实际扣动序列显示，不固定记录条数；一个长按序列可以包含 2-10 发。
- 重试/返回按钮只发送命令，并在确认状态到达前防止重复提交。
- 结算时不得保留可触发射击的 UI 焦点或旧 HUD 数据。

### 4. 视觉一致性

- 延续 P1 的字体、色彩、层级、按钮状态和错误提示风格。
- 大型面板避开枪械初始摆位和中心瞄准保留区；真实空间距离由场景 Anchor 和阶段审核节点 D 实机验收确认。
- 所有控件遵守统一命名与测试 ID。

## 交付物

- `Screen_MovingTargetSetup`、移动靶最小 HUD、`Screen_MovingTargetResults` 的 Prefab/View/Presenter。
- DTO 字段映射、命令转发表和错误状态表现。
- 3/4/5 m/s、等待取枪、倒计时、快速两发、长按连射、释放停止、禁射停止、结算、重试的 Fake 序列。
- 无真实场景/服务的 PlayMode UI 测试和测试 ID 清单。

## 测试要求

- 三种速度选中态和命令参数正确；非法/缺失速度不能开始。
- 开始成功但未取枪时 UI 保持可见；取枪状态到达后大型 UI 隐藏。
- 倒计时和实射 HUD 按 DTO 顺序更新，重复 DTO 不产生重复动画或命令。
- 快速扣动 Fake 序列逐发显示 10→9→8；长按 Fake 序列继续逐发减少，释放后保持最终值。
- 禁射中止后显示禁射/停止状态；条件恢复但 Trigger 未重新武装时，UI 不伪造“正在连射”。
- 左端停留显示禁射，离开后恢复；抵达右端则等待结果状态，UI 不决定这些时机。
- 完成后结算自动出现，快速两发序列、长按多发序列、0 命中、全命中和边界评级均正确渲染。
- 重试/返回一次点击只发送一次命令；销毁后无事件泄漏。
- 所有关键控件可由稳定测试 ID 定位。

## 验收标准

- P2 全 UI 流程可在空白测试场景使用 Fake DTO 演示。
- UI 无真实场景、目标 Transform、武器组件或玩法具体服务引用。
- 大型 UI 与最小 HUD 的职责和显隐严格符合共用契约。
- UI 没有连射间隔、Trigger Held、逐发扣弹和停止条件规则。
- 不出现昼夜、夜视、武器库、设置或移动控制 UI。

## 联调契约（非实现依赖）

- 玩法提供已冻结 DTO/事件；任何字段缺失通过文档变更处理，不直接引用服务内部模型。
- 场景提供 UI Anchor；UI 不要求 task006 的场景名称或层级。
- 阶段审核节点 D 只通过组合根把接口实现注册给 Presenter。
