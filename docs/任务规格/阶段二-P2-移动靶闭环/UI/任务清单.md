# P2 UI 任务清单

## 负责范围

本角色负责 P1/P2 正前方大型交互 UI、只读最小 HUD、显隐表现、移动靶设置/连射 HUD/结算、Presenter、稳定测试 ID 和无场景 PlayMode 测试。UI 只渲染 DTO、维护视觉临时状态并转发命令。

## 任务

| 编号 | 任务 | 规格文件 | 同线前置 | 对外输出 |
|---|---|---|---|---|
| task002 | P1/P2 正前方 UI、最小 HUD 与显隐框架 | [task002](task002-front-ui-and-visibility-framework.md) | 无 | 共用 UI Prefab、Presenter、测试 ID、显隐测试 |
| task005 | 移动靶设置、连射 HUD 与结算 UI | [task005](task005-moving-target-ui-flow.md) · [交付记录](task005-交付记录.md) | task002 | P2 页面、连射状态映射、命令转发与 PlayMode 测试 |

## 独立性要求

- UI Prefab 不保存真实场景 Transform、武器组件、XR Rig 或玩法具体实现引用。
- 空间放置只消费通用 Anchor 绑定；UI 不搜索场景层级。
- Presenter 使用 Fake DTO 序列和命令 Spy 测试，不等待场景或玩法实现。
- UI 不计算连射节奏、评级、移动靶位置、开火许可、弹药、命中或训练完成条件。

## 不负责

- 不搭建靶场、路线和卧姿 XR Rig，不实现业务状态机或 Trigger 连射。
- 不制作昼夜、夜视、武器库、设置页面或玩家移动相关 UI。
