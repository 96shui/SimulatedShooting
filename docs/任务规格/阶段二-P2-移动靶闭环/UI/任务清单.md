# P2 UI 任务清单

## 负责范围

在 P1 UI、路由和输入基线之上完成移动靶速度设置、HUD、结算，以及 P2 页面统一视觉、稳定测试 ID、无 VR 自动化和 VR 可读性收口。

UI 只负责显示 DTO、维护界面临时交互状态和转发命令，不计算移动靶状态、命中评级或点射弹药。
