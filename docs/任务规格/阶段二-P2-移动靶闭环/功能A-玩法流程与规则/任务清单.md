# P2 功能A 任务清单：玩法流程与规则

## 负责范围

P2 契约与回归准入、移动靶核心状态机、跨模式 HUD/结算聚合，以及覆盖移动靶闭环和 P1 回归的端到端测试门禁。

功能A只实现 DTO、应用服务、玩法规则、事件和测试编排，不实现 UI 视觉、Unity 场景、武器表现、目标 Transform 驱动或 XR 硬件读取。

## 需要联调

- UI：移动靶入口与速度设置、HUD、结算及全部稳定测试 ID。
- 场景：移动路线配置、规范化路线进度、端点和场景加载失败反馈。
- 功能B：10 发移动靶弹药初始化、两发点射原子命令、禁射前置拦截、逐发命中快照。
- P1：task014 端到端门禁、task015 UI/测试 ID 收口、task016 场景与性能收口；P2 不得以修改 P1 既有行为来规避回归失败。
