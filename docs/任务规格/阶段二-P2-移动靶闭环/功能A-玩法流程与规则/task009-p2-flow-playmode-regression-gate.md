## 目标

用无 VR 输入替身跑通移动靶闭环，并回归 P1 射校主流程，作为 P2 实现完成的硬门禁。

## 必须覆盖的流程

1. 主菜单 → 移动靶设置 → 选择速度 → 开始训练。
2. 3 秒等待 → 目标运动 → 若干次点射（含禁射验证）→ 结算。
3. 重新训练保留速度；返回模式选择。
4. P1 射校主流程仍可通过。
