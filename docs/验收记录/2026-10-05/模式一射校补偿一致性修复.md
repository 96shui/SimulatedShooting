# 模式一补偿与弹孔一致性

上一次终局直接评级改动没有修改补偿公式：仍为原始瞄准厘米坐标+同局固定偏移，应用补偿只更新固定偏移一次。但此前场景绘制未经补偿的物理射线弹孔，服务记录则叠加固定偏移；脱靶与碰靶还走不同坐标路径，用户会看到场景与分析不一致。

本次修复P1场景输入：所有朝向绑定靶面的射线都按同一平面交点转为靶心厘米坐标；碰到/未碰到Collider不改变坐标系。朝向靶面反方向的射击保持脱靶。场景从ZeroingShotRecordedEvent取实际服务弹着，显示相同弹孔和弹道终点，不再画另一套未补偿弹孔。P2保留原路径。补偿公式、手动每次1cm、默认归零、重复应用幂等以及终局直接评级均保持。

实际ZeroingRangeScene编辑器检查：原始靶面瞄准(2,11)cm，首轮平均(10.03,9.40)cm，默认预览(0,0)，应用后同样瞄准输入下一发为(0,0)，InsideTenRing=true。碰靶与脱靶解析一致，靶面外(40,20)cm仍按正确厘米坐标记录。详见射校补偿一致性.txt。

更新BDD06、接口04及task013；补充无VR坐标一致性PlayMode候选。Unity编译后控制台0错误。按用户要求不运行测试用例、不提交。用户实机仍需确认连续三发瞄准稳定度及所见弹孔。

操作说明：默认待应用补偿已经将平均点预览归零；若预览点在靶心，直接应用即可。方向按钮是在此补偿基础上继续每次改变1cm，额外调整会移开预览中心，不代表重复应用自动建议。
